## 1. 当前究竟是哪一版

当前**主目录**是 **32 声部 × 16 泛音的 TDM 加法合成引擎，带 16 路物理 RC 电极输入**。
38 通道键位映射模块已经存在，但整块新面板、逐声部四维表情和新手势尚未完成。
事件接收已有公共 FIFO 与确认握手，但源端单槽仍会丢紧邻事件。

| 项目 | 当前源码事实 | 核对入口 |
|---|---|---|
| 出货工程 | `src/gowin/tdm_synth/tdm_synth.gprj` | 19 个启用的 Verilog 文件、2 个约束文件 |
| 出货顶层 | `tdm_ship` 包装 `tdm_top`；调试音符口、引脚预设、引脚测试模式接常量 | `src/rtl/tdm_ship.v`；本地 process config 的 `TopModule=tdm_ship`；构建命令仍需核对选项 |
| 主时钟 | 27 MHz，音频主链无 PLL | `tdm_top.v`、`audio_clk_en.v` |
| 实际采样率 | **52734.375 Hz = 27 MHz / 16 / 32**，512 拍/样本 | `tdm_top.v:909` 显式覆盖 `DIV_BCK=16`；本次出货顶层仿真实测 |
| BCK / 字宽 | BCK 1.6875 MHz；内部 24 位、取高 16 位，左右槽重复同一个样本 | `i2s_tx.v`，不是双路独立立体声 |
| 合成配置 | `NSLOT=512`、`NG=32`、`P=16`、24 位相位 | `tdm_top.v`、`tdm_engine.v` |
| 物理输入 | `pad[15:0]`：低 8 位进音高，高 8 位进泛音掩码 | `tdm_ship.v`、`tdm_top.v:471–515` |
| 当前触摸音高 | 低 8 键是 MIDI 48–55，即 C3–G3 的全半音；固定力度 `4'd12` | `pp_touch={30'b0,pad_state[7:0]}`、`BASE=48`；不是旧五声音阶映射 |
| 音域条 | 模块已实例化，但 `cell_t=0`，保持默认档 | `strip_ctrl.v`、`tdm_top.v` |
| 主机控制 | UART 115200 8N1；寄存器写、回读、谱编辑、曲谱与遥测 | `reg_bank.v`、UART 收发、`tools/scripts/dsp_host.py` |

注意：`audio_clk_en` 的**默认参数**仍是 18，对应 46875 Hz；不能用模块默认值替代顶层覆盖值。
本次 `clock` 测试验证默认 18，另加 `shipclock` 测试验证真正出货配置 16，两项分别记录。
