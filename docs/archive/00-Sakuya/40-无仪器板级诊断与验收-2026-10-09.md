# 无仪器板级诊断与验收 · 2026-10-09

本轮经用户授权进行全面测试。硬件为已经通过USB/JTAG扫描的Tang Nano20K，只有USB数据线；
没有喇叭、外部触控、万用表或示波器。本页记录诊断版本边界，最终结果另写验收报告。

## 测试版本

- 固定底座：a61b的 `7ca52c9dd57bfc04d97e7ed2261fd802cdff9d97`。
- 在主目录 `sim_build/board_diag_20261009/` 解出独立副本；不修改a61b/6e70，不覆盖main RTL。
- `tools/scripts/prepare_board_diag.py` 产生 `diagnostic_v3`：加入诊断观察、UART连续样本回传、数字逐指命令。
- `BOARD_DIAG=1` 禁用未接线的物理RC输入，`FINGER_EXPR=1` 启用逐指数字表达；输出仍为真实FPGA合成。
- 本轮新发现：`note_map` 的复位分支没有清 `gact/gtab`。诊断版本增加清活动位与组表；
  复位前留一个活动音的新测试修前FAIL、修后PASS。此修复尚未合入main或a61b。
- v1/v2尝试与旧底座部分回归均保留，最后验收必须指向v3，而非复用旧码流结果。

## 接口（只适用于本诊断码流）

写仍为 `[地址][数据]`；普通回读写 `[0x0F][地址]`，回复 `[地址][数据]`。
原产品控制寄存器保留。高地址诊断写不进入原128字节参数银行。

| 地址 | 用途 |
|---|---|
| 写80=1/3 | 采集2048个24位样本：1是效果前，3是效果后；采集期间再触发忽略 |
| 读80 | bit0忙、bit1有效、bit2效果后来源 |
| 读81/82 | 已采样数，低字节在前；完成应为2048 |
| 写81/82 | 单个样本读取索引低8/高3位 |
| 写83 | 锁存当前事件计数、活动声部、样本计数、逐指表达状态 |
| 读83/84、85/86、87/88 | 接收确认数、on数、off数；16位计数，可回绕 |
| 读89–8C | 活动声部32位快照，不等于仍有释放尾音 |
| 读8D–8F | 样本计数低24位快照 |
| 读90/91、92/93 | 采样使能最短/最长时钟周期，应为512；这是内部计数，不是外部电气测量 |
| 读94–97 | 表达使能位图；note-off后可保留尾音最后音高，因此不等于手指所有权 |
| 读9C/9D | 最近一次分配/释放提交的组与音符 |
| 读9E/9F | 公共队列级别、note_map忙 |
| 读A0/A1/A2 | 指定样本24位低/中/高字节，二进制补码 |
| 回读A8 | 特殊连续回传：先回复A8标记，再2048×3个原始字节；期间不能插入其它回读 |
| 读A4/A5/A6/A7 | 身份D2、诊断版本1、BCK分频16、采样容量/256 |
| 写B0/B1 | 触点ID、声部组 |
| 写B2/B3 | 12位有符号位置低8/高4位 |
| 写B4=0/1/2 | 绑定、移动、撤销所有权；不代替note-on/off |

本诊断接口不是正式协议升级，不把原产品版本0x10当作已包含诊断能力；主机先检查D2身份。
没有触控器件时，触点由主机明确绑定。这不证明真实多指身份追踪或触摸到声音延迟。

## 验证分层

1. 新诊断接口真实UART线仿真：回读、参数不串写、计数、逐指、样本完成、跨样本字节顺序、带活动音复位。
2. 对v3源码运行完整 `regress_all.py --full`；已知失败与INFO分别报告，新增诊断仿真单独报告。
3. v3 Gowin综合/PnR、器件/引脚核对、资源和setup/hold/TNS复核，码流与源码指纹绑定。
4. SRAM下载同版码流，USB UART真实写读、音符覆盖、32声部/抢占/回收、随机事件、数字样本、逐指移动、力度、预设、效果和定序器。
5. 无仪器项目继续标未验：DAC/功放/扬声器、WS/SD相位与电平、触控量程/身份、最坏10ms、真实听感。

`tools/scripts/test_board_hardware.py` 的PASS只涵盖具体断言，不是产品无风险保证。
音频样本来自FPGA内部，不是模拟设备或电脑合成，也不是从DAC模拟输出采集。
诊断增加资源和观测逻辑，结果不自动证明未加诊断的最终产品码流。
