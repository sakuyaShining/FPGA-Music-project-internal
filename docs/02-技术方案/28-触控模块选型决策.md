## 0. 决策记录（2026-10-05）

**已定：走 B 路线（定制 PCB 面板）。**

配套决定：

| 项 | 决定 |
|---|---|
| 原型 | **仍要做，但缩减为"必做五项"**：芯片能否读、有无 IRQ、模拟量动态范围、重复性、轮询周期 |
| 可延后 | **邻键串扰**留到 PCB 上量（PCB 的接地网格远优于手工走线），但板上须**预留每通道测试焊盘** |
| 最关键的两项 | **芯片能否读**与**有无 IRQ**——它们决定板上是否要额外走线，走错就要重打 |
| 省时的做法 | 若模块自带焊盘，直接手指按模块焊盘即可，无需先做电极；用硬币/铜箔加大接触面积 |
| 并行安排 | 原型 1 晚 → 画板 1–2 天 → 打样 3–7 天；**打样期间做软件**（I²C 驱动、音高接入、判据重建） |

执行细则见《29-触控原型验证程序.md》。

## 1. 结论摘要

| 定位 | 方案 |
|---|---|
| **原型验证（现在）** | 现成触摸模块 + 手工触点：先回答"模拟量能不能用" |
| **主力方案（推荐）** | **定制 PCB 面板 + 12 通道控制器芯片（4 片）**，芯片用打样厂的 SMT 贴片 |
| **值得评估** | 标准电容触摸屏：连续二维坐标，但面板尺寸与接口受厂家约束 |
| **不推荐** | 纯开关量方案（如 TTP229）：拿不到模拟量，表情层直接做不了 |

一句话：**触点是 PCB 上的铜，芯片贴在同一块板上**——这是商用触摸面板的做法，也是可靠性问题的根治方案。

## 2. 三条路线对比

| | **A 现成模块 + 手工触点** | **B 定制 PCB 面板** | **C 标准电容触摸屏** |
|---|---|---|---|
| 电极 | 铜箔/洞洞板手工贴 | **PCB 蚀刻铜焊盘** | 厂家 ITO 玻璃 |
| 触点一致性 | 差（面积/胶层各异） | **高（蚀刻精度）** | 高 |
| 串扰控制 | 靠手工接地线 | **接地网格画进板** | 厂家已解决 |
| 芯片质量 | 克隆风险 | **正规渠道 + SMT 贴片** | 厂家保证 |
| 触控形态 | 12 路离散 | 38 路离散 + 模拟量 | **连续二维坐标** |
| 力度/触后 | 待实测 | 待实测 | **通常拿不到**（只上报坐标） |
| 连续位置（ribbon） | 不可行 | 需多片插值，精度有限 | **天然可行** |
| 几何自由度 | 完全自由 | **完全自由**（画板即定） | **受厂家面板尺寸限制** |
| 成本估算 | 模块 ~¥50 | 打样 ~¥30–80 + SMT ~¥50–150 | 屏 ~¥50–150 |
| 工期 | 立刻 | 画板 1–2 天 + 打样 3–7 天 | 到货 1–3 天 |
| 主要风险 | 可靠性 | **几何必须先冻结**（改板要重打） | 接口协议 + 尺寸锁定 |

## 3. 器件候选（【待核对】）

| 器件 | 通道 | 接口 | 模拟量 | 滑条/位置 | 备注 |
|---|---|---|---|---|---|
| **MPR121** | 12 | I²C，4 地址 | **10 位滤波值** | 无 | 老型号但便宜、模块多；项目早期审计推荐过 |
| **AT42QT2120** | 12 | I²C | 有信号强度 | **支持滑条** | 12 通道 + 滑条，比较对口 |
| **CAP1188** | 8 | I²C / SPI | 有 | **支持滑条** | 通道偏少，自带 LED 驱动 |
| **CY8CMBR3xxx** 系列 | 最多约 16 | I²C | 有 | 部分型号有 | 自校准成熟，工业级 |
| **TTP229** | 16 | I²C / 并口 | **无** | 无 | 只有开关量 ⇒ **排除** |
| 触摸屏控制器（GT911 / FT6236 等） | 电容屏 | I²C | 坐标 | **连续坐标** | 属路线 C |

**通道预算**：38 个触点 ⇒ 12 通道的器件需要 **4 片**（48 路）⇒ 正好用满 4 个 I²C 地址，**没有余量**。

## 4. PCB 面板设计规则

电容触摸 PCB 的通行做法（**具体数值对照所选芯片的应用笔记确认**）：

| 项 | 做法 | 原因 |
|---|---|---|
| 电极形状 | 圆角矩形/圆形，**阻焊覆盖 + ENIG** | 手指透过阻焊耦合，耐磨耐氧化 |
| 电极尺寸 | ≥ 12–15 mm | 接触面积与重复性 |
| 电极间距 | ≥ 3 mm | 降低邻键耦合 |
| **电极周围与之间** | 铺**接地的网格铜**（不是整块铜） | 抑制串扰最有效的一招 |
| 背面 | 整层**接地平面** | 稳定参考 + 屏蔽下方走线 |
| 走线 | 短、细、彼此拉开、避开电极正下方 | 减少寄生电容差异 |
| 串联电阻 | 每路串一个小电阻（阻值查手册） | 抑制噪声 |
| 连接 | 面板用**排针或 FPC**接开发板 | 可插拔，便于调试 |
| LED | 音域条 5 颗的焊盘与走线一次画进去 | 避免二次改板 |

## 5. 最小原型验证清单（画板前必须回答）

用**一片现成模块 + 5 个手工触点**，一个晚上即可完成：

| # | 要回答的问题 | 为什么关键 | 判据 |
|---|---|---|---|
| 1 | 轻碰 vs 实按，读数差几档 | 决定力度/触后能不能做 | 至少能稳定区分 4 档 |
| 2 | 同一力度重复十次，散多大 | 决定它是否"可控" | 极差 < 1 档 |
| 3 | 相邻键被按，本键漂多少 | 决定滑音/和弦可不可信 | 漂移小于档距的一半 |
| 4 | **采样率**（全通道轮询一圈的周期） | 滑音与力度的瓶颈 | ≥ 数百 Hz 才能做细滑音 |

## 6. 选型判据（决策树）

```
原型实测：模拟量稳定、可分 4 档以上？
├── 是 → 走 B（PCB + 12 通道芯片），表情从"怎么按键"来（力度/触后）
│         └── 若还需独立连续轴 → 加拇指条或脚踏
└── 否 → 表情改由显式通道提供
          ├── 要连续位置 → 评估 C（触摸屏）
          └── 只要几档   → B + 拇指条 / 脚踏，力度用固定值
```

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 克隆芯片质量不可控 | 走 PCB 路线时用正规渠道芯片 + SMT 贴片 |
| 采样率不足 | 原型阶段先测；不足则滑音只做"键间跳变 + 引擎平滑" |
| 改板要重打 | **几何先冻结**：原型验证通过后再画正式板 |
| 4 片地址用满、无余量 | 需要更多通道时改用支持滑条的多通道器件，或分两条 I²C 总线 |
| 模拟量受湿度/邻近手指影响 | 阈值与档距留足余量；必要时只用"档"不用"连续值" |
