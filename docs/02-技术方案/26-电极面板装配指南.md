# 电极面板装配指南

> ⚠️ **本指南是"最终形态"的设计参考，不是"现在就照做"的施工令。**
> 音高与八度规格尚有 4 项未定（泛音键数量、音域条几何、板载按键用途、是否加第三排），
> 触摸控制器驱动也仍在开发中。
>
> **在收到"布局冻结"通知之前，只做原型验证：一片控制器 + 下排 12 键**，
> 目的是回答"手工铜箔 + 触摸控制器这条路走不走得通"，而不是做出成品面板。
>
> 本文的尺寸、编号与分配表都是**冻结后的目标**，现在照做会白做。

## 1. 前置条件与分工

| 项 | 说明 |
|---|---|
| 开发板 | Tang Nano 20K（芯片必须 GW2AR-LV18QN88C8/I7） |
| 触摸控制器 | MPR121 模块 ×4（12 通道/片，须能设不同 I²C 地址） |
| 工具 | 电烙铁、焊锡、万用表、剪刀/美工刀、尺子、细铜线、导线 |
| 建议阶段 | 先做**一片控制器 + 下排 12 键**跑通，再扩到四片。不要一次焊满 38 个点 |

## 2. 面板尺寸与布局

触点命名规则（**接线与排查全靠它，务必按此编号**）：

| 编号 | 数量 | 内容 |
|---|---|---|
| A1 – A12 | 12 | 下排音高：C3 → B3 |
| B1 – B12 | 12 | 上排音高：C4 → B4 |
| C1 | 1 | 独立高音 C5 |
| S1 – S5 | 5 | 音域条（−1 / 0 / +1 / +2 / +3） |
| H1 – H8 | 8 | 泛音 1 – 8 |

建议尺寸（依据规格第 11 节的电容触摸几何约束）：

| 项 | 建议值 | 说明 |
|---|---|---|
| 单个触点 | **15 mm × 40 mm** | 手指接触面积与重复性 |
| 触点间距 | **≥ 3 mm** | 减少邻键耦合 |
| 触点间隔离 | **每个触点之间铺一条接地细铜线** | 显著降低串扰；这是电容触摸的标准做法 |
| 两排音高键间距 | **≥ 25 mm** | 避免手指悬停误触另一排 |
| 音域条触点 | 20 mm × 30 mm，5 格并排 | 与音高键拉开距离 |
| 面板总尺寸 | 约 **250 mm × 220 mm** | 可放在 20×30 cm 亚克力板上 |

布局示意（俯视，非等比）：

```
        ┌─ 音域条 S1 S2 S3 S4 S5 ─┐        ┌ 泛音 H1..H8 ┐
        │  (顶部，手掌活动范围外)  │        │ (右侧或下缘) │
┌───────┴─────────────────────────┴────────┴──────────────┐
│  上排   B1 B2 B3 B4 B5 B6 B7 B8 B9 B10 B11 B12      C1  │
│                                                          │
│        (两排之间 ≥ 25 mm 空隙)                            │
│                                                          │
│  下排   A1 A2 A3 A4 A5 A6 A7 A8 A9 A10 A11 A12          │
└──────────────────────────────────────────────────────────┘
```

## 3. 触点 → 通道 → 音符 分配表

| 触点 | 通道 | 音符（档位 0 时） | 所在控制器 |
|---|---|---|---|
| A1 – A12 | 0 – 11 | C3(48) → B3(59) | 第 1 片 |
| B1 – B12 | 12 – 23 | C4(60) → B4(71) | 第 2 片 |
| C1 | 24 | C5(72) | 第 3 片 |
| S1 – S5 | 25 – 29 | 不发声（音域档 −1/0/+1/+2/+3） | 第 3 片 |
| H1 – H6 | 30 – 35 | 不发声（泛音掩码 bit0–5） | 第 3 片 |
| H7 – H8 | 36 – 37 | 不发声（泛音掩码 bit6–7） | 第 4 片 |
| （余量） | 38 – 47 | 预留 | 第 4 片 |

**控制器划分**：第 1 片 = 下排 12 键；第 2 片 = 上排 12 键；第 3 片 = C1 + 音域条 + H1–H6；第 4 片 = H7/H8 与余量。

这样划分的好处：**只装第 1 片就能先弹一个八度**，可以分阶段验证。

## 4. 接线表

### 4.1 触摸控制器 ↔ 开发板

| 控制器引脚 | 接到 | 说明 |
|---|---|---|
| SDA（四片并联） | FPGA **48** | I²C 数据 |
| SCL（四片并联） | FPGA **77** | I²C 时钟 |
| VCC（四片并联） | 开发板 **3.3 V** | 【待确认】3.3 V 在 40P 排针上的具体位置，请看板子丝印/官方原理图 |
| GND（四片并联） | 开发板 **GND** | 【待确认】同上；**必须共地**，否则读数会漂 |
| ADDR（每片不同） | 按模块说明设成 0x5A / 0x5B / 0x5C / 0x5D | 【待确认】模块上 ADDR 是焊盘还是跳线 |
| 通道 IN0–IN11 | 各自的触点 | 按第 3 节表格接 |

### 4.2 上拉电阻

SDA 与 SCL **各接一个 4.7 kΩ 上拉到 3.3 V**（在靠近控制器的一端接），缺了上拉通常表现为完全读不到器件。

### 4.3 触点引线

- 每个触点焊一根细导线，**长度尽量 ≤ 15 cm**
- 引线**远离**时钟（27 MHz 晶振）与 I²S 三根线，避免噪声耦合
- 所有引线在面板上走线整齐，用扎带或胶固定，避免拉动时扯断焊点

## 5. 分阶段装配与检查点

**每阶段做完先测，再往下做。**一次焊满 38 个点，出错时无法定位。

| 阶段 | 做什么 | 检查点（该看到什么） |
|---|---|---|
| P1 | 只做下排 A1–A12，接第 1 片控制器 | 用 `dsp_host.py padmon` 逐通道能读到变化 |
| P2 | 加上排 B1–B12 与第 2 片 | 两片地址不同，互不干扰 |
| P3 | 加 C1、音域条 S1–S5、第 3 片 | 音域条换挡有 LED 指示、且换挡不产生音符事件 |
| P4 | 加泛音 H1–H8、第 4 片 | 摸任一泛音键，对应泛音电平变化（可用上位机观察） |
| P5 | 全键盘功能验证 | 按《音高与八度规格》P1–P15 逐条通过 |

## 6. 装配类常见错误与后果

| 错误 | 现象 | 排查 |
|---|---|---|
| 相邻触点被焊锡/铜箔短接 | 两个音同时响，或一个键怎么按都没反应 | 万用表通断档量相邻触点 |
| 忘记上拉电阻 | 完全读不到控制器 | 量 SDA/SCL 空闲时是否为高电平 |
| SDA 与 SCL 接反 | 读不到或读到乱码 | 对照第 4.1 节 |
| **未共地** | 读数随手指远近乱漂，时好时坏 | 量控制器 GND 与开发板 GND 是否导通 |
| 引线过长且靠近时钟线 | 偶发误触或丢键 | 缩短引线、远离 I²S/晶振 |
| 触点之间没有接地隔离 | 按一个键旁边的键也被触发 | 补铺接地细铜线 |
| 四片地址设成相同 | 读到的数据互相打架 | 逐片单独接，确认地址后再并联 |
| 铜箔被烙铁烫穿 | 接触不良、时好时坏 | 焊点用导线压住铜箔边缘，避免长时间高温 |

## 7. 装配完之后

接着走 `16-板卡bringup一页卡片.md` 的三段流程：

1. **段一**：只验硬件（官方码流出声）
2. **段二**：只验数字通路（我方码流 → LED 心跳 → 串口遥测）
3. **段三**：验输入（本文装好的面板 → 触摸/RC 实测 → P1–P15）

## 8. 待确认清单（焊之前必须落实）

1. 开发板 40P 排针上 **3.3 V 与 GND 的具体引脚位置**（看丝印或官方原理图）
2. 板上**有没有喇叭/扬声器焊盘**（决定要不要外接小喇叭）
3. MPR121 模块的 **ADDR 设置方式**（焊盘/跳线），以及是否支持 0x5A–0x5D 四个地址
4. **48 / 77 两个排针是否空闲**（I²C 要用它们）——按当前约束文件是空闲的，但仍以实物为准
