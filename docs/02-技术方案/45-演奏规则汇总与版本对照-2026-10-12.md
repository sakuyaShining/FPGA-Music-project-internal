## 2. 不变的设计思想

1. FPGA 逐样本实时生成声音，音频生成不依赖电脑。上位机负责编辑、测试、管理与备用输入。
2. 音符身份、基础音高、临时音高表达、力度/激发、音色和包络分别管理，不能因修改其中一项而无意重置其他项。
3. 统一支持持续、瞬间和混合激发语义，由乐器预设决定；不要求在截止前实现所有声音模型或准确复刻所有传统乐器。
4. 首个声音后端沿用 TDM 加法合成。以后扩展其他后端时复用事件和状态接口，不作为本轮交付前置条件。
5. 右手保留泛音构造的核心功能；精细基础谱编辑、实时修饰和草稿提交在逻辑上区分。
6. 设计必须有对应硬件观测、采购渠道、连接方案、成本及验证方法。先验证最小实体链路，再扩展完整面板。

“通用”指同一状态和接口可表达不同预设的演奏行为，不表示任何输入器件都能提供逐指滑音、真实力或多点坐标。

### 3.1 琴键与八度档位

| 内容 | 当前规则 / 状态 |
|---|---|
| 布局 | 已有管风琴式布局为候选；具体图形、排数、键数需确认，不能仅凭名称认定等同 25 号布局 |
| 每键行为 | 落键创建音符，保持不重复触发，松键按身份释放 |
| 多音 | 支持独立音符与和弦，不按音号把所有来源合并 |
| 基础音域 | 已确认继续由原有八度档位控制 |
| 切换八度 | 沿用旧规则：落键时锁存基础音高，切档不重写已按住音符，只改变后续落键计算 |
| 释放 | 不用切档后的音号重新计算释放目标；应按创建时身份处理 |
| 原有数字 | 25 号曾规定五档 −1/0/+1/+2/+3、上电 0；完整音域及布局表有内部不一致，需随实际键位复核，不能直接作为已实现的验收表 |

### 3.2 每排音高滑条

已确认：一排内音符共同滑动，保持和弦内部音程；各排控制独立；松开滑条回到原音高。

逻辑关系为：

`实际音高（音分） = 落键时锁存的基础音高（音分） + 该排临时偏移（音分）`

偏移是相同音程或频率倍率，不能给所有音加相同 Hz。滑条不修改八度档位；正常滑动和归零不触发 NOTE_ON、不重启包络。往返移动形成该排共同的手动颤音，不要求自动 LFO 才能工作。

尚未确定：

- 滑条触摸落点直接决定偏移，还是落点作为零参考、后续相对位移决定偏移。
- 最大正负音程、死区、坐标/电压到音高曲线、更新及回归平滑时间。
- 滑条处于偏移时，新加入音符是否立即继承该排偏移。
- 已松键尾音是否跟随滑条；音符归属哪个排需保持稳定。
- 滑条缺失读数、断线、失效的安全恢复。

这些必须在可采购的滑条及真实读出能力上验证，不能直接沿用旧跨键 50ms 时间窗等参数。

### 3.4 激发与声音生命周期

| 策略 | 语义候选 |
|---|---|
| Continuous | 落键起音，按住持续驱动，松键进入释放 |
| Impulse | 落键一次激发，按住仍可自然衰减，松键按预设自由衰减或加速阻尼 |
| Hybrid | 起音瞬态与持续成分同时存在，松键停止持续成分并处理残留 |

普通音高变化不重新激发。RETRIGGER 如需使用，应为显式命令。三策略的统一接口是保留方向，截止前完整交付范围和最小 Hybrid 模型仍待定。

音符是否被手指/琴键拥有、是否仍发声、是否占用 Voice 必须区分。新设计候选默认不抢占仍由演奏者控制的声部；满员拒绝新音并反馈。尾音抢占/回收、静音 Impulse 归还资源、异常音符停止规则仍需裁定和验证。

| 八度档 | 沿用逻辑规则，具体输入器件未定 | 档位编码、确认/防误触、基础音高锁存与释放正确性 |
| 状态反馈 | 初期可用已有 LED 和遥测；小 SPI 屏为候选 | 最终脱机演奏需要足够状态反馈；显示更新不阻塞音符/音频 |
| 音频与供电 | 现有 I2S 合成路径；DAC 接线资料已有 | 板级时序、真实发声、电源/地/电平、扬声器与布线 |

普通滑动电位器松手后保持位置，单独没有“用户已松手”的观测，不能直接满足松手音高归零；额外触摸检测或回中结构必须计入装配和成本。

屏幕此前候选为 2.4–2.8寸、240×320、四线 SPI、3.3V IO 的成品模块，优先带 PCB/排针/完整资料；ILI9341 为研究对象，未冻结型号。用户截图中的 ¥29 裸屏没有形成已核验采购项。“标准40PIN”不代表可直插板卡。

此前讨论的状态区 20–30 次/秒局部更新仅是显示设计目标，不是全屏帧率保证。显示不进入演奏关键路径，完整显示可延后于实体发声闭环。

### 4.1 预算与采购资格

琴键采购进展（2026-10-12）：用户提出3D打印键体，传感未定。24号顶部新增小样候选：4–6个有触点线性机械轴、少量控制用轻触开关、按库存补连接材料，先打印单/双键适配件；FSR单键触后为可选独立实验。可以组织小样采购，不具备批量键盘BOM，尚未核国内到货价或执行购买。机械轴仅提供按放，霍尔测位移与真实力测量不可混同。

用户要求尽量控制在 ¥300 以内。此前低成本原型限额含运费；是否包括开发板、DAC、完整键盘和屏幕尚未确认。必须同时列“已持有可复用物料”和“新增采购”，不能先假设已有全部工具而承诺整机 ≤¥300。

本报告不提供新报价。39–44 号历史价格、国外标价和预算限额不等于当前国内到货价格；高额触控预算已被用户否决，不作为基线。

每个准备下单的候选必须具备：准确型号与数量、可核验渠道、现货/交期、接口资料、供电/电平、配套转接与读出电路、到货总价，以及对应实验。自制原型允许列为候选，但必须给出可组装的电路及加工材料。

## 5. 当前代码与验证状态

| 项目 | 可确认的现状 | 对新设计的影响 |
|---|---|---|
| 声音核心 | 有 32组×16分量、512时隙的 TDM 机制；27MHz、16×32分频关系对应 52734.375Hz | 可复用；本轮没有最新资源、时序和全量回归结论 |
| 音符分配 | note_map 按音号匹配，存在同音重触发及满员抢占 | 需适配按键来源/身份和新资源规则 |
| 输入通路 | 当前有16路电极扫描；连续坐标/逐音符更新未完整接入 | 新键盘和排滑条需要适配，不是买到即插即用 |
| 事件交付 | 38号审计复现 padfast：源产生2事件，只确认1，RESULT FAIL fails=2 | 必须先修复，不能沿用35号“事件通路已完成” |
| 力度和谱刷新 | 已有力度缩放、谱RAM、TILT；刷新未正确保留各声部原力度，并跳过释放尾音 | 需分离音高、音色、生命周期更新权限 |
| Voice 回收 | 释放立即标 FREE；无完整声音结束反馈 | 尾音可能被覆盖，不满足完整新生命周期目标 |
| 滑音 | 旧 glide 机制存在，正常 legato未按旧意图触发；没有新排滑条完整链路 | 不把自动声部抢占滑音等同用户滑条表情 |
| 颤音 | 当前有全局 LFO 路径 | 当前手动滑条颤音需接新偏移路径；无须先实现逐声部 LFO 才验证整排手动颤音 |
| 塑谱 | 当前加性叠加/触摸置满，可创造原本为零的分量 | 与此前乘性强调候选不同，需先确定右手操作语义 |
| 数值边界 | 最终调制后的分量防混叠仍有审计风险 | 高音、八度和滑条最大偏移组合必须覆盖 |
| I2C | 既有驱动有已登记失败 | 只有选定 I2C 输入候选后才形成具体接入任务；不能假设驱动已验收 |
| 板级与实体 | 本聊天未提供真实新前端/音频闭环验收证据，原型先前尚未开始 | 当前完成状态为未验收，不转换为软件仿真通过 |

关键证据：38号审计、src/rtl/note_map.v、src/rtl/tdm_top.v，以及 `sim_build/regress/audit_20261011_padfast/audit_result.txt`。既有日志是上一轮证据，本轮只复读，未新运行测试。

34号曾同时保留“释放不归还 FREE”和后续修正；当前源码已释放即归还。35号绑定旧提交且完成结论被38号重新审计，二者均作为历史证据索引，不再作为当前新设计闸口。

## 6. 截止前闭环：交付目标与验收

以下为建议工作计划，不代表团队工期承诺或用户已批准削减功能。完整 BOM 未闭合前，不能保证在预算和期限内全部完成。

优先交付目标：真实琴键 → 音符管理 → FPGA 实时合成 → I2S/DAC 发声，同时真实排滑条和右手泛音输入能在持续发声中独立操作，并具备可观察状态与安全释放。

| 闭环环节 | 应提供的证据 |
|---|---|
| 真实输入 | 多键和弦、按放事件、滑条位置及松手检测原始记录 |
| 八度与音符身份 | 切档不掐断已有音，旧音按原身份释放；同音不同来源独立处理 |
| 排滑条 | 同排和弦共同偏移并保持音程，不重起包络；松手归零；两排互不影响 |
| 右手泛音 | 所选输入动作明确对应谱变化，基础谱/修饰操作可辨，不重置音高或包络 |
| 事件和恢复 | 同时按放、快速重复、突发及故障恢复无不可恢复卡音；拒绝/溢出有记录 |
| 声音输出 | 真实DAC发声、复音、包络、至少所需音色及受控谱峰证明；I2S板级确认 |
| 延迟 | 分层记录输入/确认/处理/提交/音频输出及最坏总延迟；≤10ms要求不因未测而取消 |
| 构建与资源 | 对最终源码版本运行适当回归及综合/PnR，保存版本、报告与产物 |
| 脱机演奏 | 不依赖电脑实时发声；关键模式/档位/状态可辨，连续演示可重复 |

赛题约束以01-选题确认与约束条件及对应官方原文为依据。本轮没有重新核验官方全文。尤其应注意：该文M9记有力度感应要求，E2记有≥3维表情；暂缓真实力原型不能直接被报告为完整满足这两项。滑音和手动颤音来自同一音高输入，不能未经核验便声称是两个独立可控维度。闭环验收还要核对最终交付与赛题逐项对应，而非只判断能发声。
