# 混响 Freeverb-lite 设计契约与验收判据

> 2026-10-02 · 起草，用户已拍板选型 Freeverb-lite。
> 本文是**实现契约**（按 §1–§3 施工）+**验收判据**（按 §4 逐条断言）。
> 实现位置建议：`src/rtl/fx_reverb.v`（新文件，不动 fx_delay.v），在 tdm_top 湿声支路并联挂接。

---

## 1. 结构（Freeverb 原版缩放）

```
输入 ──┬────────────────────────────────→ 求和 ──→ 湿声增益(右移) ─┐
       ├→ 8×梳状(并联, 阻尼低通在反馈环内) ─→ 求和 ──┘              ├→ 饱和 → I2S
       └→（干声走既有零延迟旁路, 结构不变）                          │
            8 梳求和 → 4×全通(串联) ───────────────────────────────┘
```

-**8 个并联梳状**：`y[n] = x[n] + damp·fb[n] + ...`（标准 Freeverb 梳状：延迟线 + 反馈环内一阶低通阻尼）。
-**4 个串联全通**：`y[n] = -x[n] + d[n] + g·(d[n-1] - y[n-1])`，g 固定 0.5（右移 1，零 DSP）。
-**全部系数用移位加法**（阻尼 damp、反馈 fb 取 2 的幂或 `y += (x-y)>>k` 形式）→**DSP 占用 = 0**。
- 预延迟（可选）：直接复用延迟线头部 N 样本，寄存器 0x50。

## 3. 寄存器映射（沿用 UART 通道，地址避开 0x40–0x4F）

```
0x51  RV_CTRL    [0]混响开关 [3:1]湿声增益(1/2^n)
0x52  RV_ROOM    反馈系数 fb（2 的幂档）
0x53  RV_DAMP    阻尼系数（2 的幂档）
0x54  RV_PREDL   预延迟（样本，低 8 位；高 8 位留 0x55）
```

## 4. 验收判据（执行，仿真冲激响应法，逐条数值断言）

| # | 判据 | 通过标准 |
|---|---|---|
| V1 |**旁路等价**：混响关（含延迟/合唱也关）时顶层输出 | 与引擎输出 2000+ 样本**逐位相同**（扩展现有 E4-bypass） |
| V2 |**T60 逐档**：冲激响应能量衰减曲线（Schroeder 积分）到 −60 dB 的时间 | 每个 RV_ROOM 档实测 T60 与理论 `T60 ≈ 6.91·Ts/(1−fb)` 误差 < 10% |
| V3 |**回声密度增长**：冲激响应前 200 ms 内脉冲累计数 | 单调增长；1 个梳状周期内 ≥8 个脉冲（8 梳交错生效） |
| V4 |**高频先死**：分频段（<2kHz vs >6kHz）分别测 T60 | RV_DAMP 最大档时 高频 T60 < 低频 T60（差 ≥20%） |
| V5 |**无溢出**：满幅正弦持续输入 5 s | 输出无回绕（不出现符号翻转尖峰）、饱和逻辑生效 |
| V6 |**全量回归**| `regress_all.py` 全绿（含 R0 0/2495） |
| V7 | 综合 | BSRAM ≤14、DSP 不增、**SETUP slack 修复 note_map 后 ≥ +5 ns**（前置条件） |
