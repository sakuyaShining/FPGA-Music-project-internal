## 1. 双屏和合屏的实际区别

| 项目 | 双屏：7英寸推子＋独立可视化小屏 | 合屏：一块7英寸固定分区 |
|---|---|---|
| 同时可见 | 两者各占完整显示区域，手指遮挡主要限推子屏 | 可以同时显示，但必须在800×480内分配区域；切页不满足本轮偏好 |
| 推子行程 | 右手可使用约154×86mm有效区，留边后确定行程 | 上下各半时推子区仅约43mm高；左右分区则压缩8组推子的横向间距 |
| 可视化面积 | 小屏320×240，可单独选择更易读的模块尺寸 | 可给更多横向像素，例如800×240，但“像素更多”不等于手势和图形都不缩小 |
| 视线与遮挡 | 视线在两屏间移动；可把可视化放上方，避免手遮挡 | 视线集中，但布局需防手掌挡住图形，图形和操作共同抢面积 |
| 驱动与总线 | 保留ILI9341驱动，增加RA8875事务协议；SPI需公平仲裁 | 可统一显示事务，但仍要移植三视图渲染，不能只删除旧模块 |
| GPIO | 本轮17脚＋返回线选择器候选；I²S另复用既有3输出 | RA8875不需外置DC，删除小屏CS/DC后，在同一架构下可释放2个脚；读回路径重新布局后还可能不需选择器 |
| FPGA资源 | 保留原小屏像素渲染器，单板路由压力仍在 | 可能用命令渲染替代旧渲染器；FFT/波形/轨迹数据仍需要。净节省必须实测 |
| 成本与装配 | 多一屏、线缆、支架/开孔；最新库存记录不允许把小屏按免费已有计 | 少一屏和连接，但增加大屏布局/渲染移植工作 |
| 故障影响 | 单屏故障通常影响一部分功能，但共享电源/总线仍可能关联 | 显示或触控模块故障可能同时影响观察和操作 |

“合屏”不等于必须切页；本次只保留同时显示的固定分区方案。若今后合屏，先用1:1纸样验证推子有效高度、8组宽度、视觉字号与手掌遮挡，再评价是否达到同等演奏体验。

**用户已选择继续双屏；资源优化在保留双屏的路径上评估。** 87号建议的合屏节省−1657Logic未有新综合支持，不能以此替用户撤掉独立可视化。

## 4. RA8875接口发现与双屏17脚候选

[RAiO RA8875原厂数据手册镜像](https://cdn-shop.adafruit.com/datasheets/RA8875_DS_V12_Eng.pdf)的4线SPI时序明确区分数据写、数据读、命令写、状态读，命令/数据选择编码在SPI前缀。**它不沿用ILI9341的外置DC脚。**

绘图控制寄存器DCR[7]用于判断线/矩形绘制完成；STSR另有显存/BTE忙状态。不能只轮询某一个“忙”位就覆盖所有操作，也不能无读回、无最坏等待依据地连续发图形命令。

因此修正88号“不能接MISO、两屏只能写”的假设。双屏候选：

```text
RA8875 MISO ── I0 ┐
                 │ 74LVC1G157 ── Y ── Nano封装28 / J6-9
74LV165 QH ─── I1┘
RA8875 CS_N ── S
```

S=0选RA8875，S=1选按键移位寄存器；[Nexperia功能表](https://assets.nexperia.com/documents/data-sheet/74LVC1G157.pdf)支持该映射。候选**74LVC1G157GV,125 / C503437**，3.3V供电；精确封装/生命周期/可替代型号在原理图前继续核。不得直接将两路推挽输出并接。

- 共用原INPUT_DATA，不新增面板GPIO，保留TP_INT和六路SENSE。
- 小屏DC仍由封装20/J6-16输出，改名LCD_VIS_DC；大屏不接这个DC。
- SPI时钟空闲/采样模式、CS和选择器传播延迟、读回建立时间需驱动和模型验证。
- 每次读按键前重新LOAD快照；大屏传输期间165可以被共享时钟移位，其输出被选择器隔离。
- 所有扫描锁存控制字只在屏幕CS无效时发送，且保存复位位；不能把图像数据锁存到595输出。
- 忙轮询应按有界短事务释放SPI，不长时间占住总线；RC扫描与触摸处理优先级要有饥饿/超时判据。

这只是接线候选、功能表及引脚不重复检查通过，尚未画入原生工程、未做驱动/PnR/电气签收。完整表见`hardware/reselection-20261019/nano-io-candidate.csv`。

## 5. AUX引脚已逐图确认可复用

本次按PDF技能逐图查看[Sipeed 3921 Rev1.30原理图](https://dl.sipeed.com/fileList/TANG/Nano_20K/2_Schematic/Tang_Nano_20K_3921_Schematics.pdf)第2页：

| 信号 | FPGA封装 | 实际排针 |
|---|---:|---|
| I²S BCK | 56 | **J5-7** |
| I²S DIN | 54 | **J5-8** |
| I²S LRCK | 55 | **J5-11** |

因此在对应板版本上，可在载板从J5把现有I²S分送到PCM5122的输入，保留MAX98357A；无需生成另外三路FPGA音频端口。**88号的结论方向可行，本轮补上了排针依据。** 这不等于用户实板版号、负载/边沿/串阻和布线已验证。

I²S的FPGA输出不能与DAC主模式输出相接；PCM5122的BCK/LRCK必须保持输入。喇叭差分输出也不接3.5mm AUX。DAC的3.3V模拟/数字供电、去耦、电荷泵、输出RC、插座接地及上电静音仍需单独原理图，不把板上3.3V余量当已足够。

## 6. PCM5122时钟候选已经精确计算

依据[TI SLAS763C](https://www.ti.com/lit/ds/symlink/pcm5122.pdf)的可编程PLL、分频、FSSP/IDAC寄存器，保留现有fs和32BCK时隙，候选如下：

| 项目 | 本轮结果 |
|---|---|
| fs / BCK | 52,734.375Hz / 1,687,500Hz |
| PLL | BCK参考，P=1、J=24、D=0、R=2 → **81MHz**，落入VCOM整数PLL区间 |
| DSP / IDAC | 除4 → 20.25MHz；384周期/采样，IDAC=0x0180 |
| DAC调制 / OSR | 除24 → 3.375MHz=64fs；再除4 → 843750Hz=16fs |
| 电荷泵 | DAC时钟除2 → 1.6875MHz |
| 速度模式 | **Double speed**，因为48kHz < fs ≤96kHz；不能照48kHz表默设Single speed |
| 插值 | Program2低延迟插值候选，至少256周期，384周期满足这一数字条件；音乐运算仍在FPGA |

本轮计算并独立解码了导出的20项寄存器字段，PLL/分频/IDAC、速度位和16位I²S均与算式一致。导出表为`pcm5122-clock-fields.csv`。

**这不是完整上电初始化程序，也没有证明实体DAC已工作。** 还需完成MODE/地址引脚、待机/软静音、Clock Flex解锁、禁止自动分频、无外部SCK时的错误检测策略、PLL锁定读回/超时、帧同步/音频极性及解除静音顺序。当前表不写尚未验证的错误检测组合，尤其不通过屏蔽PLL失锁来冒充锁定。

I²C优先与参数存储、触摸共用3.3V总线；PCM5122七位地址范围0x4C—0x4F（资料中的0x98等是含R/W的地址字节），ADR引脚需显式绑值。上电DAC初始化应在进入实时演奏之前完成；EEPROM写入/ACK等待不得阻塞触摸。
