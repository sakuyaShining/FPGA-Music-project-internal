## 1. 这一版是什么

一台 **32 复音 × 16 泛音的加法合成电子乐器引擎**，全 FPGA HDL、逐样本实时生成，
经 I²S 输出到 DAC；有 38 通道电容触摸面板作为演奏输入（面板硬件尚在验证中）。

| 项 | 值 |
|---|---|
| 目标器件 | GW2AR-LV18QN88C8/I7（Tang Nano 20K） |
| 采样率 | **46875 Hz**（27 MHz ÷ 576；`BckDiv=16` ⇒ BCK 1.6875 MHz，BCK/LRCK=32） |
| 复音 | **32 组**（`NSLOT=512`，每组 16 个时隙 = 16 泛音） |
| 合成方式 | 加法合成（每泛音独立相位累加器 + 频率调控 + 包络） |
| 输出 | I2S（Philips 标准）→ MAX98357A；24 位内部、取高 16 位送 DAC |
| 控制 | UART 寄存器协议 v1.0（19 号文档 + 修正案 A1–A9）；另接触摸面板 |

## 3. 关键契约（这一版**定死**的行为）

### 3.1 音符归属与抢占（`note_map.v`）

| 动作 | 规则 |
|---|---|
| note-on | 优先级 = **同音重触发 > 空闲组 > round-robin 抢占** |
| 空闲判定 | `gtab[n] == FREE`（127） |
| note-off | 找在奏该音的组，写 `gate=0`（进入释放段，**不是硬停**） |
| ⚠️ **已知缺陷** | **note-off 只清 `gact`，不把 `gtab` 写回 `FREE`** ⇒ 32 组填满后空闲搜索永不命中，之后全部走抢占。**列在阶段 3**（见 33 复核记录二） |

### 3.2 事件接收

| 项 | 规则 |
|---|---|
| 优先级 | UART（`0x61` 写脉冲）> 定序器 > pads > 排针 |
| **pads 路径** | **不丢事件**（实测）：`pad_scan` 用 8 位待发位图 + `note_busy` 反压，推迟到 note_map 空再发，每次一个。判据 `17 evloss`：8 键同时按/放 = 16 条事件全对应 |
| ⚠️ **已知缺口** | UART `0x61` / 定序器 / 排针 `ev_*` 都是**单拍脉冲且不受反压** ⇒ note_map 忙（约 20 拍）时该次事件被忽略。**列在阶段 2**（见 33 复核记录 §3.3） |

### 3.3 亮度作用范围

| 项 | 当前 |
|---|---|
| `0x5C TILT` | **全局**（谱 RAM 与预设谱本身是全局的） |
| 生效时机 | 只在下一次装载时被读走 ⇒ 要经 `0x63` 刷新；**手势级**，不做音频级摆动 |
| 恒等点 | `0x70`（`reg_bank` 初值即 0x70；写 0 是"最暗档"） |

### 3.4 复位

| 项 | 行为 |
|---|---|
| `rst_n` | 清演奏状态（相位、包络、门），**不清参数寄存器** |
| 上电默认 | 静音、`preset 0`、`CTRL=0x02`、`0x6E=0`（力度→音色关）、`0x5C=0x70`（亮度恒等）、FX 仅干声 |
| 判据 | `09b vp7`（`RESULT vp7=PASS silent=1 regs=1 preset0=1`） |

### 3.5 滑音规则（本版明确写死）

| 方式 | 触发条件 | 本版状态 |
|---|---|---|
| **(a) legato** | 新音按下时旧音**仍在响** ⇒ 复用该组，写滑音初值 | ✅ 已实现且可运行时开关 |
| **(b) 滑动** | 手指不离开面板跨键、时间窗内连续 | ❌ **未实现**（等输入层；不做"同时猜和弦/连奏/滑动"） |

| I²S 标准接收器 | 逐位一致 0/99（滞后 2 字），正 68 / 负 132 | `tb_i2s_std.v` + `i2s_std_check.py` |
| **8 键同时按/放不丢事件、不挂音** | 16 条事件（8 on + 8 off）全对应 | `tb_evloss.v`（`17 evloss`） |
| GUI 自检 | **10/10 PASS**（exit 0） | `sim_build/gui/selftest_report.txt` |

**本版明确未覆盖**（不得当成已验）：

- **饱和（截顶）行为**：出货配置下 `sum_raw` 只用到 73%，从未进饱和区。
- **汇合点的事件丢失**：pads 有 `note_busy` 反压（已实测不丢）；而
  **UART `0x61` / 定序器 / 排针 `ev_*` 都是单拍脉冲且不受反压** ⇒ note_map 忙时被忽略。
  这一条尚无判据覆盖（阶段 2 的工作对象）。
- **板上一切**：I²S 电气、真实延迟、MAX98357A 群延迟、扬声器。
- **PnR 时序**：亮度轴乘法尚未重新综合；`+15.229 ns` 是加它之前的数。
- **长时稳定性**：从未跑过小时级仿真。
- **输入层模拟量**（力度/触后的传感器通路）：面板尚未验证。
