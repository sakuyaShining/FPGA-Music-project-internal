# 移交说明（硬件组装）

> 给负责采购与组装的队友。**先读这一页，再按下面的顺序看其它文档。**

## 1. 你要做三件事

1. **采购**：按《采购清单》下单，最急的是**开发板**（没有它什么都开不了工）
2. **做面板**：按《电极面板装配指南》裁铜箔、贴触点、接线
3. **上电验证**：按《板卡 Bring-up 一页卡片》一步一步走，每步都写了"该看到什么"

## 3. 你需要装什么

| 要装的 | 用途 | 备注 |
|---|---|---|
| **Gowin 编程器驱动** | 让电脑认到板子 | 装完设备管理器应出现 2 个 USB Serial Converter + 1 个 COM 口 |
| Python 3 | 跑上位机命令行工具 | 可选；只看串口遥测时需要 |
| Gowin IDE | **只有要自己重新编译时才需要** | 包里有现成码流，通常不用装 |

## 4. 怎么烧板子

包里的 `码流/tdm_synth.fs` 就是可以直接烧的文件。

| 项 | 取值 |
|---|---|
| 烧录方式 | **SRAM**（掉电即失、零风险；不要烧 Flash） |
| 下载频率 | **2.5 MHz** |
| Verify | **不勾**（勾了会极慢或失败） |
| 数据线 | 必须是 **USB-C 数据线**，充电线会让"灯亮但电脑认不到" |

⚠️ **SRAM 烧录掉电即失**：拔电就没了。演示或录像前必须重新烧一次。

## 5. 第一天走这三步就够

1. **只验硬件**：烧官方 audio 例程 → 扬声器出声（先排除线/驱动/板的问题）
2. **只验数字通路**：烧`码流/tdm_synth.fs` → **LED 心跳亮**（不用耳朵就能判断 FPGA 活着）
3. **连电脑读遥测**：`python tools/scripts/dsp_host.py --port COMx padmon`

后面才是面板、触摸控制器、音高验收。

## 6. 出问题去哪儿查

| 现象 | 查哪里 |
|---|---|
| 板子认不到 / 烧录失败 | Bring-up 卡片 §5 失败判读表 |
| 焊接后某个键不灵 / 相邻键互相触发 | 装配指南 §6 装配类常见错误 |
| 声音破音、音高不对 | Bring-up 卡片 §3 三个容易出事故的点 |
| 触摸控制器读不到 | Bring-up 卡片 §5 最后一行 |

## 8. 关于源码

包里包含完整源码（`src/rtl`、`src/sim`、`src/constr`、`tools`）。如果你要自己重新编译：

```powershell
powershell -File tools\scripts\build_gowin.ps1 -Project src\gowin\tdm_synth\tdm_synth.gprj -SspiAsGpio -PlaceOpt 2 -RouteOpt 2
```

改完代码要跑验收：

```powershell
powershell -File tools\scripts\accept_all.ps1
```

它会自动编译、跑回归、综合布局布线，并检查时序余量（低于 +5 ns 直接判红）。
