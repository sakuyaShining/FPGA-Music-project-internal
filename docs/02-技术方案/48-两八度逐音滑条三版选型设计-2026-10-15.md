# 两八度逐音滑条：三版选型设计

状态：**讨论中/待实现**。用户最新纠正是本稿范围依据：原两排逐音演奏布局覆盖两个八度，每个音位采用滑条，另设一条八度切换滑条；取消独立钢琴键结构，不改变为四条全音域条或单条多指。“三版”指同一产品需求的三版完整选型设计。

## 1. 三版共同产品规格

- 音高区：沿用两排逐音布局；触摸一个音位起音，在该音位滑动实现所属音的滑音/手动颤音，多指跨音位形成和弦。
- 八度切换：独立一条物理滑条，保留位置选择音域档方向；用户先前指定压力感应条，具体选型必须有位置/接触输出证据，不擅自改成仅二值触摸条或普通测力电阻。是否需要测量压力大小是另一能力，不从“压力感应”名称推定。
- 声音框架、四预设分层、实体编辑、右手已有泛音构造设计继续有效。右手全和弦修饰/松手保持等不因传感路线更改。
- 复用Nano20K、已有屏和喇叭；触点位置/身份与音乐算法由FPGA承担，不增加计算MCU。完整触摸到声音最坏≤10ms。
- 首版单个音位能否同时分辨两指尚无证据；按跨音位多指设计，不声称单条任意多指。左右手目标触点数不能等同25音位全按同时分层资源。

原39号§3及25号通道表为两排C3–B3、C4–B4加高端C5，共25音位。以此作可追溯计算基线；若最终每排都含独立高端C则26位，下面同时列增量，不擅自重裁用户“每排完整八度”的端点语义。

### 节点预算（电容路线候选）

每音位3电极仅为待验证几何候选：25位=75节点，26位=78节点。八度条若采用5个位置段会增加5个位置节点；如采用压力式模拟位置条，则另计ADC/接触检测而非5个电容节点。右手8组若采用3电极分区，则另加24节点，右手实体形态仍按原待定项，不因此冻结。

因此25位＋5位置段＋右手24节点的示例合计104；26位示例107。单个音位的电极数不是声部数，旧38个二值逻辑通道不能直接视为原始传感通道数。

## 2. 第一版：PCB电容滑条＋FPGA并行RC测量

**完整结构**：两排逐音PCB电极 → 分组模拟复用与外部RC/施密特整形 → FPGA原始计时、基线及插值 → 逐指事件/合成；独立八度条、右手、按钮和屏幕分别接入，不串入实时音频等待链。

核心候选：TI CD74HC4067M96 / C496123 / SOIC24-300mil；TI SN74LVC14ADR / C133541 / SOIC14。4067只切换信号，LVC14只整形，二者都不是位置传感器。设计采用明确外部阻值，不把FPGA弱上下拉当精密电阻。

**规模候选**：8组测量前端，各配1片16:1复用器，2片六路LVC14可提供8路整形并处理未用输入；128节点规划容量可容纳104/107节点例子。若八度条用模拟位置传感器，额外ADC/释放检测必须列料，不能因存在空闲电容地址就视为已接入。测量中公共充放电驱动与各路RC/保护拓扑须先原理图核对，未发布接线引脚定稿。

**时延预算**：各组同时扫描16地址，若希望一轮≤2ms，则每地址包含切换、放电、稳定和采样应≤125μs；两轮判断约4ms仅是采集规划。剩余时间分给事件/同步/音频及余量。RC/寄生/噪声实测不达标时不能维持达标宣称；不能通过减掉音位满足预算。

**制造**：定制FR4电极/载板，SOP类前端便于装配；传感区与测量前端尽量靠近，覆盖膜、手指接触面与地/屏蔽一起验证。先做少量相邻音位的可复用原型再扩两排；若正式板带实验区可减少独立打样次数，仍按嘉立创实际工艺与面积计价。

**500元判断**：三版中优先验证的预算方向，但尚未有完整国内报价及位置/噪声/延迟证据；不能标“已满足500元”。建议120元核心器件、100元PCB、50元装配、50元连接/阻容保护、30元覆盖固定、30元运费、60元其他整机控件、60元预备，共500元上限，八度条/ADC从这些项中真实扣除。

**主要缺口**：位置分辨率、静按漂移、跨音位多指独立、MUX串扰、功放/屏干扰、真实压力位置条供货、引脚和FPGA资源联合验证。

## 3. 第二版：PCB电容滑条＋多片原始CDC

**完整结构**：同样的两排逐音滑条电极 → 多片AD7147原始CDC并行测量 → FPGA读原始数据并自行定位/生成事件；八度条和右手不改变共同需求。

器件候选ADI AD7147ACPZ-1500RL7 / C207411 / LFCSP24(4×4mm)，SPI。AD7147-1才是I²C版本；具体内部自动校准/阈值路径需核对，FPGA使用原始CDC，不用器件触摸判断替代项目算法。

**完整规模**：75/78音高节点若每片最多6阶段，至少13片；如果5段八度也由CDC测，则80/83节点至少14片；再把右手24节点加入则104/107节点至少18片。以上是假设每节点一个转换阶段、按6阶段组织的保守计算，实际电极连接/序列需验证，不能把13个CIN输入当作13个同时完整结果。

**时延**：AD7147在decimation64时6阶段序列为4.608ms，12阶段为9.216ms。采用6阶段是为了保留系统余量，不代表触摸响应已验；滤波、完整电极帧、读回和判定都须计入。不能通过满12阶段减少芯片后仍用6阶段的时延数字。

**供货与成本**：已查公开页C207411有库存，10+为USD4.6571/片；13片芯片本身USD60.5423，18片USD83.8278，还不含板、八度位置条、装配、连接与运费。这是国际站参考，不是国内CNY报价。C456284是另一包装且缺货，不混用。

**500元判断**：相较少量滑条小样，此完整规模的芯片与QFN装配成本明显增加；当前不能作为约500元主选，除非实际国内报价及拓扑优化证明可行。不得裁音位、放宽10ms或外包算法以假装满足预算。

## 4. 第三版：逐音膜式位置条＋多通道ADC

**完整结构**：每个音位一条膜式位置电位器，按压接触后输出位置 → 多路采样前端/ADC → FPGA接触释放判定、位置滤波与音乐事件；另有一条专用八度位置条。

已核候选为Spectra Symbol ThinPot TSP-L-0050-103-3%-MP / C17239514 / 50mm行程，标准10kΩ、三端位置器件；位置输出不等于连续测力。ADC128S022系列或XADC128S022-XC C53026457只作采样候选，尚未完成完整模拟链和封装核对，不作为最终BOM。

**规模**：25音位＋1八度条=26条模拟位置传感器（26音位则27条）。8通道ADC至少4片可容纳原始位置通道，但额外接触/压力检测可能增加通道，MUX/缓冲、采样保持建立和释放浮空处理必须实际设计。右手保持原设计，不能拿同一个模拟输出区分同条多指。

**供货与成本**：C17239514当前公开页缺货，1+参考USD13.3441；仅25条音位传感器就是USD333.6025，另计八度条/ADC/板/装配。不把不同国产条或其他长度的低价当同料替代证明。

**500元判断**：此已核料号无法支持当前预算方向；该版本是现成位置传感器的完整对照方案，当前不推荐采购。若后续寻找国产定制替代，需要可核型号、有效行程、位置/释放输出、单价和原型证据，不能先承诺存在几元级等价件。

## 5. 同规格比较与选择建议

| 项目 | 第一版：FPGA RC | 第二版：多片CDC | 第三版：膜式条ADC |
|---|---|---|---|
| 两排/两八度逐音位置 | 保留 | 保留 | 保留 |
| 独立八度切换条 | 必须另落实位置/接触传感器 | 同左 | 专用位置条，亦需供货 |
| 触控音乐算法在FPGA | 是设计目标 | 原始CDC读回方式下是目标 | 是设计目标 |
| 全规模核心数量 | 例8片MUX＋2片六路整形 | 例13片CDC仅音高；加入其他节点更多 | 25条音位膜片＋至少4片8通道ADC，另八度条 |
| 500元方向 | 优先做有证据的小样 | 完整规模成本不利，未证明可达 | 已核进口条路线不适合 |
| 制造签收 | 未签收 | 未签收 | 未签收 |

建议优先第一版做可测原型，第二版为测量前端正式规格对照，第三版为膜式手感/现成位置元件对照。三版都描述完整原布局，不能把只有少量滑条的原型当成第二版完整机成本。
