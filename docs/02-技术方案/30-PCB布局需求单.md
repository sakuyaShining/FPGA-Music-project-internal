## 1. 这块板是什么

一块**电容触摸面板 PCB**：正面是 38 个触摸电极（手指按的地方），背面是 4 颗触摸控制器芯片、走线、连接器与接地平面。它通过一根排线接到 Tang Nano 20K 开发板，由开发板供 3.3 V 并读数据。

**它不负责**：发声、按键逻辑、LED 驱动逻辑（那些在 FPGA 里）。

## 2. 机械

| 项 | 要求 |
|---|---|
| 板框 | 约 **260 × 200 mm**（可按实际排版微调，长宽比不要变太多） |
| 板厚 | 1.6 mm |
| 层数 | **2 层**（成本与工期优先；正面=电极+网格，背面=地平面+器件+走线） |
| 安装孔 | 四角 M3 安装孔，中心距板边 ≥ 5 mm；另在板中央补 2 个，防止按压时板面弯曲 |
| 连接器位置 | 板**右侧或下缘**，朝开发板方向；标注引脚 1 位置 |
| 表面处理 | **ENIG**（沉金） |
| 阻焊 | 电极**覆盖阻焊**（不要开窗），其余常规 |

## 3. 电极（触点）几何

### 3.1 触点清单与编号（**必须丝印标出**）

| 编号 | 数量 | 对应功能 | 建议尺寸【待原型确认】 |
|---|---|---|---|
| A1–A12 | 12 | 下排音高 C3–B3 | 15 × 40 mm |
| B1–B12 | 12 | 上排音高 C4–B4 | 15 × 40 mm |
| C1 | 1 | 独立高音 C5 | 15 × 40 mm |
| S1–S5 | 5 | 音域条（−1 / 0 / +1 / +2 / +3） | 20 × 30 mm |
| H1–H8 | 8 | 泛音 1–8 | 15 × 30 mm |

- 电极间距 **≥ 3 mm**
- 两排音高键之间 **≥ 25 mm**
- 音域条布置在**顶部**，与音高键拉开距离（防手掌误触）
- 所有电极圆角处理（尖角处电容场集中，读数更抖）

### 3.2 电极周围与之间：**接地网格**

- 电极周围与电极之间铺**接地的网格铜**（hatch，网格线宽约 0.25 mm、间距约 1–2 mm）
- **不要用整块实心铜**包住电极——那会显著增加电极对地电容，降低灵敏度
- 网格必须通过多个过孔**良好接地**（每 10–15 mm 至少一个过孔）

### 3.3 背面

- 背面铺**整层接地平面**，但在**电极正下方**按制造常规做处理（避免电极对地电容过大）【具体做法请按所选芯片的应用笔记确定】
- 控制器芯片**不要放在电极正下方**，放在电极群旁边、背面的空区

## 4. 电气

### 4.1 触摸控制器

| 项 | 要求 |
|---|---|
| 数量 | **4 片**（12 通道/片，共 48 路，用掉 38 路） |
| 地址设置 | 每片 **ADDR 引脚按不同方式接**（0x5A / 0x5B / 0x5C / 0x5D），**布局必须包含这个跳线或焊盘** |
| 通道分配 | 第 1 片=A1–A12；第 2 片=B1–B12；第 3 片=C1+S1–S5+H1–H6；第 4 片=H7/H8+余量 |
| 去耦 | 每片 100 nF，紧贴 VCC 引脚；整板再放 1 个 10 µF |
| 串阻 | 每通道串一个小电阻到芯片【阻值对照数据手册】 |
| 器件选型 | 【待原型确认】**

### 4.2 I²C 总线

- SDA / SCL 从连接器走到四片芯片，**菊花链**，两端各 **4.7 kΩ 上拉到 3.3 V**（上拉放在面板板上，靠近芯片端）
- **SDA/SCL 必须远离电极引线与 LED 走线**，平行距离 ≥ 3 mm，必要时用地线隔开

### 4.3 IRQ 线（重要）

- **必须预留一根 IRQ 走线**：从第一片芯片的 IRQ 引脚（或四片 IRQ 的线与）到连接器
- 即使原型确认"用不上"，**也一定要走这根线**——漏了就是重打一块板
- 【待原型确认】四片 IRQ 如何合并（线与 / 各自独占到连接器）

### 4.4 测试焊盘

**每个电极通道留一个测试焊盘**（1.5 mm 圆盘，位于背面空区，丝印标注通道号）。

理由：邻键串扰要在真板上量，没有测试点就得靠探针戳芯片引脚。

### 4.5 音域条指示灯

- 5 颗 LED 的焊盘与限流电阻位置（建议 **1 kΩ**），
- **走线一并画好**（通到连接器），但**允许不焊**（v1 可选）
- 位置：每格旁边，便于辨认当前档位

## 5. 连接器与接口契约（**这是软硬件的分界线**）

建议 **2×8 = 16 针** 排针/排母（或同规格 FPC）：

| 引脚 | 信号 | 说明 |
|---|---|---|
| 1 | GND | |
| 2 | GND | |
| 3 | 3.3 V | 来自开发板 |
| 4 | 3.3 V | |
| 5 | SDA | 到开发板 48 脚 |
| 6 | SCL | 到开发板 77 脚 |
| 7 | IRQ | 低电平有效 |
| 8 | LED_S1 | 音域条第 1 格指示 |
| 9 | LED_S2 | |
| 10 | LED_S3 | |
| 11 | LED_S4 | |
| 12 | LED_S5 | |
| 13 | 预留 | S2 按键 / 脚踏（将来） |
| 14 | 预留 | |
| 15 | 3.3 V | 备用供电 |
| 16 | GND | |

**丝印必须把这张表印在连接器旁边**（调试时不用翻文档）。

## 6. 走线规则

| 项 | 要求 |
|---|---|
| 电极引线 | **尽量短**（≤ 15 cm 等效长度）；线宽尽量细；**不要走在电极之间** |
| 电极走线间距 | 相邻电极走线间距 ≥ 3 倍线宽，必要时用地线隔离 |
| 走线禁区 | **电极正下方与电极之间的网格区域不得走线**（除接地） |
| 时钟/音频 | 本板没有时钟与音频，但**如果将来从开发板引线过来，必须远离电极** |
| 过孔 | 接地过孔充足（见 3.2） |
| DRC | **零错误**；丝印不得压在焊盘上 |

## 7. 丝印要求（直接影响装配与调试）

1. 每个电极**必须标编号**（A1…A12 / B1…B12 / C1 / S1…S5 / H1…H8）
2. 连接器旁印**第 5 节的引脚表**
3. 板上印：板名、版本号、日期、四片芯片的地址标注（0x5A…0x5D）
4. 标注第 1 脚与板子方向（防止回装时装反）

## 8. 验收判据（这块板怎么算画对了）

| # | 判据 |
|---|---|
| 1 | 38 个电极齐全，编号与第 3.1 节表格**逐项一致** |
| 2 | 每个电极与相邻电极之间**都有接地网格**，且网格有足够过孔接地 |
| 3 | 4 片芯片的 ADDR 设置**互不相同**，且丝印标明 |
| 4 | IRQ 走线**存在**并通到连接器 |
| 5 | 每个通道**都有测试焊盘** |
| 6 | 连接器引脚定义与第 5 节表格一致，且丝印可见 |
| 7 | DRC 零错误 |
| 8 | 5 颗 LED 的焊盘、限流电阻位、走线齐全 |

## 9. 待原型确认的项（画板时先按建议值，回来再改）

| 项 | 建议值 | 确认后可能的变化 |
|---|---|---|
| 电极尺寸 | 15 × 40 mm | 若手感偏小/偏大，调尺寸 |
| 电极间距 | 3 mm | 串扰偏大则加宽 |
| 串阻阻值 | 【查数据手册】 | 按手册与实测 |
| 器件型号 | MPR121 或同类 12 通道 | 若无 IRQ 引脚则**必须换型号** |
| IRQ 合并方式 | 四片线与 | 按芯片能力定 |
| LED 是否焊接 | v1 可不焊 | 保留焊盘即可 |

## 11. 生成方式建议

- 工具不限（KiCad / 立创 EDA 等）
- **先用"单通道模板"复制**：把这一个电极+网格+走线做成可复制的单元，再阵列 38 次——比逐个画快得多，也能保证一致
- 画完先跑 DRC，再按第 8 节过一遍自检清单
