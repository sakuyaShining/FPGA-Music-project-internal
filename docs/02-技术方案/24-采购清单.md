### D. 接线与实施边界

建议资源分配为矩阵12个GPIO、独立前端UART2个GPIO、ADC SPI4个GPIO，共18个GPIO。现有CST的pad区域27–42及48/77可作为核对起点，尚未生成新顶层/CST并经官方原理图逐针复核。物理FPGA球号不是排针位置编号。

新增UART必须使用独立3.3V引脚；原69/70为板载USB桥连接，不把ESP32 TX并接到已被BL616驱动的RX线。ESP32外接端子按原理图确认电平和选择开关；不使用RS485/CAN端子冒充TTL UART。共享地，不直接并接两路5V电源。

通信候选460800baud、8N1，帧含版本、序号、触点数量、ID/X/Y、校验；最新状态可合并，但按放沿不可静默覆盖。完整五点帧须限制长度，实际UART读出延迟与触控刷新独立测量。GT911扫描周期不等于整机≤10ms，既有总延迟目标未验收。

采购表最终还需库存、预算口径及MCU分工答复；报价齐备后分配预算，不把支出上限冒充成交价。本页以下内容均为历史，不再用于首版采购。

## 到货后第一件事：核对引脚（防止约束对不上）

板子到手当天，**先别焊任何东西**，拿这张表和板子/官方原理图核一遍。我们的约束文件是按这些脚写的（`src/constr/tdm_top.cst`）：

| 信号 | 引脚 | 说明 |
|---|---|---|
| clk | 4 | 27 MHz 晶振 |
| rst_n | 87 | 板上按键 S1（低有效） |
| 板载按键 S2 | 88 | 预留（八度档/设定模式） |
| led[5:0] | 20 / 19 / 18 / 17 / 16 / 15 | 共阳，低电平点亮 |
| pa_en | 51 | MAX98357A 功放使能（高有效） |
| dac_din / ws / bck | 54 / 55 / 56 | I²S 三线 → 板载 MAX98357A |
| uart_rx / tx | 70 / 69 | BL616 USB 串口 |
| pad[0..15] | 27–42 | 40P 排针：16 路触摸电极 |
| 空闲排针 | 48 / 77 | 预留给 I²C 的 SDA / SCL |

核对的三个重点：

1. **40P 排针是否把 27–42 全部引出**（16 路电极全靠它）
2. **板上有没有喇叭/扬声器焊盘**（有则不必买小喇叭；没有则必须买）
