## 1. 物理层与帧格式

| 项 | 值 |
|---|---|
| 电气 | BL616 板载 USB 串口，引脚 rx=70 / tx=69，LVCMOS33，115200 8N1 |
|**写帧**| 两字节：`[addr][data]`，任意间隔可（uart_rx 两字节组帧）；一次写 = 一次寄存器生效 |
|**读帧（A3，已实现）**| 写入 `[0x0F][src_addr]`，FPGA 回传 `[src_addr][value]` 两字节 |
| 写入语义 | 全部经**待生效装载区**，下一个样本边界统一生效（D6：样本边界档） |
| 延迟账 | 双字节事件 @115200 ≈ 174 µs ≪ 10 ms |
| 复位语义 | 软复位（S1）后寄存器**保留**（已测 P4）；**断电丢失**——上位机重连后应重同步 |

## 2. 重排背景（历史记录）

本节记录 2026-10-02 重排前的问题；其中旧版 R 切片范围与默认值不再代表当前 RTL。
当前寄存器地址、默认值和读写方向以 §3、`regmap_baseline.csv` 及 `regmap_dump.py --check` 为准。

**复核 A1（重排的直接动机）**：死区默认值与活区**物理重叠**——
`0x30–0x37` 在默认表里是"泛音3=297618…"（旧 inc 数据），被 tdm_top 读作颤音/滑音/音色；
`0x40–0x57` 三重重叠（旧 inc / 效果器 / 混响）；`0x70–0x73` 四重重叠（旧幅度表 / 曲谱下载）。
⇒**重排前上电默认状态未定义完整**（旧 preset/颤音字段可能读到遗留数据）。
所有测试先写后测，掩盖了这一点。重排后新增上电行为测试（见 §7-P6）。

## 4. 关键字节语义（新增部分）

**左手音符事件（串行化）**：先写 `0x60`（on+音高），再写 `0x61`（力度，写入即触发）。
两次写之间无时序要求；触发在下一采样边界原子生效。物理排针事件与定序器事件
走同一 note_map，三者互为兜底（优先级/或关系由 RTL 决定）。

**右手塑谱（泛音键排 v1）**：
- 物理电极扫描 + `0x5B` 软写入**按位或**→ pad 状态；
- pad 变化 → 谱 RAM 按位映射（摸=该泛音幅度→满幅×力度档，不摸=0 或预设底谱，由 SPEC_MODE[0] 定）；
- `SPEC_MODE[1]=1`（默认）时 pad/谱变化**自动刷新在响声部**（D6）——这就是"按住音改谱当场变形"；
- 上位机模式：PC 算好 16 字节谱，`0x58` 从 0 起连写 16 次 `0x59`（自动步进），最后写 `0x5A` 触发刷新。

**F3 指令识别**：对上位机透明（识别在 RTL 分类，事件字节不变）。0x62 状态位留给演示读数。

## 5. 冻结条款

1. 本表经用户确认后冻结；**任何地址变更需用户批准 + 在任务清单登记**；
2. 新增功能只允许用"保留"区，不得改动已冻结位定义；
3. 0x01–0x0E 的回归（包络参数化）与 0x38–0x3F（VIB/GLIDE_EN）是已知的两个未来扩展点；
4. 协议版本号写入 reg_bank 0x7F（=0x10，v1.0），上位机可据此识别。

## 6. 塑谱 v1 验收判据（执行，随步③④验收）

| # | 判据 | 通过标准 |
|---|---|---|
| VP1 | 谱 RAM 写入/自动步进 | 连写 16 字节后内部谱阵列逐字节一致 |
| VP2 |**在响变形**：长按音符 → 改谱 → 频谱断言 | 正在响声部的谱峰在 ≤2 个样本周期内变为新谱形；**未触及声部输出逐位不变**|
| VP3 | 替换/叠加两种模式 | 替换=只响摸的泛音；叠加=预设底谱+加强，数值断言两者差 |
| VP4 | pad 位掩码→谱映射 | 8 键逐键独立验证（每次只摸一根，对应泛音幅度=满幅档） |
| VP5 | 物理电极 OR 软寄存器 | 电极扫描与 0x5B 写入等效驱动同一 pad 状态 |
| VP6 | 事件串行化 | 0x60/0x61 触发的事件与排针事件在 note_map 端等效（装载序列一致） |
| VP7 |**上电行为（A1 验收）**| 复位后零 UART 写入：静音、preset 0、颤音关、定序器关、FX 干声——新增 tb 测试 |
| VP8 | 全量回归 | regress_all --full 29/29（含 R0、F1 与 VP7） |
