## 1. 引脚预算复核：17 脚刚好，零余量

按 60 号候选表复核，加入 7 英寸第二屏后仍然成立：

| 信号 | 封装脚 | 用途 |
|---|---:|---|
| BUS_SCK | 27 | 共享 SPI 时钟（595 / 165 / 两屏） |
| BUS_MOSI | 15 | 共享 SPI 数据（带 LED0 负载） |
| SCAN_LATCH | 16 | 595 锁存（带 LED1 负载） |
| INPUT_LOAD_N | 17 | 165 并行载入（带 LED2 负载） |
| INPUT_DATA | 28 | 165 串行输出 |
| SENSE_0/1/2 | 29/30/31 | 6 路 RC 并行测量 |
| SENSE_3/4/5 | 41/42/48 | 同上 |
| STORE_SDA/SCL | 25/26 | I²C 共享：EEPROM + FT5316 触摸 + PCM5122 配置 |
| LCD_VIS_CS_N | 18 | 可视化小屏 CS（带 LED3 负载） |
| LCD_HARM_CS_N | 19 | 7 英寸屏 CS（带 LED4 负载） |
| LCD_SHARED_DC | 20 | 两屏共享 DC（带 LED5 负载） |
| TP_INT | 77 | 触摸中断 |

**合计 17 个逻辑 GPIO。**

### 1.1 595 的 8 位输出也刚好占满

| 位 | 用途 |
|---|---|
| Q0–Q3 | 4067 地址 A0–A3（16 地址） |
| Q4 | 4067 使能（高=禁用） |
| Q5 | RC 激励 RC_DRIVE |
| Q6 | 两屏共享 RESET |
| Q7 | 触摸 RESET |

### 1.2 165 的 8 路输入也刚好占满

4 个预设键 + 1 个编辑键 + 旋钮按压 + 旋钮 A 相 + 旋钮 B 相 = **8 路**。

### 1.3 由引脚预算推出的三条硬约束

1. **7 英寸屏必须是 SPI 显示**。16 位并口的 7 英寸模组需要 16 数据 + RS/WR/CS/RD ≈ 20 根线，17 脚预算直接排除。这一条把 MRB7966（SSD1963 并口）排除出候选。
2. **不能接 MISO**。两屏只写不读，MISO 悬空（不可接地）。
3. **零余量**。若最终模组需要 BUSY/WAIT、背光 PWM 或第二路 TP_INT，必须先腾出引脚——最可行的做法是把 6 路 SENSE 减到 4 路（牺牲 2 个测量通道，节点容量从 84 降到 56，不够 83 节点），所以实际上**没有安全余量**。这是本方案最大的单点风险。

## 2. 7 英寸触摸显示屏：唯一真正的缺口

### 2.1 立创商城没有 7 英寸整屏（已实证）

| 检索词 | 结果 |
|---|---|
| `7寸 电容触摸屏` | 返回触摸芯片与连接器，无整屏 |
| `7.0寸 TFT 液晶显示屏` | 最大只到 3.2 英寸（HS32B01A，C19632786，¥49.77） |
| `7寸 800480` | 页面明确提示"没有找到完全匹配的商品"；唯一带 7.0-800480 字样的 NHD-7.0-800480EF-20（C17335206）属"其他模块"类目、库存 0、¥591.42 |
| `7寸 SPI 显示屏` | 页面明确提示无匹配；尺寸分布最大 3.2 英寸 |

**结论：7 英寸 800×480 SPI 整屏必须外购，立创商城无法供货。** 这与 62 号判断一致，本轮用四种检索词独立复核。

### 2.2 架构正确的候选：ER-TFTM070-5V4

| 项 | 参数 |
|---|---|
| 尺寸 / 分辨率 | 7.0" / 800×480 |
| 显示控制器 | **RA8875**（内置 GRAM + 硬件绘图指令） |
| 接口 | I²C、3 线 SPI、**4 线 SPI**、6800/8080 8/16 位并口 |
| 触摸 | 可选电容触摸，控制器 **FT5316**（I²C） |
| 供电 | 3.3V 或 5V；480mA@3.3V / 300mA@5V |
| 外形 | 180.00×104.00mm，有效区 154.08×85.92mm |
| 价格 | **US$40.18 起**（基础配置）；电容触摸为加价选项，国内含运总价**待询价** |

**为什么这个架构是对的**：RA8875 有 GRAM 和硬件画线/画矩形/填充指令。FPGA 只发命令，不推像素。

| 指标 | 逐像素推送（ST7796S 类） | RA8875 命令绘制 |
|---|---:|---:|
| 全屏 800×480 RGB565 | 768000 B | 不需要 |
| 6.75MHz 全屏理想耗时 | 910 ms（1.1 fps） | — |
| 8 组推子单帧更新 | ≈ 768000 B 不可行 | ≈ 120 B |
| 6.75MHz 单帧耗时 | — | ≈ 142 µs（>30 fps 余量充足） |

**这一条把"7 英寸在 6.75MHz SPI 下不可用"的结论推翻了**——前提是必须选带图形加速控制器的模组，不能选裸 ST7796S。

### 2.3 其他候选与排除理由

| 候选 | 结论 |
|---|---|
| RONBO **MSP7001**（US$30，7" 800×480 SPI+CTP） | 更便宜，但**显示控制器 IC 栏空白**、触摸 IC 未定、3 线/4 线描述自相矛盾。不取得确切控制器与触摸型号不能下单 |
| LCDWIKI **MRB7966**（SSD1963，16 位并口） | **引脚预算排除**（需 ≈20 根线） |
| Surenoo **SSP0700A**（LT7686 + FT5426） | 架构合适（LT7686 也带图形加速），但国内价/点数/可售版本未闭环 |
| 微雪 **7inch HDMI LCD (C)**（C359951，¥239.40） | 需 HDMI 视频 + USB 触摸主机栈，Nano 20K 都不具备 |
| 微雪 **3.5inch F**（SKU30896，¥107.06 参考） | 架构同类但尺寸不符用户 7 英寸要求；**预算内唯一可行解** |

### 2.4 关于"7 英寸 vs 500 元"

这是本轮最重要的发现：**7 英寸屏与 500 元预算不可同时满足。**

- 7 英寸模组 ¥280 起（且未含电容触摸加价、未含国内运费）
- 整机其余部分 ≈ ¥366
- 合计 ≈ ¥646～700

详见 §5。

## 3. 左手前端定量

### 3.1 片数与容量

| 项 | 25 音位 | 26 音位 |
|---|---:|---:|
| 音高节点（3 电极/位） | 75 | 78 |
| 八度条节点（5 段） | 5 | 5 |
| 合计感测节点 | **80** | **83** |
| 6 片 4067 × 16 地址 | 96 | 96 |
| 每路留 2 个参考负载（地址 14/15） | −12 | −12 |
| 可用感测位 | **84** | **84** |
| 余量 | 4 | **1** |

**两例都装得下**，但 26 音位只剩 1 个位置。25/26 的差别只是 3 个电极 + 3 颗保护，成本差约 ¥2.3——这是设计决定，不是成本决定。

### 3.2 关键器件选择

**MUX：选 Nexperia 74HC4067PW,118（C179326），不选 TI CD74HC4067M96（C496123）**

| | Nexperia C179326 | TI C496123 |
|---|---:|---:|
| 1+ 单价 | **¥2.89** | ¥4.04 |
| 10+ 单价 | **¥2.22** | ¥3.42 |
| 6 片合计 | **¥17.34**（1+ 档×6） | ¥24.24（1+ 档×6） |
| 封装 | TSSOP-24（0.65mm） | SOIC-24-300mil（1.27mm） |
| Ron @4.5V | 80Ω | 70Ω |
| 供电范围 | 2.0–10V | 2–6V |
| 库存 | 14,713 | 7,832 |

**Ron 对测量的影响可以忽略**：Ron 与 47kΩ 测量电阻串联，80Ω 只带来 0.17% 误差；通道间 ±20Ω 差异带来 0.04% 误差，在 8 位位置分辨率下完全不可见。

**代价**：TSSOP-24 手焊困难，必须交厂 SMT。用户已确认"小封装交工厂"，可接受。

**施密特整形：SN74LVC14ADR（C133541），¥1.4573 @5+，MOQ 5**

1 颗六门刚好覆盖 6 路 SENSE。注意它是**反相器**，FPGA 侧计时逻辑需按反相处理，或两级串联还原极性。

**保护：TPD4E02B04DQAR-TP（C2841426），¥0.7486 @5+，DFN2510-10**

- 4 通道/颗，25 颗覆盖 100 路（83 节点 + 余量）
- Cj 0.25pF（商城参数表值），漏电 10nA
- 比单通道 TI TPD1E01B04DPYR（C779389，¥0.091/颗 × 83 = ¥7.55）**更贵**，但少 58 个焊点
- 若改用单通道：¥7.55，但 83 个 0.6×1mm 焊盘，装配成本反升

**建议：先用 25 颗 4 通道方案**，除非实测证明 0.25pF 对 3 电极滑条位置线性度有影响。

### 3.3 一个需要澄清的风险

60 号按"每电极一颗保护"做预算上限。但从电气角度，**更常规的做法是每电极串 1kΩ + 每个 MUX 输入加钳位**，而不是 83 颗 TVS。83 颗 DFN 器件在 154×86mm 的滑条区域上布板密度很高，且会引入额外寄生。

**建议**：先按"每电极 1k 串阻 + 每路 1 颗 4 通道 TVS（6 颗，覆盖 MUX 公共端）"做小样，实测 ESD 与位置精度后再决定是否加满。这样保护件从 25 颗降到 2 颗，省 ¥17。

## 4. 控制、存储、音频定量

### 4.1 按压编码器：C470754 是错的，必须换

**56 号文档把 EC11E15244B2（C470754）列为"1.5mm 按压"候选，这是错的。** 立创分类明确把 C470754 归入"**不带按压开关**"组。

带按压的候选：

| 型号 | C 料号 | 1+ 单价 | 库存 | 定位/脉冲 | 建议 |
|---|---|---:|---:|---|---|
| **EC11E183440C** | **C370986** | **¥15.56** | 1,910 | **30/15** | **首选**：有定位手感，适合数值微调 |
| EC11E1834403 | C361165 | ¥9.77 | 3,206 | 0/18（无级） | 降本备选，但无定位手感不适合离散调值 |
| EC11E153440D | C370992 | ¥10.88 | 459 | 0/15（无级） | 同上 |
| EC11N1524403 | C470737 | ¥18.95 | 974 | 30/15 | 备选 |

**选 EC11E183440C**：菜单导航和数值微调必须有机械定位，否则一次转动跨越多个档位无法控制。

### 4.2 AUX DAC：PCM5102A 在 52.734375kHz 下不可用（重大更正）

我此前（10-19 早些时候）判断"PCM5102A 可用"，理由是 27MHz = 512 × 52.734375kHz 且 fSCK 允许 512 倍。**这个判断是错的。** 核对 TI SLAS859C 原文：

| 手册原文 | 位置 | 含义 |
|---|---|---|
| "Common audio sampling frequencies in the bands of 8 kHz, 16 kHz, (32–44.1–48 kHz), (88.2–96 kHz), (176.4–192 kHz), and 384 kHz **with ±4% tolerance** are supported." | §9.3.5.2 | 采样率检测只认这几段，容差 ±4% |
| Table 10 无 52.734kHz 行 | §9.3.5.2 | 无对应系统时钟组合 |
| "SCK rates that are **not common to standard audio clocks**, between 1 MHz and 50 MHz, are **only supported in software mode, available only in the PCM512x, PCM514x, and PCM5242 devices**" | §9.3.5.2 | **PCM5102A 不在这个名单里** |
| Table 11（BCK PLL 模式）只列 8/16/32/44.1/48/96/192/384 kHz | §9.3.5.3 | 3 线模式也不支持 |

52.734375kHz 比 48kHz 高 **9.86%**，远超 ±4% 窗口。

**结论：PCM5102A 无法工作在项目原生采样率，无论给不给 SCK。**

**替代：PCM5122PWR（C962071），¥19.87 @1+，TSSOP-28，库存 403**

| 项 | 值 |
|---|---|
| 采样率 | **8 kHz – 384 kHz 连续**（手册 §Recommended Operating Conditions） |
| 配置 | 软件（I²C/SPI）**或**硬件 |
| 时钟 | 集成 BCK 基准 PLL，可内部生成 SCK → **3 线 I²S，不占额外引脚** |
| 位深 | 16/20/24/32 位 |
| 输出 | 2.1 Vrms 中心接地，无需隔直电容，可驱动 ≥1kΩ |
| 为什么能行 | 软件模式下手动配置 PLL 与分频，**不走采样率自动检测** |

**代价（必须说清）**：需要在 FPGA 上电时通过 I²C 写 PCM5122 的时钟树寄存器，为 52.734375kHz 算好 PLL 分频值。这段初始化代码**目前不存在，属于待实现工作**，且实测前不能签收。

**备选（更简单但有代价）**：
- **PT8211-S（C92004）**：无采样率检测、无 MCLK、3 线右对齐，任何 fs 都能跑。但**库存仅 1 颗**，且只有 16 位。不可作为主选。
- **UDA1334ATS**：手册 audio mode 覆盖 50–100kHz，52.734kHz 在内，但 NXP 已停产。

**引脚影响**：PCM5122 用 3 线 I²S（BCK/LRCK/DIN），可与板载 MAX98357A 共用同一组 I²S 信号（54/55/56 已在板上走线到功放）。**不需要新增引脚**，只需在载板上把这三根线并联引出。I²C 配置走 25/26。

### 4.3 存储

- **24LC256-I/SN（C411625）**：SOIC-8，库存 537，批量 ¥2.64，1+ 估 ¥4.50。32KiB 够 4 槽 × 1KiB × 双份 + 元数据。
- **TF 卡**：复用板载卡座（封装脚 80–85），不买模块。32GB C10 约 ¥30。
