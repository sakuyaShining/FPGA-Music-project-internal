## 2. 开机、演奏与声部归属

| ID / 操作 | 冻结行为 |
|---|---|
| B01 开机 | 静音；定序器与测试模式关闭；默认 preset 0；持续方式；固定力度 15/15；力度塑谱关；亮度恒等 `0x70`；滑音/颤音无有效调制；效果仅干声。无须电脑写初始化才能得到这些行为。 |
| B02 选音 | 每个稳定按下沿只发一次 note-on，长按不重触发。起音时锁存实际音符号；松开用同一音符发 note-off。换档仅影响之后按下的键，已按住的音不移调。 |
| B03 音域 | 首个原型验证现有 8 键半音路径；扩展到 12 键须保持半音规则。完整键位逻辑沿用 25 号文档：基准 C3、半音偏移 0–24、档位 −1…+3、不环绕、最高 MIDI 108；超上限不发声，松开也不补发 off。实物通道数另经原型决定。 |
| B04 和弦与同音 | 不同音各占声部；同音再次 note-on 重触发该音，首版不叠多份同音。正常演奏一次只启用一个音符源（面板、GUI 或定序器）；切源先停止旧源并执行清音。混源同音所有权不作为首版功能。 |
| B05 分配与回收 | 同音重触发 > 已释放/空闲组 > round-robin 抢占。存在已释放候选时不得抢按住的音；32 组全部按住才允许抢占。被抢音后来的 off 不得关闭替代它的新音；不存在的 off 无副作用。 |
| B06 持续方式 | 按下起音并进入该音色的保持状态，松开从**当前包络电平**进入释放，不能跳回高电平或再次起音。释放到零后静音；释放组可用于新音。 |
| B07 击发方式 | 按下只击发一次，随后自动衰减到零；按住不会维持或循环。松手不重新起音，允许自然尾音结束。再次完整按下可以重触发。 |
| B08 方式切换 | 用户显式选择“持续／击发”，默认持续；不以点击/长按猜测。切换前清音，切换后须重新按下才发声。包络常数随版本配置保存，须报告实测起音/释放/击发衰减时间；首版不提供未实现的 ADSR 调参按钮。 |
| B09 力度保持 | 面板首版固定 15；GUI/定序器允许显式 4 位力度。每次起音的力度随声部保存；刷新音色、改亮度不能取用别的音最近一次力度，也不能复活已经松开的音。 |

首版默认复音模式关闭滑音。辅助颤音使用明确开关与全局深度/速率，关闭后恢复直音，不能改谱或力度。
现有滑音保留为诊断/辅助演示入口，**不得称为已完成的手指跨键连滑或可靠的单声部 legato 产品模式**；需要明确声部重定向与 off 归属后才能纳入正式演奏。

## 3. 音色编辑、保存与调用

| ID / 操作 | 冻结行为 |
|---|---|
| B10 编辑 | 一个音色含 16 个分量幅度（整数 0–255）。拖动滑块只改本地草稿；点击“应用／试听”才提交。用户层采用替换谱，避免同一草稿因叠加预设而得到不同结果。全零谱是静音音色。 |
| B11 应用 | 全部 16 项作为**一份完整谱**生效；在写入期间不逐项自动刷新，不暴露半新半旧谱。完成后刷新所有仍按住的声部与后续新音；保持每声部的音高、力度、包络阶段/电平和调制状态，不重触发，不复活释放声部。首版不暴露“逐声部编辑”作为产品功能。 |
| B12 试听 | 可使用正常按键或显式试听按钮；试听结束发送配对 off。试听不是预录音播放；重复试听、取消、切音色都不能留下挂音。 |
| B13 保存 | 保存到电脑的音色文件，不能把帧日志导出当作音色保存。文件至少包含 `schema_version=1`、名称、16 项谱、发声方式、辅助颤音配置与效果配置。校验长度、整数范围、版本及配置范围；保存不修改正在响的声音。 |
| B14 调用 | 导入先校验，再载入草稿；用户点击应用才影响设备。错误文件不改变草稿与设备。调用含发声方式变化时按 B08 清音；其余变化按 B11 生效。相同文件在相同配置下产生相同谱与控制值。 |
| B15 持久性 | 自定义文件保存在电脑；FPGA 运行期配置断电丢失。重启回到板上默认 preset 0；不承诺自动恢复最后一个自定义音色。GUI 重连先读取/同步设备，不默默重放旧音符或自动播放。 |

现有 `0x58/0x59/0x5A/0x63` 用于谱写入与刷新；事务期间关闭自动刷新是必要步骤。
是否能实现整谱提交、刷新保持包络及在输入事件并发时不读到中间态，须由端到端判据证明。
若现有协议缺乏提交隔离能力，须补充兼容修正案；不能仅靠 GUI 连续发帧宣称原子生效。

## 4. 右手 8 档塑谱

右手只控制**临时修饰**，不改已保存的基础谱。模式通过显式操作选择，默认“明暗”；独立启动使用默认模式。
不根据点按/滑动/长按猜模式。8 个位置编号 H1–H8，不依赖控制器能提供连续位置。

| ID / 操作 | 冻结行为 |
|---|---|
| B16 明暗模式 | H1–H8 分别选择 `TILT=[0x00,0x20,0x40,0x60,0x70,0xA0,0xD0,0xFF]`。H5 为恒等。作用于全部仍按住声部及新音，不改音高、力度与包络；释放尾音不再重新装载。 |
| B17 局部分量强调 | Hk 强调基础谱的第 k 个分量（k=1…8）；目标谱该分量为 `min(255, floor(3*S[k]/2))`，其余为 `floor(S[j]/2)`。不把原本为零的分量强行变成 255，不改基础谱；此模式亮度固定恒等。 |
| B18 多触点与松手 | 多个位置同时有效时固定取编号最小者；不相加、不按最后扫描顺序决定。右手全松恢复基础谱及亮度恒等；恢复不产生任何 note-on/off。切换塑谱模式先回到中性，须全松后重新触摸才激活。 |
| B19 平滑与隔离 | 新档目标在音频侧以 20 ms 线性幅度过渡，更新从当前值继续，不能每次刷新重启包络。控制更新最多 50 次/秒，重复同档不重发。响应开始延迟仍须 ≤10 ms；20 ms 是过渡完成时间。塑谱不得改变声部归属或写入音色文件。 |

两种模式分别演示“总体明暗”和“局部分量强调”；GUI 提供同样的 8 档操作以便硬件前验收。
现有电极掩码“按位或、命中分量推到最大”的行为与本合同不同，必须改接首版映射再验收。
模拟设备只证明操作流程；声音判据必须来自真实 RTL 输出或板上输出。
