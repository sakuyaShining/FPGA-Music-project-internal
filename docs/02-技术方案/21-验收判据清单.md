## 2. TDM 三不变量（改引擎前默背，详见移交说明 v2 §一.2）

1. 装载走"待生效区"+周期奇偶标签，样本边界统一消费——**禁止恢复直写状态存储**；
2. 奇偶翻转在 sc=NSLOT-1，判定用读取时刻奇偶（ppr1）；
3. 累加窗口旋转 LAT 拍（清零 sc=LAT、锁存 sc=LAT-1）。
外加：门初值 0（无幽灵音符）；不变量"每样本拍数 = NSLOT"；不变量"查表地址用推进前相位"。

## 3. F1（512 谱峰）——已入闸口

- 工件：`src/sim/tb_tdm_f1.v` + `tools/scripts/f1_check_tdm.py`
-**栅格公式必须用 RTL 式**`(71583+8800k)×fs/2^24`——用四舍五入的 27.7 会累计漂移 18Hz
 （判据的尺子要跟被测物同源）；
- 采样**只在 WS posedge**（两个沿都采=时间轴拉长一倍、频率全部减半）；
- 采样前必须等包络进延音（≥4000 样本周期，按周期计不按拍计）+ UART 引导写 0x40=0x01；
- 判据 G1=512/512，G2=512，G3<5%，G4<半格。

## 4. 塑谱 VP1–VP8 执行细则（步③④完成后立即执行）

| # | 配方 |
|---|---|
| VP1 | 经 UART 连写 0x58(idx)/0x59(val) 16 次（自动步进）→ 断言内部谱阵列逐字节 = 写入序列（hierarchical 读 `u_tdm` 内谱 RAM 或经行为反映） |
| VP2 核心 |**在响变形**：0x60/0x61 长按 note 69 → 采 4096 样本基线谱 → 写新谱（0x58–0x5A，如首泛音→末泛音倾斜）→ 0x63 刷新该声部 → 再采 4096：断言 (a) 新谱峰位置/相对幅度按新谱变化（首/末泛音能量比反转）；(b) 变化发生在 ≤2 个样本边界内（分窗 FFT 或逐样本能量跳变点定位）；(c) 若同时长按第二音（note 72）且 0x63 只刷 note69 声部 → 第二音的谱峰频率与幅度**逐位不变**|
| VP3 | 替换模式（SPEC_MODE[0]=0）：未摸泛音幅度=0；叠加模式（=1）：=预设底谱+写入值（数值断言两种模式之差=底谱） |
| VP4 | 逐 pad：置 HARM_PADS 单位掩码 ×8 → 对应泛音幅度=满幅档、其余=0/底谱，逐根断言 |
| VP5 | 物理电极路径（pad_scan 实现后）：电极注入与 0x5B 写入产生相同 pad 状态与相同谱变化 |
| VP6 | 串行事件（0x60/0x61）与排针 ev_* 触发同一 note_map 装载序列（逐拍比对 load_en/load_slot/load_inc） |
| VP7 | 上电行为：复位、**零 UART 写**、16384 样本：输出全零、无测试模式频谱（test_mode 引脚下拉后=0）、preset=0（行为侧：第一事件响应符合预设 0 的谱） |
| VP8 | regress_all 全绿（含 --full） |

**VP2 的"逐位不变"实现要点**：对比窗口必须取刷新后的**同一相位区间**（谱变化会改波形但
"未触及声部"的波形应逐样本一致）——若两声部混叠无法分离，改为分两次实验（只发一个音）。

## 5. pads PS1–PS7 执行细则（pad_scan 实现后）

| # | 配方 |
|---|---|
| PS1 | 电容模型 tb：把 pad 建成可参数化放电时间（快=无指 / 慢=有指），断言计数单调随参数增大 |
| PS2 | 计数在阈值 ±5% 抖动 100 轮：输出状态翻转 ≤1 次（滞回生效） |

| PS4 | 8 个音高 pad 逐一触发 → 抓 note_map 装载的 inc，对照五声音阶期望表（C4=262hpz… 用 note_inc.hex 的 MIDI 60/62/64/67/69/72/74/76 项） |
| PS5 | pad_harm 某位置位 → 在响声部对应泛音幅度变化（同 VP2 断言法） |

## 6. 混响 T60（17 号契约 V2–V4 的执行配方）

1.**冲激**：单样本满幅注入（tb_fx test=2 已有），采 ≥30000 样本（T60 最长档 ~2s @fs）；
2.**Schroeder 积分**：E(n) = 10·log10(Σ_{k≥n} h(k)²) —— 从尾向头累加；
3.**T60**：E 从 −5dB 到 −35dB 段线性拟合，外推到 −60dB 的样本数 × Ts；
4.**V2**：RV_FB（0x48）逐档 → T60 实测 vs 理论 `6.91·Ts/(1−fb)` 误差 <10%；
5.**V3**：回声密度——前 200ms 内脉冲计数随时间单调增；
6.**V4**：把冲激分别过低通（截止 2kHz）/ 高通（6kHz）再各自 Schroeder → damp 最大档时
 高频 T60 < 低频 T60（差 ≥20%）——**"高频先死"**，报告直接引用；
7. 溢出测试：满幅正弦持续 5s 无回绕（V5）；全部走 0x48/0x49 寄存器（顺带验证 UART 路径）。
