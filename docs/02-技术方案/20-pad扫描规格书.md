## 1. 引脚分配（40P 排针，全部 LVCMOS33；事件并口 16 根已释放改串行）

| 引脚 | 信号 | 组 |
|---|---|---|
| 27–34 | pad_note[7:0] |**左手**：音高键 ×8（五声音阶，见 §4） |
| 35–42 | pad_harm[7:0] |**右手**：泛音键 ×8（→ HARM_PADS 位掩码） |
| 48 / 77 | 备用（v2: MPR121 I2C SDA/SCL，或八度切换键） | — |

板载按键：S1=复位（不动）；S2（引脚 88，可选）= 八度切换。
扫描原理：IO 先推高充电 N 拍 → 切高阻 + 内部下拉（PULL_MODE=DOWN）→ 数放电到读 0 的拍数。
手指靠近 → 电容变大 → 放电变慢 → 计数变大。**无 ADC，纯数字**。

## 2. 扫描时序参数（@27 MHz）

| 参数 | 值 | 说明 |
|---|---|---|
| 充电时间 | 64 拍（≈2.4 µs） | 推高确保充满 |
| 计数窗口 | 12 位计数器，溢出封顶 4095 | 最大放电观测 ≈151 µs |
| 轮询节奏 | 每路 3 拍状态机（充/放/读），16 路轮转 | 整轮 ≈ 48+48 拍 ≈**3.6 µs**，每样本周期（512 拍）扫 ~9 轮 |
| 判定 | 裸计数 > 基线 × 1.15 → 触摸；< 基线 × 1.08 → 释放 |**滞回**防临界抖动 |
| 去抖 | 连续 3 轮同状态才翻转 | 3.6µs×3 ≈ 11µs，人手无感 |
| 基线标定 | 复位后前 32 轮取**中位数**为基线；此后每秒慢速跟踪基线漂移 | 对策：若上电时有触摸，基线偏高 → 该 pad 需松手后 1 秒内自适应回来 |

## 3. 输出与接线

- `pad_note_state[7:0]`：左手触摸位图 → 经五声音阶表（§4）生成**note 事件**（on/off 边沿），走 note_map 既有 ev_* 路径，**力度 v1 固定 12/15**（v2 MPR121 再上电容力度——协议不动，见 §5）；
- `pad_harm_state[7:0]`：右手位图 →**或**进 `0x5B HARM_PADS`（软寄存器按位或，上位机可强制）；
- pad 变化触发 `SPEC_MODE[1]` 的自动刷新（D6，样本边界生效）。

## 4. 左手五声音阶表（写死在 case 里——song_seq 教训：不用 readmemh）

pad0..7 =**C4 D4 E4 G4 A4 C5 D5 E5**（五声，任意组合无错音；八度跨 C4–E5）
八度切换（S2 或备用引脚）：整体 ±1 个八度，边界限幅。

## 5. 协议关联

- `0x63 SPEC_REFRESH`（冻结修正案 A1）：写 0–31 = 刷新该声部谱形；0xFF = 全刷。写即触发，样本边界生效——**逐声部独立塑形**的机制入口；
- pad 力度 v1 固定值不改协议；v2 MPR121（I2C，10 位接近量）上 pads 力度与真连续轴——届时只用 0x64 起的保留区。
