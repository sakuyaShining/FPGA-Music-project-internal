# 触控原理、候选模块与验证边界

2026-10-07。用途：在器件与面板未定时建立选型依据；资料结论与方案预算不等于实物已通过。
当前唯一确定采购为 Tang Nano 20K；左手音高/滑动/颤音，右手分量强调。所有触控候选仍须实测。

## 1. 原理与信息层级

电容电极附近出现手指会改变电容耦合；控制器测充放电/电荷变化，并经过滤波、基线与阈值判断。
覆盖绝缘层也可检测，但层厚、面积、布线与噪声会影响结果。接触面积引起的变化不是压力测量。

| 输出 | 能说明什么 | 不能自动说明什么 |
|---|---|---|
| 触摸位图 | 哪些电极被检测为触摸，可做离散复音键 | 手指身份、连续坐标、跨键同指关系 |
| 每电极测量值/基线 | 相对信号变化、噪声、耦合，可实验估计位置 | 真实力度、任意多指坐标、重复性 |
| 单条滑条坐标 | 一条规定几何上的连续位置 | 同条多指独立追踪 |
| 多点坐标与身份 | 多根手指位置与移动轨迹，须核对协议及 ID 稳定性 | 低延迟、压力、多指靠近/交叉始终可分辨 |

## 2. 现有路线与可核对的例子

| 路线 | 官方实例与能力 | 在本项目的边界 |
|---|---|---|
| 离散电极模块 | Adafruit MPR121 breakout：12 通道，I²C，触摸位图与滤波值/基线 | 可做按键/多分量选择；不能直接获得逐指滑音轨迹 |
| 专用滑条器件/开发板 | Microchip AT42QT2120：12 键；开滑条后最多 9 键加滑条，报告一个滑条位置 | 单条不能默认用于同区域多指，需设计电极并核对扫描/检测时间 |
| 集成多点面板模块 | Waveshare 4.3inch Capacitive Touch LCD：GT911，I²C，5 点，触摸中断 | 多点坐标候选；尺寸、电气与实际报告速率须核对，5 点不是无限复音 |
| 多点控制器开发套件 | Microchip MTCH6303 套件/控制器：最多 10 点，官方例子五点典型约 100 Hz | 证明路线存在；该速率不自动满足 ≤10 ms 总延迟，不是本项目已选器件 |
| 自研 FPGA RC 扫描 | 当前 `pad_scan.v` 有 16 路计数与触摸状态 | 时序由我们控制，但电气稳定性、连续位置与多指追踪仍需自证 |

上述是候选类型与产品实例，不是采购清单。触摸层与显示层职责不同，采用触摸面板不自动要求实现 LCD 显示。
若只需有限声部独立表情，也可评估多个物理分离的单指滑条；它限制每条一个手指，并改变键位形态。

## 3. 延迟账

总延迟 = 传感器获取/报告等待 + 滤波/去抖 + 通知/轮询等待 + 总线读取 + 事件处理 + 合成/I²S + DAC/模拟输出。
避免重复计入厂商已包含在检测响应里的滤波时间；需明确每个时间戳的含义。

- 100 Hz 完整报告对应 10 ms 周期；周期模型下最不利等待接近 10 ms，尚未计入读取和输出。
- 200 Hz 对应 5 ms 周期，只是有更多余量；并不是保证总延迟 ≤10 ms 的充分条件。
- MPR121 ESI 可选 1–128 ms，二级滤波最少 4 次。NXP AN3890 的 16 ms ×4 示例响应约 64 ms，所举最坏情况约 96 ms；1 ms ×4 的快设置约 4 ms。
- 4 ms 滤波响应不等于 4 ms 触摸到出声；阈值、去抖、扫描相位、通信仍需计入。
- IRQ 只减少报告已经准备好后的主机等待，不能让传感器内部扫描加速。
- I²C 40 个数据字节，按每字节含 ACK 的 9 位估算，在 400 kHz 约 0.9 ms，地址等开销另计；100 kHz 则约 3.6 ms。器件须确实支持该速率。
- 更快读取寄存器可能反复读到同一帧；数据包抵达频率不等于真实新数据频率。
- PC USB、串口日志与图形刷新只作观察，不应串入正式演奏控制路径；测量记录自身也不能阻塞采集。

建议预算（未证明）：传感器检测/报告 ≤5 ms、读取/接收 ≤1 ms、数字处理与输出链 ≤2 ms，保留 2 ms 余量。
最终以端到端实测与时序上界分析为准；达不到预算就更换候选或收缩连续表情范围，不能改报起点掩盖延迟。

## 4. 先测哪些指标

| 测试 | 记录 | 通过依据 |
|---|---|---|
| 新数据周期 | 单指、两指、最大点数；空闲唤醒与连续活动 | 不是重复寄存器值；最慢情况仍符合延迟预算 |
| 起音/释放/移动延迟 | 分段时间与最终输出，均值/P95/最大实测，记录测试次数 | 总控制到输出 ≤10 ms；有限次数最大实测不能冒充绝对最坏保证 |
| 静止抖动 | 坐标/计数时间序列；映射后的音分误差 | 小于计划颤音的可控幅度，滤波后仍符合延迟预算 |
| 两指分辨与身份 | 相邻、反向移动、靠近、交叉、逐指抬起 | 不串声部、不造假第三点；不可靠动作须有明确边界 |
| 长按与重复 | 长按漂移、松手恢复、快速重复触发 | 不自动释放，不漏起音/off，不把触后变化解释成换指 |
| 实际装配 | 线长、覆盖层、功放开启、供电条件 | 最终安装条件下仍稳定，不能只测试裸模块 |

测量分两层：逻辑分析仪看 IRQ/I²C/FPGA 接收标记/I²S，定位各段；
端到端还须可重复的接触或电容变化参考时刻，最后测模拟输出。
仅测 IRQ→I²S 会漏掉传感器之前的延迟。电子切换校准电容可测试传感响应，但仍需验证实际手指输入。
PC 时间戳适合趋势，不足以单独证明毫秒级起音延迟；若测到声学输出，还需交代传播距离等条件。

## 5. 推进闸口

1. 文档筛选：型号、面板、供电/I/O 电平、接口、IRQ、报告率/省电模式、最大点数、ID 与原始数据能力。
2. 一个候选小原型：先单指起音与释放，测全链；不先购买四片或制作全尺寸面板。
3. 两指原型：一指固定另一指移动，再反向运动与分别抬起，证明声音归属。
4. 合成器先用人工坐标事件独立验证音高映射与声部保持；传感器再接入，便于定位问题。
5. 功能、稳定性、延迟都通过后，再决定正式面板与最大支持手指数。
