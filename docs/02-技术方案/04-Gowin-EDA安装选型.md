## 二、对我们项目的实际影响

### 我们的器件是 GW2AR-LV18QN88C8/I7（Tang Nano 20K 上的芯片）

关键问题：**教育版支持不支持 GW2AR？**

- 已知事实：Tang Nano 20K 是 Sipeed 主推的教育级板卡，**官方 wiki 的入门教程就是基于教育版 IDE 写的**（`install-the-ide` 页面）。
- 已知事实：Sipeed wiki 提到 "注意 60K 目前已经被教育版支持，需要下载 V1.9.11.03 或更新版本的教育版 IDE 使用" ——说明**教育版确实覆盖 Arora V（GW5AT-60K）等较新器件**。
- 推断：**GW2AR（Arora II 系列，属于较成熟的老器件）教育版必然支持。**

→ **结论：做我们的项目，教育版完全够用。**

### 教育版的"非商业用途"限制会不会有问题？

我们参加的是**大学生竞赛**，属于教育用途。合规。

唯一要注意的：如果将来拿这个项目去做商业产品，需要换商业版。对这个竞赛而言不构成障碍。

## 三、两版对比：代价分析

| 维度 | 教育版 | 商业版 |
|---|---|---|
| 上手时间 | **立即**（下载即用） | 等 1–3 个工作日审核 |
| 换电脑 / 重装系统 | 无影响 | **需重新申请 License** ⚠️ |
| 版本新旧 | 略旧（1.9.11.03） | 更新（1.9.12.03） |
| 风险 | 极低 | License 过期/绑定带来的中断风险 |

**对一个 47 天倒计时、零基础、要频繁试错的项目来说，"下载即用"和"不怕换环境"的价值远大于"版本新一点点"。**

## 四、我的建议（供你决策，不是替你决定）

**建议：先装教育版，不申请 License。**

理由：
1. **零等待**——今天就能开始，47 天倒计时里每一天都值钱；
2. **零绑定风险**——不担心 MAC 绑定、License 过期、重装系统后续麻烦；
3. **器件够用**——我们的 GW2AR 是老器件，教育版必支持；
4. **合规**——竞赛属教育用途。

**什么时候需要改成商业版？**
- 如果教育版**真的缺你需要的功能**（例如某个 IP 核生成器被裁剪）；
- 或者你想用 GW5AT（Mega 60K）而教育版版本太旧（那也要 ≥1.9.11.03）。

→ **这是可逆决策**。先装教育版，遇到问题再换，成本很低。**反过来说，先申请商业版是"不可逆的等待"。**

## 五、安装操作步骤

### 步骤 1：下载

打开 **https://www.gowinsemi.com.cn/software/3** （云源软件教育版）

下载这两个（选 Windows）：
- **云源软件教育版 For Win (V1.9.11.03)** — zip，422.25 MB
- **云源编程器教育版 For Win (V1.9.11.03)** — zip，85.57 MB ← *烧录用，别漏*

> 💡 校验 MD5（可选，但建议）：
> - 云源软件：`e5ed6222b1038369e52efbe1584f55a9`
> - 编程器：`ae8db0e1cc0353cd7a07ac421e149eea`

### 步骤 2：安装

1. 解压两个 zip
2. 先装**云源软件教育版**，按默认选项走（安装路径**不要有中文和空格**，例如 `D:\Gowin\Gowin_V1.9.11.03_Education`）
3. 再装**编程器教育版**（通常和软件装在同一父目录下，例如 `D:\Gowin\Programmer`）

### 步骤 3：验证安装成功

1. 打开 Gowin EDA（桌面图标）
2. 新建工程：`File → New → FPGA Design Project`
3. 器件选择时，确认能找到 **GW2AR** 系列 → **GW2AR-LV18QN88C8/I7**
   - 找不到 → 教育版器件库不全，回来看第四节
4. 能建出工程 = 安装成功

### 步骤 4：装 USB 驱动（如果识别不到板子）

Tang Nano 20K 板载 BL616 芯片作下载器。Windows 通常自动识别；
如果 Gowin Programmer 提示找不到设备，去设备管理器看有没有未识别设备，装 `Gowin Programmer` 安装目录下的 USB Cable 驱动。
