# 音高与八度规格（键位表）

> 2026-10-05 起草案 · 本文是**契约**，不是描述：每一条都对应到可自动执行的判据（见第 7 节）。
> 适用对象：左手音高键位、修饰键、八度档、以及它们产生的音符事件。
> 不涉及：音色（谱形）、效果器、包络——那些属于引擎规格。

## 1. 目的与范围

把"演奏者按下某个物理位置 → 系统发出哪个音"这件事**完全确定下来**，包括边界情况（高音到头、修饰键中途变化、挂音防护）。改键位时只改本文，不改代码里的隐含约定。

## 2. 物理布局与通道分配

面板为两排、每排 13 个触摸位置，另加两个八度键与八个泛音键，合计 **36 通道**（三片 12 通道触摸控制器）。

| 通道 | 位置 | 功能 | 半音偏移 |
|---|---|---|---|
| 0 – 11 | 下排第 1–12 键 | 音高：C3 → B3 | 0 – 11 |
| 12 – 23 | 上排第 1–12 键 | 音高：C4 → B4 | 12 – 23 |
| 24 | 上排最右 | 单独的高音 C5 键 | 24 |
| 25 | 面板边缘键 | 八度降一档 | 不发声 |
| 26 | 面板边缘键 | 八度升一档 | 不发声 |
| 27 – 34 | 泛音排 | 泛音 1–8 掩码 | 不发声 |
| **合计 35** | | 三片控制器（36 通道）余 1 个 | |

说明：

- **没有两个通道映射到同一个音**。高音端点 C5 由单独的通道 24 提供，而不是让两排都包含端点——若两个相邻物理键对应同一个音，按在交界处会同时触发两个通道，白白占用两个声部并发出两条 note-off。
- 每排是 12 个等宽键（C 到 B），加上右侧独立的高音 C 键，构成完整的两个八度加一个端点。
- 泛音键不产生音符事件，只改变当前声部的谱形掩码（对应 `0x5B` 与掩码通路）。

## 3. 音高计算与八度档

### 3.1 计算公式

```
音符号 MIDI = 48 + 半音偏移 + 12 × 档位
```

- 基准 `48` = C3
- 半音偏移：见第 2 节表格，取值 0 – 24
- 档位：见 3.2

### 3.2 八度档

| 档位 | 相对基准 | 音域起点 | 音域终点 |
|---|---|---|---|
| −1 | 低一个八度 | C2 (36) | C7 (96) |
| 0 | 基准（上电默认） | C3 (48) | C8 (108) |
| +1 | 高一个八度 | C4 (60) | C8 (108) 截断 |
| +2 | 高两个八度 | C5 (72) | C8 (108) 截断 |
| +3 | 高三个八度 | C6 (84) | C8 (108) 截断 |

- **整体覆盖 C2 – C8（MIDI 36 – 108）**，含钢琴最高音 C8，E7(100) 在内。
- **限幅规则**：计算结果 **大于 108 时不再发声**（不是夹紧到 108）。理由：夹紧会让最高档的多个键发出同一个音，演奏者会误以为按键坏了；不发声是明确的行为。
  - 注意：现有 RTL 的上限判断是"小于 108"（即最高 107）。按本文应为 **≤ 108**，需要一行改动。
- **档位边界**：在 −1 档再按降档、在 +3 档再按升档，**档位不变**（不环绕）。
- 上电默认档位为 **0**。

### 3.3 档位与曲谱播放

片内曲谱播放**不随档位移调**，始终按曲谱自身音高发声。理由：行为可预期；否则"先按档位再播放"的结果不确定，且可能把整首曲子推到音域之外。

## 4. 修饰键（Shift）

| 项 | 规定 |
|---|---|
| 功能 | 与音高键同时按住时，该音升高一个半音 |
| 作用范围 | 只对音高键有效；对八度键与泛音键无效 |
| 单独按住 | **不产生任何音符事件** |
| 中途变化 | 不影响已经按下的音：**以按下瞬间算出的音为准**（见第 5 节） |
| 组合顺序 | 先按 Shift 后按键、或先按键后按 Shift 均可；以**按键瞬间** Shift 的状态决定 |

## 5. 音符事件语义（防挂音）

这是全篇最容易出错、也最必须写死的一节。

1. **按下**时：计算最终音符号 → **存入该通道的锁存器** → 发出 note-on（含力度）。
2. **松开**时：**读锁存器**发出 note-off → 清除锁存器。
3. 因此：按下之后无论档位或 Shift 如何变化，松开时一定发出**同一个音**的 note-off，**不会挂音**。
4. 锁存器**每通道一个**（36 个），互不影响。
5. **重复触发**：某通道在未松开时再次被识别为按下，视为**同一次按键**，不重复发 note-on。
6. **声部不足**：当 32 个声部已满，引擎的声部抢占策略决定谁被替换；**事件本身仍照常发出**（即本规格不因声部不足而改变事件语义）。

## 6. LED 指示

当前档位必须有可见指示，否则演奏者无法判断自己在哪一档。

| 档位 | 指示 |
|---|---|
| −1 | LED1 亮 |
| 0 | LED1 + LED2 亮（上电默认，双重确认） |
| +1 | LED2 亮 |
| +2 | LED3 亮 |
| +3 | LED3 + LED2 亮 |

规则：档位指示占用 LED1–LED3；其余 LED 保持原有用途（心跳、定序器指引）。具体灯位分配在实现时按现有 LED 驱动补全，但**"每一档必须唯一可辨"**是硬要求。

## 7. 判据清单

每条判据都要能自动执行、能判红。

| 编号 | 判据 | 输入 | 期望 | 如何测 |
|---|---|---|---|---|
| P1 | 键位映射正确 | 25 个音高键 × 5 个档位 = 125 组 | 音符号 = 48 + 偏移 + 12×档位，逐组相等 | 表驱动测试台 |
| P2 | 半音完整 | 遍历下排 13 键 | 12 个半音类各出现一次，C4 出现两次 | 同上，集合比对 |
| P3 | 档位语义 | 同一键在 5 个档位各按一次 | 音符号依次相差 12 | 同上 |
| P4 | 上限行为 | 档位 +2 / +3 下的高音区键 | 超过 108 的键**不发 note-on**；不夹紧 | 事件序列比对 |
| P5 | 档位边界 | 在 −1 按降档、在 +3 按升档 | 档位不变，无环绕 | 读档位寄存器 |
| P6 | 挂音防护 | 档位 0 按下 → 切到 +2 → 松开 | 恰好一条 note-off，音符号等于**按下时**的值 | 事件序列比对 |
| P7 | Shift 语义 | Shift + 各音高键 | 升半音；Shift 单独按住无事件 | 事件序列比对 |
| P8 | 非音高键不发声 | 八度键、泛音键 | 不产生任何 note 事件 | 事件序列比对 |
| P9 | **无同音通道** | 遍历 25 个音高键（同一档位） | 25 个音符号**两两不同**，无重复 | 集合比对 |
| P9b | 高音端点存在 | 档位 0 下按通道 24 | 发出 C5（音符号 72） | 事件序列比对 |
| P10 | LED 唯一可辨 | 5 个档位 | 指示图案两两不同 | 断言灯位向量 |

## 8. 与旧判据的替换关系

旧判据是针对五声音阶写的，改键位后其断言全部失效。替换关系必须逐条列出，避免"悄悄丢掉一条判据"。

| 旧判据 | 新判据 | 说明 |
|---|---|---|
| PS1（8 键对应 8 个五声音） | P1、P2 | 被表驱动判据覆盖，且覆盖更全 |
| PS2（力度 12/15） | 保留（并入 P1 的力度字段） | 力度语义不变 |
| PS3（按下/松开事件） | P6 | 增加锁存语义 |
| PS4（音高表逐项相等） | P1 | 由 8 组扩为 125 组 |
| PS5（八度档） | P3、P4、P5 | 原为未接线状态，现正式定义 |
| PS6（修饰） | 新增 P7 | 原来没有修饰键 |
| PS7（非音高键） | P8 | 原为遥测键，现增加八度键 |

## 10. 未定项

1. **半音布局形态**：当前采用"两排全半音、每排 12 键 + 独立高音 C"。备选为"两排全音阶交错"（A 排 = C D E F# G# A#，B 排 = C# D# F G A B），其优点是任意音程指法一致、换调只需整手平移，代价是学习成本。
2. 泛音键的数量与排列（当前按 8 个设计）
3. 八度键是在面板上（占 2 通道）还是板载按键 S2（不占通道）
4. 是否需要一个"低音档"把音域向下延伸到 C1（会增大限幅与判据范围）

## 11. 手工电极的几何约束（制造相关）

电容触摸对相邻电极的耦合敏感，手工铜箔面板需要遵守：

| 项 | 要求 | 原因 |
|---|---|---|
| 单键宽度 | ≥ 12 mm（建议 15 mm） | 手指接触面积与重复性 |
| 键间距 | ≥ 3 mm | 减少邻键耦合 |
| 键间隔离 | 相邻键之间铺设**接地走线** | 显著降低串扰，是电容触摸的标准做法 |
| 两排间距 | ≥ 25 mm | 避免手指悬停时误触另一排 |
| 引线 | 尽量短、远离音频与时钟走线 | 减少噪声耦合 |
