## 3. 首批到货后做的实验

### 实验 A：真实力度是否具有可演奏的范围

固定覆盖层和加载位置，用约 20g、50g、100g、200g、500g 的已知质量加载作为候选量程探索；最低值可能低于安装后的触发阈值，因此要记录实际阈值，不能强行要求该点有效。

每级重复十次，记录原始值、换算/归一化值、标准差和迟滞。再缓慢连续加力、减力，观察曲线是否单调、是否提前饱和、是否出现明显跳变。保持固定加载一分钟检查漂移。手指试奏负责评估手感，固定加载负责排除人手自身抖动。

通过依据：在目标轻触到重按区间内，能形成稳定的连续控制；重复性、迟滞和噪声可量化。具体误差上限待量程及手感数据后冻结。

### 实验 B：两路力度独立及 ADC 通道切换

A 传感器保持固定载荷，B 逐级加力及释放；记录 A 是否变化。交换两路再做，比较慢采样与目标采样配置，排除电源波动及 ADC 建立问题。

本实验验证两个独立测力通道和采样电路，不代表被动二维矩阵的多点耦合已经通过。

### 实验 C：FPGA 至声音的力度表达

两路分别绑定两个独立音符，用真实力变化更新各自表达量；验证 A 加力时 B 的音高、幅度与身份不被覆盖，连续加力不产生新 NOTE_ON，释放不挂音。

记录力信号、ADC 帧有效时刻、事件提交标记和音频输出。用规定的短起音参考预设测量，避免慢 Attack 包络混入控制延迟。单点实验通过只证明测力链的一部分，尚不能给最终阵列的总延迟结论。

## 4. 阵列到货后必须追加的实验

1. 两指同排、同列和对角线独立加力，固定一指载荷观察另一指是否被污染。
2. 一指滑动同时加力，另一指保持；分离位置与力度变化，不重触发。
3. 候选最大同时触点数及最小间距；接近、合并和释放时的身份行为。
4. 完整阵列帧周期、最坏单元扫描相位、接口读出及丢帧。
5. 在目标多指负载下验证物理输入至音频输出 ≤10ms，分别测按下、力度变化、滑动和释放。

所有实验保存原始时间戳、配置、源码身份和图像/波形证据。不能用材料响应时间、ADC 峰值吞吐或空载帧率代替系统结论。

## 5. 本轮不优先购买

显示屏、完整外壳、最终尺寸 PCB、多块普通电容触摸屏、批量单点 FSR、仅用于压力可视化但无可用原始接口的 DAQ。用 LED 与上位机遥测观察实验，不代表最终反馈功能取消。

采购顺序：核实板卡与仪器现状 → 少量真实力传感器和小实验采样链 → 阵列样品与匹配读出 → 通过实验后扩大到完整演奏面。
