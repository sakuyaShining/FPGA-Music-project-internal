# 四预设频谱修复

用户指出不同音色预设频谱相同。代码检查发现草稿选择不发送设备，而默认replace+[255,0,...]会以相同正弦幅度谱覆盖预设。仅选择草稿或沿默认replace路径应用，不能作为内置四预设有效性测试。

## 实现

- 演奏区增加直接生效的“设备音色”，按用户选择发送预设+全零附加谱，SPEC_MODE=0，回读确认。草稿保持独立；按住时等待松键，再用于下一次起音，不以额外note-on或全刷掩盖生命周期问题。
- 草稿选择明确标为“草稿预设”，replace模式显示覆盖关系。设备实际模式/参数与草稿名称分开。
- 默认保留起音实测谱，依据FPGA接受事件及PCM原采样时间戳对齐首1024个减采样点；8k个以内有界采样块历史支持事件与音频到达顺序差异。下一次起音、配置缺口或传输异常清除旧参考。取消勾选可看实时FFT。
- 标准A4测量也优先使用其已接受测试起音窗口，避免对短促音色只取900ms后尾部FFT。
- 配置停止流时不再把一次空read当作排空；等待完整帧和80ms接收静默，最多400ms，USB分片中间空读继续等待。原失败记录保留。

## 验证与边界

70项测试通过，包括正弦替换草稿不污染直接预设、按住延迟切换不重触发、分片中间空读、起音窗口按源时间戳对齐、衰减后保留、下一次起音清除与正常入口。

真实COM6四预设测试采用相同A4/力度12，按FPGA接受起音对齐首1024观察样本，全部RMS>1e-5，不用静音归一化制造差异。40–5000Hz峰值归一化FFT幅度的相对L1差异预置阈值0.05，六组差异约0.650–1.111，全部可区分；可读PRESET/SPEC_MODE匹配。此指标仅证明本次可观察谱不同，不证明完整乐器音色相似度、实体DAC/触控或完整配置适配。

证据为D:/FPGA-Project/host-workbench-20261012/evidence/preset-spectra-20261013-04/report.json、stream.bin、preset-0～3.png与four-preset-spectra.png。01记录排空失败独立保留；02曾取650ms后的窗，其中马林巴为静音，该归一化结论不可作为有效四音色验证，03/04改为对齐起音并增加非零判据，不覆盖旧证据。

测试恢复原预设为纯内置模式，附加谱被清除。协议不支持读取完整旧谱，未声称恢复未知谱RAM；编辑草稿仍在原用户窗口中，不被测试更改。实体声音、配置物理单位及长时性能仍按原边界挂账。
