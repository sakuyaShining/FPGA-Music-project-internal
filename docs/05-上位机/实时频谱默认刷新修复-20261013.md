# 实时频谱默认刷新修复

用户指出按键后频谱停在一个画面。原因是05版为短促音色对比默认开启起音窗口冻结，并非UART或FFT计算停止。该默认选择与持续演奏需求不符。

06版默认使用最新连续PCM窗口计算FFT；“冻结起音谱”默认关闭，仅在用户明确勾选时使用起音快照。取消时立即计算当前窗口并重绘，不必重新按键或重新连接。频谱标题区分“实时频谱 · 第N帧”与“已冻结起音谱”。稳定长音的谱形可以稳定，但接收帧号随真实数据增长。

保留四预设直接选择、自动连接/收流、后台配置与A/B。测试的对齐起音窗口保持可用，不将它默认用于主实时演奏视图。

71项测试通过，包括GUI默认不冻结、连续440Hz→880Hz测试帧的频谱随新数据变化、手动冻结无事件时不伪造数据、取消冻结立即恢复。测试夹具只验证算法与控件行为，不生成产品实测音频。本次为主机默认行为修复，未修改或重新下载FPGA码流。
