# 零、先校准预期

**6 天学不出"完备的 FPGA 基础"**，这是事实。但**项目也不需要完备**。

这个项目真正用到的技能，只占 FPGA 知识体系的一小块：

```
整个 FPGA 知识体系
├── 需要 ✅  Verilog 基础语法 / 时序逻辑 / 计数器 / 状态机 / 仿真 / 工具链流程
├── 需要 ✅  定点数思维 / 位宽管理 / 流水线概念 / BRAM / DSP 基本用法
├── 需要 ✅  会看资源报告与时序报告
├── 不需要 ❌ SDRAM/DDR 控制器、高速接口（PCIe/MIPI/以太网）
├── 不需要 ❌ 复杂 IP 集成（软核 CPU、AXI 总线）
├── 不需要 ❌ 高级时序约束（多周期路径、false path、时钟组）
└── 不需要 ❌ PCB 设计、信号完整性、电源完整性
```

→ **把 6 天全部投在"需要"那一栏，足够了。**

# 一、必须会（回来后立刻要用）

每一项都写成**可自测的动作**。能做出动作 = 会了；只是"看过" = 不会。

## A. 工具链闭环（最重要，优先级最高）

| # | 验收动作 | 自测方法 |
|---|---|---|
| A1 | 能**从零**建一个 Gowin 工程，器件选对 | 器件选 **GW2AR-18C** → 封装 **QFN88** → 型号 **GW2AR-LV18QN88C8/I7** |
| A2 | 能写 `.cst` 把信号绑到真实引脚 | 例：把 `led` 绑到某个引脚，烧进去灯真的亮 |
| A3 | 能走完 **综合 → 布局布线 → 烧录** | 板子上出现你预期的现象 |
| A4 | 能找到**资源报告**里的 LUT / FF / BSRAM / DSP 占用 | 说出你的点灯工程占了多少 LUT |
| A5 | 能在**时序报告**里找到 **WNS** | 知道 WNS < 0 是什么意思（时序没满足） |

> **A 组是硬门槛。** 如果 6 天只能做一件事，做这一组——因为后面所有工作都跑在这个流程上。

## B. Verilog 核心（够用即可，不用学全）

| # | 验收动作 |
|---|---|
| B1 | 能写一个 1 Hz 闪烁 LED（用计数器分频） |

| B5 | 能用 `parameter` 参数化一个模块，能说出 `generate` 是干什么的 |

## C. 心智模型（比语法更重要）

| # | 验收动作 / 能回答的问题 |
|---|---|
| C1 | 能解释：**"FPGA 里代码不是顺序执行的，而是同时存在的硬件"** |
| C2 | 能解释：**"一个 `always @(posedge clk)` 描述一组寄存器，每个时钟上升沿才更新一次"** |
| C3 | 能解释：**"组合逻辑有传播延迟，时序逻辑按周期推进"** |
| C4 | 知道**位宽要自己管**，知道两个 16 位数相加可能变成 17 位 |
| C5 | 能解释：**"为什么 FPGA 能做'同时算 100 个东西'，而 CPU 不行"** |

> **C 组是"能不能独立判断"的分水岭。** 语法忘了可以查，心智模型错了会写出完全错的架构。

# 三、**不需要**现在会（别浪费时间）

| 不需要 | 为什么 |
|---|---|
| SDRAM / DDR 控制器 | 我们的效果器用片内 BSRAM 就够 |
| 高速接口（PCIe / MIPI / 千兆网） | 本项目用不到 |
| 软核 CPU / AXI 总线 | 赛题要求"纯 FPGA HDL"，不用软核 |
| 复杂 IP 集成 | 我们只需要 rPLL（时钟）一个 IP |
| 高级时序约束 | 单时钟域设计，约束简单 |
| PCB 设计 / 信号完整性 | 我们的硬件是铜箔 + 杜邦线 |
| SystemVerilog 高级特性 | 纯 Verilog-2001 足够 |
| 形式验证 / UVM | 用不上 |

> **如果教程里有这些章节，可以先跳过。** 它们不是本项目的前置条件。
