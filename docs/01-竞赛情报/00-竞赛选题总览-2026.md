### 规则要点

- 每队 ≤3 人，≤2 名指导老师，每人限 1 队；仅队长有操作权限。
- 组别：高职高专组 / 本科生组 / 研究生组（队内只要有 1 名研究生即归研究生组）。
- 报名后需资格审查：看提交完整度、项目创新性、科学性、工程可行性、设计难度、FPGA 平台适用度。
- 初赛 = 线上评审（作品报告 + 演示视频）；**决赛含 FPGA 基础编程设计能力考核，通过才有评奖资格**。
- 奖项：一等奖 ≤100、二等奖 ≤200、三等奖酌情；专项奖（最佳创意奖、最佳工程奖，各 ≤3）；企业特别奖由协办单位独立评选。
- 竞赛方式：**参赛队自行选择项目**，用组委会指定 FPGA 开发平台开放自主设计，也可在指定平台之外自行扩展电路。
- 与**FPT'26 Design Competition**有合作赛题，属独立通道，入选决赛队伍名单已于 2026-09-01 公示（详见官网通知）。

**选题二 完整要求（原文要点）**

- 交互：电容触摸 / 光电感应 / 压力检测 / 无接触手势等**任意自研方案**，≥2 个独立可控演奏维度，能识别选音、和弦、触发、拨弦等指令。
- 合成：以 FPGA 为核心并行计算平台，硬件逻辑层搭建实时音频合成引擎；算法可用**波表采样 / 加法合成 / FM 调频 / 物理建模**等任意合规方案；逐样本、逐声部实时运算；**通过 I2S 接口输出至 DAC 解码发声**。
- 基础要求：
 1. 多维交互控制检测（≥2 个独立可控维度）；
 2. FPGA 纯硬件实时音频合成，**控制信号到音频输出总延迟 ≤10ms**，杜绝软件串行运算滞后；
 3.**基础复音数 ≥4**；所有输出音频必须由 FPGA 依实时演奏指令逐音逐样本生成，支持单音实时变调、ADSR 包络调控、多声部实时混音；**严禁直接播放预录 PCM 音频、预置推流及整段录音触发**。
- 拓展要求：
 1.**复音数 ≥32**，或单音加法合成分量 ≥32 路，或多条并行物理建模运算单元；
 2. ≥3 维演奏表情调控（力度动态、滑音、颤音等）；≥2 种乐器音色自由切换；硬件内部实现**混响、延迟、合唱**等数字音频效果器；
 3.**延迟压至 ≤5ms**且确定性无抖动；硬件实时可视化（LED 演奏指引、李萨如图形、实时频谱、波形显示）；
 4. 脱机演奏 LED 曲目指引、蓝牙模块 + 手机 App 联动（在线曲谱、键位自定义、录音回传）。
-**核心评分规则**：
 1. 独立发声单元＝含独立相位累加器、频率调控、包络控制的完整振荡器；单波表采样查表不计多谐波数量；加法合成按运算分量统计、FM 按调制运算器统计、物理建模按并行弦/模态单元统计；
 2.**系统吞吐量指标 = 同时活跃可闻独立振荡器总数 × 实际音频输出采样率**（过采样不叠加加分）；
 3. 现场验证：测试模式输出多路不同频率音频，频谱可观测对应数量独立谱峰，并用 RTL 代码佐证纯硬件实时合成通路、验证无预录音频播放行为。

**板卡获取**：报名时同步勾选申请，每队仅能申请一块，高云评审后抽取寄送，**完赛后需寄回**（广州市黄埔区科学大道 235 号 601 房，朱俊香 18389838792）。申请渠道 `https://www.gowinsemi.com.cn/university/boardapply/2026`。

### 6. 复旦微（Fudan Micro）

平台：**FMQL30TAI-悟净开发板 lite**（国产 FPAI 芯片 FMQL30TAI：4 核 CPU ~1GHz + NPU ZG330 8TOPS@INT8 + FPGA ~125K LC / 400 DSP / 9.3Mb BRAM + VPU 4K@30；Ubuntu 20.04；工具链 Icraft / Procise）；完整版悟净；也允许第三方 FMQL30TAI676HM 板或自研硬件。
