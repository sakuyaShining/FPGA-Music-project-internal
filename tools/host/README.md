# FPGA 乐器上位机

当前发行版为 `host-workbench-20261015-10`，从桌面“FPGA乐器上位机”打开。

快速重复按键变小/静音已于2026-10-15在FPGA包络中修复并下载SRAM，08版上位机继续使用。实板结果、构建指纹和断电后的重新下载方式见 `docs/05-上位机/快速连按修复-20261015.md`。

## 日常使用

1. 选择 COM6，点击“连接”。连接成功后自动开始传输数据，显示“可以演奏”。
2. 在琴键上方选择管风琴、钢琴、钟或马林巴，直接切换音色。按住琴键时切换，会等松开后应用。
3. 点击钢琴黑白键，或按照琴键上的字母/数字演奏。默认 C4–C6，共25个连续半音，补齐 F、B 和所有黑键。鼠标按住拖动可滑奏；电脑键盘可以组合按键。“低八度 / 高八度”整体移动音域，五个位置合计覆盖 C2–C8；“力度”控制新按下音符的力度。
4. “停止所有声音”释放主机按下的琴键；“断开”停止传输并释放串口。

主界面的“按键记录、声音波形、实时频谱”来自设备回传数据，默认持续刷新。频谱是声音中各个频率的强弱，不是曲谱。同一音高的主峰可能相近，不同音色主要看其他峰；钢琴、钟和马林巴会衰减，因此持续按住时频谱逐渐变低是正常现象。声音由开发板输出，电脑只显示和分析数据。

钢琴式电脑键盘映射：

| 区域 | 白键 | 黑键 |
| --- | --- | --- |
| 低音组 C4–B4 | Z X C V B N M | S D G H J |
| 高音组 C5–C6 | Q W E R T Y U I | 2 3 5 6 7 |

逗号、L、句号、分号、斜杠也可演奏 C5–E5，与上排部分琴键重叠。换八度会同步更新琴键音名和当前范围。按住音符后换八度，松开仍释放原来的音符；失焦和断开时释放主机持有的音符。在输入框内打字以及使用 Ctrl / Alt 组合键时不会触发演奏。

## 曲谱播放

连接后，点击主界面“曲谱播放”。格式是 `音高:拍数`，用逗号分隔；例如 `60:1,62:1,64:2`。音高为MIDI编号，60为C4；0表示休止。最多63步，每步1–255拍，速度40–240 BPM。

- “下载曲谱”：写入开发板RAM，暂不播放。
- “下载并播放”：下载当前输入内容，从头循环播放。
- “停止”：停止循环并释放曲谱音符，随后可恢复手动演奏。

播放期间暂停手动按键，避免同音符互相释放；“停止所有声音”也会停止曲谱。断开或关闭上位机会停止本次曲谱。下载时会短暂暂停观察数据，操作完成后自动恢复；操作在后台进行，不占住界面。

10版修复实时模式下旧入口读不到协议版本而拒绝发送的问题，并修复多字节参数的地址递增；速度、曲谱长度和播放控制均有回读校验。已在09版FPGA程序上验证顺序、休止、重复音、循环、停止和断开，数据见 `D:/FPGA-Project/host-workbench-20261015-10/evidence/score04`。

## 编辑自己的音色

点击“编辑音色”，选择音色来源：

- **内置音色**：使用开发板已有的四种音色；日常使用直接在主界面选择即可。
- **手绘音色**：拖动16根柱子调整声音成分。第一根是主体，后面的柱子改变明亮度和质感；“纯净”和“明亮”提供两个起点。全部为零时没有声音。

点“用于演奏”才会改变设备，下一次按键即可使用。手绘音色使用整数倍谐波，独立于内置音色；不需要理解“预设谱、叠加谱、替换谱”。编辑、打开和保存都不会自动发送参数。“保存音色”保存当前编辑内容，“打开音色”恢复编辑内容，之后仍需点“用于演奏”。旧的完整配置文件在“高级工具”的开发配置页打开。

编辑区可以收起，主界面的琴键和三幅实时视图持续保留。小窗口默认收起编辑区，编辑内容可滚动查看。

## 视图和高级工具

“视图设置”集中管理显示范围、波形放大、字体和配色。“冻结起音谱”默认关闭，仅供对比起音；勾选后频谱明确标为已冻结，取消立即恢复刷新。

“高级工具”用于开发配置、指令实验、设备诊断和音色测试，日常演奏无需打开。开发配置包含尚未接入硬件的字段，不能把保存完整配置理解为设备全部参数已生效。实际应用和回读结果保留在高级工具中。

源码启动：`python tools/host/dsp_gui.py`。模拟设备只检查寄存器与操作流程，没有真实音频。

## 应用范围

目前只支持预设和谱的部分应用。articulation（发声方式/包络/混合分组）、vibrato及effects物理单位尚未适配；列表在界面和证据中保留。设备当前状态、完整草稿和发送记录分开显示。显式在奏音刷新及完整音色模型验收仍待实现。

观察Fs13183.59375Hz、Nyquist约6.59kHz，FFT1024点Hann，频率栅格约12.87Hz；不是20kHz全带宽实测。实体传感器/≤10ms、独立FPGA显示与DAC不由上位机测试签收。

## 验证与打包

```powershell
$env:QT_QPA_PLATFORM='offscreen'
$env:QT_QPA_FONTDIR='C:/Windows/Fonts'
$env:PYTHONPATH='tools/host;tools/scripts'
python -m unittest discover -s tools/host -p 'test_*.py'
python tools/host/dsp_gui.py --selftest
python tools/host/dsp_gui.py --workbench-selftest
python tools/host/dsp_gui.py --startup-check

# 构建输出与临时目录可放到空间充足的盘
$env:FPGA_HOST_BUILD_ROOT='D:/FPGA-Project/host-workbench-20261012'
$env:TEMP='D:/FPGA-Project/host-workbench-20261012/temp'
$env:TMP=$env:TEMP
python tools/host/build_exe.py
```

依赖Python、PyQt5、numpy、pyserial；打包另需PyInstaller。未指定输出根目录时，产物在tools/host/dist。打包同时运行旧接口帧一致性和新工作台离线自检。

单文件exe需先解压DLL再启动。启动时临时目录已写入可执行文件，使用构建输出根目录下的temp；10发行版为`D:/FPGA-Project/host-workbench-20261015-10/temp`，双击也不再依赖C盘TEMP。该目录须可写；移至其他电脑时应按目标路径重新打包。

`host_version.json`记录主机产品文件SHA256与设计包来源，不证明设备当前运行完整07码流。当前工作区原RTL未修改，不能拿GUI测试替代其版本接合或板测。主机基线来自交接文档对应66a4工作区。实现及剩余事项见docs/05-上位机/实现与验收-20261012.md。
