# ★ TDM 引擎：逐位一致达成（2026-09-30 第五轮）

> **核心结论：TDM 引擎与全并行引擎【逐样本逐位一致】，已在 8 种时隙组合下验证通过。**

---

## 一、★ 突破点：把"清零"这个动作整个去掉

前四轮全部栽在同一件事上，而正确的做法是**不做这件事**。

### 为什么"清零"必然是错的

时隙 s 的回写发生在 `sc = s-3`，各时隙的回写时刻天然错开。
任何"清零窗口"的首尾都必然切在某个时隙中间：

| 释放点 | 受害时隙 | 实测现象 |
|---|---|---|
| `sc = LAT` | 写回时刻 `sc < LAT` 的时隙（s3~s6） | 0~7 匹配延迟 2、8~15 延迟 1 |
| `sc = 0` | 写回时刻 `sc = 0` 的时隙（s3） | 换一批受害，问题没消失 |

**单独测任一组都"通过"**（组内偏移一致，被延迟搜寻吸收掉了）——
这是整个排查过程中最阴险的地方。

### 正确的做法

> **BSRAM 上电本来就是 0。相位、包络、门的初值天然一致，
> 根本不需要"清零"这一步。**

流程简化为：**上电（全 0）→ 装载 inc/amp/gate → 直接开跑**。
每个时隙每周期恰好被回写一次，从同一个 0 起跑，天然均匀。

仿真里补一个 `initial` 给存储器赋初值即可（硬件上 BSRAM 上电即为 0）。

## 三、遗留问题（如实记录）

### 1. ✅ 已解决（2026-10-01，ZCode 复核修复）：包络的起音触发时刻偏斜
**修复后：8 种掩码在【跳过 0 个样本】（含完整起音段）下 TDM ≡ 全并行逐位一致（各 0/2495）。**

真正根因有三个，且都不是"门沿偏斜"本身：
1. **激励不对称**：并行引擎的 inc/amp/gate 是组合连线上电即有效，TDM 的参数经
   load 口落在第 3~4 个样本周期 → 两边连"音符从哪拍开始"都不同。
   修法（tb）：两边统一为"显式音符事件，样本边界生效"（并行侧激励改寄存器）。
2. **装载无样本边界语义**：load 口即时写状态存储，各时隙在各自访问时刻看到
   新参数，同一音符的起音点相差最多 1 个样本周期。
   修法（RTL）：装载写入"待生效区"+ 周期奇偶标签，各时隙在装载后的
   第一个完整样本周期统一消费（tdm_engine.v "待生效装载区"注释块）。
   陷阱：奇偶翻转点必须在周期末尾 sc=NSLOT-1（在 sample_en 翻转让
   恰好读在 sc=0 的时隙晚一拍）；判定必须用读取时刻的奇偶（ppr1）。
3. **累加窗口横跨两代状态**：旧窗口 [sc0..sc31] 里 slot 0~3 的乘积来自
   上一周期 sc28~31 的读取、slot 4~31 来自本周期 —— 同一样本和混两代状态。
   旧版能对上解析真值纯属装载起点（sc=28）恰好与组边界重合的幸运。
   修法（RTL）：窗口旋转 LAT 拍（清零 sc=LAT、锁存 sc=LAT-1），
   每个样本和 = 全部 32 时隙同一代状态的乘积。
4. 附带：门初值 1→0（旧值是"幽灵音符"，装载前包络就爬升）。

代价：Logic 1979 → 2089（11%），BSRAM 4 → 5 块，slack +18.4ns；音色示范
频谱演化数据与修复前完全一致（听感零变化）。

### 2. 频谱峰值计数尚未跑通
用 32 个等间隔频率跑 FFT，目前只检出 1 个峰。
判断是 **FFT 加窗/阈值的问题，不是设计问题**——
因为验收 1 已经逐位证明了 32 个时隙各自独立正确。
（第一版栽在"峰间距 46.5 Hz 远小于 FFT 分辨率 152.6 Hz"，
把间距拉到 391 Hz 后仍只剩 1 个峰，阈值与分组策略需要再调。）

## 四、本轮修掉的真 bug：流水线错位一拍

```
sin3(post-t) ← tad2(post-t-1) ← 级1数据(t-2)
amp2(post-t) ← amp_eff(pre-t)  ← 级1数据(t-1)
```

`amp2` 比 `sin3` 新一拍 → 乘法把「上一个时隙的正弦」和「当前时隙的幅度」配到一起。

**症状伪装成"相位推进快了 16 倍"**——我用 `mul=16` 拟合竟然 600 样本 0 处不符，
差点接受这个错误解释。是"直接测相位存储"才推翻它。
**修法**：加一级 `amp3 <= amp2`。（`osc_core` 没这问题，因为它的幅度是组合直通。）
