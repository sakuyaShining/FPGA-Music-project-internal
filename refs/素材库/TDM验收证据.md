### 试过的修法：读侧加/减 `3×inc` —— **两个方向都是 2464/2481**

原因：**`3×inc` 折算成查表步进不是整数**。
对 slot 0（`inc=11811`）：`3×11811/65536 = 0.54` 步 → 地址在 0/1 之间频繁跳变
→ 几乎全错 ✗

**⇒ 正确修法不能在"查表地址"上做平移**，而要让**相位与幅度处在同一条时间轴上**。
即：把 3 个周期的偏移从**时基**上消除（例如让幅度也延迟 3 个周期，
或让相位的推进比幅度早 3 个周期启动），而不是在地址上补。

## 遗留问题：最终定位（架构级）

**现象**：包络打开时，起音段前 2.5 ms 有差异（最大 4.66% 满幅，中位 0.36%）。

**机理（已完整查明）**：

> `slot_addr = sc + LAT` → 时隙 s 的读在 `sc = s-LAT`、写在 `sc = s-LAT+1`。
> 两者跨周期边界当且仅当 `s - LAT + 1 ≡ 0 (mod NSLOT)`，即 **`s = LAT-1`**。
> **每个周期必然有且仅有一个这样的时隙**（LAT=4 → slot 3）。
> 该时隙的正弦用的是**本周期刚写的**相位，其余时隙用的是**上一周期的**
> → 它相对其它时隙**领先一个周期**。
> 包络恒定时这只是整体延迟（被延迟搜寻吸收，"包络关闭时逐位一致"）；
> 包络变化时相位与幅度的相对关系被打乱 → 起音段对不上。

**证据链**（全部实测）：
- slot 3 单独测 `0 / 499`，延迟 1 拍；slot 0~2 单独与组合 `0 / 498`，延迟 2 拍
- 二者一组合即 `345 / 499`，且**移动预置窗口释放点后数字一个不变** → 与窗口无关
- 32 个时隙单独测**全部逐位一致**

其余时隙：slot 0~2 写在 `sc=29,30,31`；slot 4~31 写在 `sc=1..28` ——
都在释放之后的同一周期内，独独 slot 3 与释放同拍。

### 下一轮的做法（非常明确）

把预置窗口的释放点**从 `sc=0` 挪开**（例如释放到 `sc = NSLOT-1`），
让"第一次正常回写"落在 slot 3 之外的时刻；或者给释放沿加一拍缓冲，
使 slot 3 的写与释放错开。

**这是十八轮以来最精确的一次定位：从"某个范围"缩小到了一个时隙、一个拍号。**

### 当前状态（核心验收全绿）

预置窗口在测试台暂时关闭（RTL 分支保留），包络关闭时 8 种掩码全部 `0 / 500` ✓

按第十六轮定位的根因（**相位起始偏移**）下药：
`pclr` 期间把相位**预置为 `inc`**（而不是清零 / 冲刷 / 冻结），
因为写的是同一个值，**这个操作是幂等的 → 窗口边界理论上无所谓**。

| 0 | 450 |
| 1 | 900 |

而且不符数随 `k` **线性增长**（450 / 900 / 1351 / 1801 ≈ 450×(k+1)）——

其影响随频率线性放大。**这是"偏移"而不是"逻辑错"的典型特征。**

### 下一轮的直接切入点（很明确）

让相位预置与包络归零**用同一个时隙索引**，并且**窗口严格覆盖整数个周期**：

2. 窗口起点也由 `sample_en` 对齐（不只是终点），使其成为整数个周期
3. 然后重新扫单时隙 0~31 + 多时隙 8 种，全绿才算过

★ 关键认识：**"幂等"只在"覆盖了全部时隙"的前提下成立** ——
前几轮的清零/冻结失败、这一轮的预置部分成功，都指向同一条：
**窗口必须完整覆盖所有时隙，且相位与包络必须同步覆盖。**

|---|---|---|

  （而不是靠"第一次回写"隐式决定）；或让相位与包络**共用同一个
  "第一次推进"节拍**（例如统一在 `sc==0` 打一个全局推进使能）

★ 关键：**这次要动的是相位侧，不是包络侧** —— 前几轮一直在包络侧打转，
方向反了。

## 遗留问题（如实记录，未解决）

### ★★ 已把范围锁死到"slot 4 及以上"（本轮最大进展）

> 因此差异**只可能**出在"包络打开才生效"的那条路径上，
> 而包络的**存储轨迹已被逐拍证明与并行完全一致**（第八轮）。

| 项 | 状态 |
|---|---|

| 包络关闭时全部时隙 | ✅ 逐位一致 |

## 修了什么（三处 RTL + 一处测试台，根因链见《TDM进展与未解问题.md》§3.1）
1. **装载样本边界对齐**：load 口改写"待生效区"（pv/pp/pg/pi/pa 存储阵列 +
   周期奇偶标签），各时隙在装载后第一个完整样本周期统一消费。
   两个陷阱：奇偶翻转点必须在 sc=NSLOT-1（周期末尾）；判定用读取时刻奇偶（ppr1）。
2. **累加窗口旋转 LAT 拍**：清零 sc=LAT、锁存 sc=LAT-1、sum_raw 改寄存器输出。
   旧窗口 [sc0..sc31] 混两代状态（slot 0~3 读上一周期、slot 4~31 读本周期），
   旧版能过解析真值纯属装载起点恰落在组边界的幸运。
3. **门初值 1→0**：废除"上电幽灵音符"，起音只由显式 load_gate 0→1 沿触发。
4. **测试台激励对称化**：并行侧 inc/amp/gate 改寄存器（STIM_INC_AT=0/Gate_AT=1），
   与 TDM 装载同为"显式音符事件、样本边界生效"。
