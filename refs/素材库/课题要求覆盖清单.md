**延迟的构成（架构上可算）**：
```
控制采样 → 音符事件 → note_map 装载 16 拍 → 待生效区（下个样本边界）
→ 流水线 LAT=4 拍 → 累加 → 输出锁存
→ I2S 一帧（32 BCK）
```
在 27 MHz 下：16 + 4 + 32 ≈ 52 拍 ≈ **1.9 µs** ✗ 加控制侧去抖（若 1 ms）✗ **总延迟约 1 ms，远低于 10ms** ✓
**⇒ 理论余量很大，但必须实测** ✗
