## 二、当前设计规格

```
4 声部 × (8 泛音 × 独立相位累加器 + 独立 ADSR)
  → 混音（增益 + 饱和）
  → I2S（16bit / 46875 Hz / BCK 1.5 MHz）
  → 板载 MAX98357A
```

| 指标 | 数值 |
|---|---|
| 振荡器数 | 32（4 声部 × 8 泛音） |
| 输出采样率 | 46875 Hz（27 MHz ÷ 18 ÷ 32，全整数零抖动） |
| **吞吐量 = 振荡器数 × 采样率** | **1 500 000 osc·Hz** |
| Logic | 13362 / 20736（65%） |
| Register | 4459 / 15750（29%） |
| BSRAM | 32 / 46（70%） |
| DSP | 24 / 24（100%） |
| 关键路径 | 24.76 ns / 37.04 ns（slack **+12.3 ns**） |

### 已知限制（如实记录）
1. **包络参数是编译期常量**，不能运行时改。
   原因是它们要被 32 份包络实例使用，做成寄存器会直接撑爆器件（实测 26226 > 20736）。
   音高与幅度是运行时寄存器 —— 这正是 M6 与「多音色」所需。
2. **UART 引脚尚未指定**（需对照 Tang Nano 20K 原理图确认 BL616 的串口脚）。
   已开内部上拉，悬空时读高电平 = 空闲，不会误触发写。
3. **DSP 已 100%**、BSRAM 70% —— 全并行声部数的天花板约 5 个。
   再往上必须走 TDM。
