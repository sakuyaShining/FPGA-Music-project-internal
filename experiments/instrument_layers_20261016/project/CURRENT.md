# 当前实施入口 · 四槽运行时表与双层原型

整机**部分实现**。源自69号（其来源为engine-safety `683db4834a031baca217b9e3ae7a0369644b8935` / 原码`a7427ed`），主目录HEAD仍为`fe326ad9505c94f46f9236bf7f9bfc3b5f1b9a12`；原实现、GUI和全部旧实验保留。

本轮限定数字范围**已验证**：四槽各16分量独立提交、两层同音独立声部、逐指一对多滑音、释放身份与抢占隔离、已响声部保留原配置、理想595/RC输入到双层PCM，以及旧PCM/I²S兼容。源文件与测试对应关系见`../delivery.json`和[复现入口](../README.md)。

联合综合20668/20736 Logic、12604/15750寄存器、43/46 BSRAM；余68 Logic、3 BSRAM。只是现有组合的综合，不是时序/引脚/全产品通过。三次失败变体的源与记录保留，未用覆盖旧快照的方法消除资源失败。

完整配置应用、四层同时、非易失保存、实体编辑、音频伴奏录放/事件曲谱和7英寸界面继续**待实现/部分实现**；必须先做资源优化与存储架构探针。音色表不支持逐层独立起音/释音/效果器，不能把原型称为完整通用乐器。已有小屏刷新压力和短音遗漏、模拟触控/≤10ms、AUX时钟/接线和约500元预算仍未闭环。

测试刻画到启动首个PCM未知、I²S数据512拍未知，选定/参考一致；4096拍预热后无未知且每512拍连续输出。这个启动边界不升级为实体上电验收，静音策略和板上复位仍待处理。没有连接COM、下载FPGA、试听、点屏、购料或打板。

下一步优先压缩分配/身份与表情元数据的资源，建立完整配置和录放所需的明确余量；随后接逐层包络、非易失保存和SDRAM/TF。两层采样级同时生效、整键抢占、切换和在奏编辑语义仍须独立设计验证，不替用户定案。
