# 运行时槽v1与时间语义

这是逻辑配置口的每分量88位格式，不是UART协议。四槽各16分量，写非活动银行，16项齐全才可提交。错误写/不完整提交不发布，原活动银行保持；取消草稿/CRC/传输超时/设备保存尚未接合。

| 位 | 字段 |
|---|---|
| 87..84 | 保留，必须0 |
| 83 | 独立包络标记；1使用本分量参数，0回退既有全局包络 |
| 82..79 | 起音分频shift，0..15 |
| 78..63 | 起音每次更新增量，1..32768 |
| 62..59 | 衰减分频shift，0..15 |
| 58..55 | 释放分频shift，0..15 |
| 54..53 / 52..48 | 释放m（1..3）/k（0..31） |
| 47..32 | 频率比Q8，1..65535 |
| 31..24 | 幅度0..255 |
| 23 | 保留，必须0 |
| 22..7 | 延音Q15，0..32768 |
| 6..5 / 4..0 | 衰减m（1..3）/k（0..31） |

core的待生效与当前epar元数据均由31位扩到71位（只在INSTRUMENT_ENV=1时），包括40位扩展、8位起音标签与23位原包络。包络和原参数按既有时隙消费规则一起生效；release-only保留当前参数，新ON的起音标签触发再激励。不开新选项时仍为31位，逻辑路径保持。

16分量提交串行于音符接受，避免半份音色被读到；不声称不同层/所有分量必在一个共同的采样瞬间完成装载，沿既有装载时序。发布后的旧音已经保存自己的数据，不继续引用可改写槽银行。

全局15位包络帧计数每个合成样本更新，stage-one同步读取时一并快照。ATTACK/DECAY/RELEASE各按自己的shift每2^shift个样本推进一次；不推进时保持状态/电平，但ON/OFF事件始终优先处理。SUSTAIN和IDLE不受分频阻挡。最大分频与两次回绕在单独测试中检查。

编译器沿原schema1的毫秒量挑选整数增量、m/k和shift；量化报告给出名义时间与首次等待上界。53kHz附近短时间只能取整数采样；长时间可能有较大的分频相位等待。释放以满幅32768到固定cutoff100估算，实际起始电平不同，时长也不同。时间映射属于可调整适配设置，不作为最终音乐交互定案。

击发模式通过将延音设为0使泛音在按住时也自然衰减；持续模式使用设定延音；混合模式逐分量选择。该实现是加法合成的包络激励，不是钢琴/弓弦等声学模型已完成。

schema1目前没有逐分量频率比编辑字段，编译时沿所选内置预设比率；低层v1词可表达独立比率。右手推子路径保持原性能修饰，不写回基础配置；独立颤音和每层效果器尚未实现，开启时拒绝编译应用。
