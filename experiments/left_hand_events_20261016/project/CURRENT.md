# 整机接合当前入口 · 左手身份链阶段

整体仍**部分实现**。本阶段接通了此前缺少的位置→音符实例→分配反馈→逐指音高；[实现与复现](../README.md)及`state.json`按真实证据记录各项状态。原68号接合区及产品源保持，未下载或接入实体传感器。

```text
六路RC输入 → 595扫描 → 校准/完整帧 → 26条位置/接触报告
                                          ↓
                           带世代的实例请求＋接收/完成反馈
                                          ↓
                     同音独立分配 → 延后绑定 → 逐指音高
                                          ↓
右手报告 → 分区推子/保持/平滑 → 32组×16分量合成 → PCM/I²S
                                                    └→ 小屏可视化
```

限定数字链路**已验证**：包括两个音位同MIDI独立控制、移动不重奏、分别松手、满32组抢占保护、失效/超时/校准处理、左右手同时控制、真实合成PCM和原I²S兼容性。RC模型只注入理想数字跳变，不能签收实体电极/噪声/覆盖层、实际屏显示、最坏≤10ms或听感。

当前联合资源：串行实例查找候选19621/20736 Logic、41/46 BSRAM，未PnR。余1115 Logic、5BSRAM仍须容纳尚未接合的配置/分层、7英寸显示、EEPROM和TF/SDRAM录放，必须先做资源账或进一步优化，不能据此承诺全机单板。

下一步是最小完整配置的设备应用与双层实例原型，并为录放/存储和7英寸接口安排联合资源验证；随后接非易失保存、实体编辑/故障提示、实际引脚/PnR及小样/实测。保持四预设自定义、同音分层、录好伴奏后现场演奏不同旋律、双屏与AUX等目标，约500元成本仍未闭环。

每条滑条当前只表示一个接触。音位25/26端点、八度在奏切换、手势显式跨区、强调曲线/分组和PCM作用范围等仍按用户决定收口；故障超时常数及抢占后等待真实松手属于可替换原型策略，不能冒充用户已经试听确定的最终规则。
