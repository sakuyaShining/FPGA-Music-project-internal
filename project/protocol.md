# 整合候选协议v1.1

当前 `PROTO_VER(0x7F)=0x11`；默认表、RTL、GUI与上电测试已同步。
来源为6e70的45号修订，原文归档；诊断D2接口不属于本产品协议。

曲谱：停止 `0x50=0` → `0x73=0` 清写指针 → 成对写 `0x70` 音符、`0x71` 拍数
→ `0x73=N` 提交1～63步 → `0x50=1` 播放。0x72保留。停止发一次当前音的off；重复停止不重复off。

整谱：`0x5A=0x80` 开草稿事务 → 依次写 `0x58` 索引与 `0x59` 值
→ `0x5A=0x01` 替换或 `0x00` 叠加提交 → 需要改变在奏音时显式写 `0x63=0xFF`。
整幅谱RAM发布等待note_map空闲；引擎装载仍逐槽消费，不能称整组/整和弦原子更新。
刷新保留对应组原力度已测；完整包络/释放音行为和右手手势仍待联合验收。

主机在发送v1.1事务前读0x7F。旧码流未确认v1.1时拒发，而不是猜测兼容。
配置文件可以保存设备尚未实现的草稿字段；文件校验通过不代表设备能应用三方式、自动表情或完整配置。

四源队列丢弃计数回读为UART 0x74/75、定序器0x76/77、pads 0x78/79、排针0x7A/7B；
0x7C为丢弃状态位。满时的事件拒绝可观测，不宣称无限输入速率不丢。
