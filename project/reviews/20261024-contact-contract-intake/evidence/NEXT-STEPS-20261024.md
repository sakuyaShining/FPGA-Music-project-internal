### ② v1 实物验收（1–2 小时，板子在手）

91 号五栏验收里，**唯一空着的一栏**是「实物验收 ❌ 零」。它不需要等 PCB、不需要等 codex：

```
烧 impl_pnr_board.fs（verify 报 0x00006020 是预期，忽略）
  → python tools/board_velocity_check.py dump
  → 读到 0xD0=0x75 = 码流在跑
  → 按 pad[0] 听 C4
  → 测触摸到发声延迟（目标 ≤10ms）
```

**这是整个项目当前最大的不确定性，而且成本最低。** 做完之后 v1 才能从「可烧录」变成「已验证可烧录」。
