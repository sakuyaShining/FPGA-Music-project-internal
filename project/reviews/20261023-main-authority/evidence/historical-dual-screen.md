## 4. 真实产品顶层必须怎样接合

当前已读源集中**不存在覆盖完整要求且绑定当前PCB的产品顶层**。本轮没有用常量、假触摸输入、奇偶观察器或未连接输出拼出“全功能PnR”。真实产品连接合同如下，当前缺口都有实际数据路径后才具备产品PnR资格：

1. J5/J6六路SENSE→同步/RC计时→物理节点映射→26音位及独立八度档→带实例ID的事件/四层分配→32组×16分量。26×4不是104个常驻声部；32组共享，四层无尾音时最多8个完整组合，尾音也占组。抢占/分层启停细则须显式定义，不能用未实现的双层限制替代完整要求。
2. I²C触摸报告→整帧触点身份→分区推子→全和弦增益/保持/RESET；I²C还服务EEPROM和PCM5122，必须有优先级、超时和后台提交，EEPROM写周期不能阻塞演奏。
3. 共用BUS_SCK/MOSI由595、165、ILI9341和RA8875事务仲裁；BUS_RETURN经现有选择器区分165与RA读回；按键/旋钮从165解码。U8高两位必须由运行时复位服务保持，不能扫描时写00。06df的rc_mux_scan_hw及25/26音位映射候选已有隔离正/负测试，尚未接合此顶层。
4. 现场PCM和独立回放PCM在采样边界混音→原I²S三线同时送功放/DAC；两条流独立控制、禁止回放关闭现场。录音对象/右手是否作用回放等未决语义保持参数化待定，不能默认为方便实现的规则。
5. SDRAM环形区↔SD卡扇区/文件；带时间戳事件与PCM建立一致保存/恢复合同。实体编辑的草稿、运行配置、持久化记录、正在发声实例分别管理。
6. RA8875显示推子/编辑/曲谱，ILI9341显示完整音乐可视化；不合屏、不缩小推子。FPGA生成控制与绘图命令，利用**现有候选RA8875**的显示RAM/图形引擎，不增加计算MCU。[RAiO原厂资料](https://www.raio.com.tw/en/RA8875.html)支持800×480、768KB显示RAM、图形加速与SPI；它不替代FT5316触点控制器。此说明只论芯片能力，具体模组出货接口仍待核。

当前捕获为17个面板GPIO＋3路复用I²S，逐脚唯一；UART、板载TF及SIP SDRAM另列。不能把SIP55端口计成55个外部排针，也不能把LED0..5保留作独立调试输出——当前PCB已经复用这些脚。86号CST只有14个外部脚，尚未覆盖真实面板/TF/双屏/I²C/音频时序，故其即使通过也不是上述产品顶层。

左手两帧确认的3T包络是按逐行采集、整帧发布及最坏相位推导，非新实测。正常触摸、移动、释放和传感故障恢复应分别列出延迟，不用100ms故障看门狗替代正常≤10ms。右手报告率情景不能套用旧GT911或新FT5316未取得的规格。I²C EEPROM页写要后台、触点优先，DAC启动配置也不可阻塞运行时触摸。

512拍全音源样本周期、事件处理队列和显示50ms是三个不同调度窗口。控制器瞬时耗时低不等于排队最坏延迟低。SDRAM时序沿用原SDC：正常输入max/min6.5/1ns、输出max/min3/−2ns、setup/hold不确定度0.5/0.2ns；加严10/1ns、4/−3ns及1/0.5ns。精确SIP die、封装/温压仍待绑定，保持原约束不放宽，不新增内部/SDRAM false path。

参数容量：当前四槽表704B、双运行库1408B，加同规模草稿仍远小于32KiB EEPROM；完整schema、日志冗余/CRC/掉电提交须计入。五分钟16bit PCM约31.64MB只是例子，不是用户冻结时长；SDRAM不是非易失保存。曲谱/事件数据需另算峰值，不能以平均PCM字节率代替。
