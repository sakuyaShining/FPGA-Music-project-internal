# 产品规则待冻结清单

用户已确认PRODUCT-SPEC的产品复述准确并授权推进；本页只列剩余边界，不重新打开已确认目标，不把建议写成批准。

## 已明确，不再作为可裁剪项

- 曲谱播放时可继续现场演奏，形成四手联弹效果；不是只能播放或只能演奏。
- 达到复音或声部资源上限，丢掉最早开始发声的音符。以完整度加权抢占的旧建议不能覆盖此决定。
- 不因此自动限制播放期间最多两层；共享32组×16分量、四槽目标仍保留。
- J10保留、J11取消；独立核心功能、实体编辑、非易失和实际声音录放仍是目标。

## 需要形成合同的边界

| 条件 | 已知依据与未定边界 | 建议及判据（尚未批准） |
|---|---|---|
| 资源耗尽 | FIFO基本顺序已定；多层音符、释放尾音、同拍曲谱/现场事件和不足多组时的事务边界未写全 | 以完整音符实例为单位回收其所有层，跨来源按起音序号比较；空闲或已自然结束的组先用；同拍排序确定且可复现。需验证满32组、尾音、换代、迟到OFF不误杀新实例；不擅自赋予某来源优先权 |
| 层选择/移调/归一 | Q组合有直接讨论；短/长按切层、在奏音变化、层增益和移调越界还需精确范围 | 先把原问答映射成事件/状态表，再确认；新增/撤去层不得重启已有音或留下孤立层；不能用降低复音数掩盖实现问题 |
| 编辑/保存 | 编辑→选槽→编辑激发与音色、独立操作键、断电保存已定；试听、应用、取消、换槽和在奏音更新时机未统一 | 草稿/正式定义/运行修饰/在响实例分离；保留16词完整提交。明确保存反馈、断电中断和错误恢复；不能把UART或非活动bank直接当完整编辑器 |
| 左手与力度 | 两排逐音滑条/独立八度、84节点能力已定；25/26端点、八度切换影响和力度标定/默认曲线未完全冻结 | 明确演奏中的换档是否只作用新音；全规模多指/串扰/延迟测试；不把电容变化称为测得压力。力度默认值须单独接受，不以旧黄金强制关闭表达 |
| 曲谱、音频与右手 | 曲谱播放＋现场和PCM录放均要保留；曲谱事件格式、播放期间右手控制对象、文件与时间基准未统一 | 曲谱事件进入合成音符管理；PCM播放走音频混合，不假装能从PCM中FIFO删除某个音符。定义右手对现场/曲谱的作用、暂停/跳转/停止时OFF与尾音处理，保留同时演奏能力 |
| 实体接口与制造 | 平台、现有PCB接口、J10路线和独立操作已定；精确屏/CTP/线束、按键映射、供电和AUX装配需与owner关闭 | 不自动采用16键/PCF8575或删除功放；以同版原理图/PCB/BOM/CPL核对，最后做实际触摸/发声/断电/装配验证 |

实现可先推进不依赖上述选择的可逆诊断和独立单元验证；涉及产品听感或交互的选择须提交清晰建议与反例供用户确认。最终码流需要完整顶层、明确规则、功能回归、同版PnR/STA及已声明的实体测试边界，不能只交一个能综合的fs文件。
