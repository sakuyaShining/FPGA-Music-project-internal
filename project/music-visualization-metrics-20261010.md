# N-12 三视图架构与性能评估清单

2026-10-10。演奏轨迹＋波形＋频谱为当前功能组合；所有应用计算仅用Tang Nano20K FPGA。本文是评估方案，数值建议尚未冻结，不是实测或用户批准的功能缩减。实现状态仍为未实现；已有04数字音频证据继续保留。

## 架构结论

现有“旁路分析、共享FFT、小数据缓冲、按坐标渲染”方向合理，但没有同配置综合和联合PnR，不能称最优。最优须明确目标函数：在不破坏声音/触控时限的前提下，以可用资源实现足够的可读性、响应和频谱区分能力。LUT最少、延迟最小、频谱分辨率最高通常不能同时达到。

推荐基线分为两个来源，使用同一FPGA时间基准：

1. 已接受事件、分配结果、实际音高状态→带指/声部世代号的轨迹历史。记录实际执行而非主机意图；显示释放尾音与手指离开须区分。不能从混合音频FFT反推所有触点身份。
2. 最终音频数字节点→只读采样分支→波形min/max桶与峰值统计；同源样本→加窗→共享定点FFT→功率/频带→频谱柱。明确是干声、效果后还是I²S量化后；若显示“送到DAC的数字音频”，应对齐最终I²S采样位宽与时间。
3. 数据版本/时间戳→一致的显示快照→FPGA渲染→显示器。保存波形桶、轨迹和谱柱，不默认保存整屏RGB。波形视觉抽点不能不经滤波直接拿去FFT；频谱降采样必须有抗混叠滤波。

分析和显示不能阻塞音频时隙，也不能反压实时触控入口。视觉忙时明确统计丢帧、数据年龄和队列溢出；note-on/off等生命周期事件不能静默丢弃。移动事件合并必须有可验证的最大误差和最后状态保证，不作为默认已批准策略。

候选比较至少包括：同采样率1024/2048点FFT；带抗混叠滤波的低频分析支路；共享蝶形与可配置低资源FFT IP；直接扫描渲染与小块更新显示。不自动选择SDRAM整屏或升级FPGA。Gowin IP是候选，不把其他器件示例占用当作本版结果。

## 指标及测量定义

硬约束来自用户和既有N-10；下列响应/精度/持续时长数值为工程建议，待显示硬件、频谱用途和联合资源评估后冻结。

| ID | 指标 | 定义、判据与测试 |
|---|---|---|
| V-01 | 计算位置 | 触控、轨迹、波形分析、FFT、频带及实体渲染均在Nano20K；构建输入/网表/外设功能审计。电脑参考模型仅作验证 |
| V-02 | 对音频的影响 | 同一确定性事件序列、相同采样点比较开/关可视化输出逐样本一致；最大负载下零音频欠载、零新增超时、无采样节拍改变。调度断言与板级时钟观测分别留证据 |
| V-03 | 触控实时性 | N-10实际触摸→真实音频输出最坏≤10ms，联合三视图与最大输入负载实测；模拟触点不能替代实体触摸。统计最坏、P95/P99和测试样本量 |
| V-04 | 接受事件→首个可见轨迹的延迟 | 包括状态提取、排队、渲染、显示扫描；记录P50/P95/最大。建议先评估P95≤100ms；不能只测内部寄存器更新 |
| V-05 | 音频变化→首个可见波形/谱变化的延迟 | 分别记录窗口年龄、分析时长、平滑、显示等待；波形先评估P95≤100ms；短窗频谱先评估P95≤150ms，长窗低频另报。不把窗口中心/结束时间混用 |
| V-06 | 数据更新率与屏幕刷新率 | 分别测轨迹数据、波形、频谱的独立新帧/秒，以及屏幕扫描刷新率、重复帧和抖动。建议评估20–30次/秒新数据；60Hz屏幕不等于60次/秒FFT |
| V-07 | 三视图时间对齐 | 同一计数器、样本索引、事件时间；频谱注明窗口起止/中心和群延迟。报告对齐误差；建议输出数据时间戳以音频采样周期为单位，屏幕可见误差另计 |
| V-08 | 轨迹身份正确性 | 同音多指、反向移动、释放尾音、重分配/偷音、ID重用、复位均不串线；确认note-on/off/绑定等关键事件完整。32组不能等同32实体触点数量 |
| V-09 | 轨迹容量与精度 | 并发轨迹数、历史秒数、更新频率、时间/音高量化、横纵像素误差及内存上界。按最终输入事件峰值和音高接口步长测，不从UART平均速率猜峰值 |
| V-10 | 波形来源与幅度精度 | 明确采样节点、采样率、24bit内部或16bitI²S、满幅单位。测试零、负数、满幅、剪切、低幅度；量化误差与缩放误差分别统计，避免自动缩放把噪声画成大信号 |
| V-11 | 波形时间跨度与峰保持 | 可见窗口时长、samples/column、触发稳定性、脉冲是否被min/max保留。用单周期脉冲、阶跃、周期单音和释放测试；不能仅每列取一个点 |
| V-12 | 波形统计质量 | 若提供峰值/RMS/剪切计数，定义窗口、单位、舍入/饱和；与同批原始样本软件参考对照。建议幅度/RMS误差先评估≤1%，近零另用绝对误差阈值 |
| V-13 | 频谱频段与真实分辨能力 | 定义采样率、滤波/降采样、N、窗、有效带宽、栅格Δf及等效噪声带宽。用等幅双音及强弱双音测最小可区分间距；峰值插值精度不能代替双音分辨率 |
| V-14 | 频谱幅度准确度 | 定义幅度谱/功率谱、单边缩放、窗增益补偿、dBFS参考、DC/Nyquist处理；整bin与非整bin扫频。建议先评估单音峰值误差≤1dB（指定幅度/频段），不能要求每个bin都≤1dB |
| V-15 | 频谱定点与动态范围 | 数据/旋转系数/累加位宽、逐级缩放、舍入、饱和、噪声底和弱分量可见范围；DC、满幅和弦、交替符号、低幅信号。建议先评估60dB可用展示范围，不把24bit输入当24bit有效精度 |
| V-16 | 频谱时间响应 | 窗口N/fs、hop、attack/release平滑、计算周期及队列等待分项测。显示“新谱”时附样本窗口；停音后消退速度可调但不可掩盖数据过期 |
| V-17 | 降采样与频带质量 | 如有降采样，定义滤波通带纹波、阻带抑制、群延迟；用折叠频率扫频测伪峰。频带最大值、能量求和或均值须明确；参数谱柱与实际测量谱分开 |
| V-18 | 屏幕与接口带宽 | 分辨率、颜色深度、三个视图像素预算、字体/线条可读性、显示总线有效吞吐、刷新方式及撕裂。I/O电平/引脚和音频/触控共享冲突审查；当前屏幕未选，不能冻结指标 |
| V-19 | FPGA资源与实现时序 | 分别记录增量及整机LUT/FF/CLS/BSRAM/DSP、RAM端口/利用率、实际时钟及跨域、setup/hold/TNS；最终组合完成布线且约束完整。保留后续触控和未实现音乐功能预算，不能用“利用率<100%”替代可布线证明 |
| V-20 | 稳定性与可观测性 | 满负载持续运行，丢帧/过期/溢出计数、恢复/复位、静音和异常显示；建议先评估连续60分钟零音频故障，视觉吞吐低于目标算失败而非仅计数通过 |
| V-21 | 产品独立运行与证据身份 | 无PC参与应用计算时三视图仍可使用；断开调试链接但保持正确供电进行验证。每次结果绑定源清单、参数、屏幕、码流SHA及测试输入；内部数字图不能签收DAC电压/听感 |

## 当前可计算的边界

当前采样率fs=27MHz/512=52734.375Hz。以下为推算，不是FFT模块实测：

| FFT N | 窗口N/fs | 频率栅格fs/N | radix-2复数蝶形数N/2×log2N |
|---|---:|---:|---:|
| 512 | 9.71ms | 103.00Hz | 2304 |
| 1024 | 19.42ms | 51.50Hz | 5120 |
| 2048 | 38.84ms | 25.75Hz | 11264 |
| 4096 | 77.67ms | 12.87Hz | 24576 |

FFT计算时间应测实际总周期/时钟，包括窗、存储访问、旋转因子、功率和频带汇总；蝶形数量不是总周期。显示更新间隔由hop、计算与传输共同限制，窗口长度不等于唯一响应延迟。

A4=440Hz与A♯4约466.16Hz相差26.16Hz，C2约65.41Hz与C♯2约69.30Hz相差3.89Hz。2048点25.75Hz栅格并不保证窗函数下能分开A4/A♯4，更无法凭这一参数承诺分开低音半音。1/3.89Hz约257ms只是约束尺度；实际窗主瓣和幅度差还影响分辨。不能同时默认“全频段低音半音分辨”与“全部谱变化≤100ms”。轨迹显示实际合成音高，因此无需靠FFT做音符识别。

现有115200/8N1传2048×24bit加标记共6145byte，线传时间约533.42ms，理想上限约1.87帧/秒，尚未计捕获/协议开销。当前协议用于快照/验证，不能充当20–30Hz实体显示链路。实体画面由FPGA直接输出；将来上位机显示可传已在FPGA生成的桶/谱柱，需独立带宽预算，不外移FFT。

显示带宽例：320×240×16bit×20fps=24.576Mbit/s仅像素载荷，尚未计命令和空闲；不能据标称SPI时钟直接保证帧率。800×480×16bit全屏需6.144Mbit，不能存在本器件片内828Kbit BSRAM中。

04诊断配置已验占用：Logic17800/20736、CLS9798/10368、BSRAM34/46、DSP9.75/24（工具单位），setup+11.111ns、hold+.214ns。它包含诊断功能，不是最终三视图产品预算；剩余资源必须与触控/音乐未实现项联合规划，不能全分给FFT。

## 如何判断架构更好

先冻结显示硬件与“观察音色/分量”或“精确区分相邻低音”的频谱用途；两者成本不同。记录候选参数集、资源、窗/滤波、延迟和错误，形成同条件对照，而非仅比较FFT点数。

验证顺序：资源/带宽账本→独立定点模型与RTL判据→候选综合→全功能联合PnR→确定性音频开关对照→满负载显示及实体触控/音频板验。电脑计算仅提供验证参考；产品的分析和渲染仍在FPGA。

资料：[Gowin FFT IP](https://www.gowinsemi.com/en/support/ip_detail/16/)与[用户指南](https://www.gowinsemi.com/upload/database_doc/2205/document/6287531082ddf.pdf)说明低资源结构与参数选择；[MathWorks pspectrum](https://www.mathworks.com/help/signal/ref/pspectrum.html)说明分辨带宽、窗主瓣和强弱邻近音的关系。本文数字来自当前采样率公式、明确的显示假设与本项目04证据，推荐阈值为本项目建议。
