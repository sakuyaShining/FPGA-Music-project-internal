# 触控前端决策与两种面板比较

日期：2026-10-10。对应N-01、N-02、N-10；用户本轮授权调研并做器件决策，面板形态选择“暂不确定，先比较两种”。
本次决定第一轮验证平台与候选排序；没有采购、投板或实物验收，不改变发声语义。源码仍为已验integration-20261010-04。

## 本次工程决策

第一轮选 **Infineon PSoC 4100S Max，CY8CKIT-041S-MAX套件**，用它比较“独立音键内滑动”和“互电容整面多点”。套件具体MCU为CY8C4149AZI-S598。官方套件含触控扩展板，可评估滑条、触控板及接近感测，有公开工具及示例。不能把套件现成示例直接当作25键、双手多指或10ms已验。[官方套件](https://www.infineon.com/evaluation-board/CY8CKIT-041S-MAX)、[套件指南](https://www.infineon.com/assets/row/public/documents/30/44/infineon-cy8ckit-041s-max-psoc-4100s-max-pioneer-kit-guide-usermanual-en.pdf)

面板原型增加触控采集MCU，FPGA继续负责音符、声部、音乐规则和音频合成。采集MCU只执行扫描、基线/滤波、坐标提取及输出带序号的输入帧；不在它里面复制合成器。这是本轮硬件架构选择。原因是可定制电极与扫描配置，而且当前完整板测配置CLS已用95%，不能假设FPGA还可无代价容纳大规模感测/追踪算法。

整面专用控制器备选 **Azoteq IQS9150**；先不购买两个完整平台。若PSoC整面追踪开发成本或稳定性不合格，再切专用控制器原型。左右手可分区或分控制器，但不先决定跨区滑动的音乐行为。

## 形态比较

| 项目 | 独立音键，每键可滑动 | 整块多指互电容面板 |
|---|---|---|
| 选音定位 | 键区域明确，容易盲操作；可做独立形状/触觉边界 | 音键是坐标区域，可更改布局；需要帮助盲定位 |
| 位置感测 | 每键多个电极插值；一块大电极只能较好判断接触，不直接给滑动位置 | Tx/Rx交点扫描提取多个触点坐标 |
| 所有权 | 不同键可天然分区；同键两指仍需额外检测，不能默认支持 | 必须维护触点ID，处理两指靠近/交叉/合并/离开 |
| 滑动范围 | 键内范围受几何限制；越界策略未定 | 可自由移动，但跨音区是否改音不由硬件选型决定 |
| 通道/布线 | 25键若每键3段已是75电极；右手8个3段区再24，加5设置点为104，是示例预算而非定稿 | 矩阵以Tx×Rx节点换取较少引脚，但扫描节点、追踪与覆盖层调试增加 |
| 扩展 | 可拆成多个模块，各模块并行扫；总线读取仍要计时 | 可拆左右两面板，避免一个控制器承担所有手指与面积 |
| 第一轮 | 4个独立滑动键，测4指反向移动、邻键与边缘；随后扩到全部目标区域 | 小型互电容矩阵，测4/5指、靠近/交叉/分别抬起；随后满尺寸双手 |

以上通道数是工程推算。84 GPIO不等于84个任意可用感测输入：专用电容、通讯、调试、封装与MSC分区占用必须按原理图复核，不能据总GPIO数决定片数。
官方设计指南区分自电容CSD与互电容CSX：整面CSD坐标会有多点鬼点问题；真正整面多点应选互电容，增加的交点扫描时间要计入预算。[Infineon触控板设计指南](https://www.infineon.com/dgdl/Infineon-AN234185_PSoC_4_CAPSENSE_touchpad_design_guide-ApplicationNotes-v02_00-EN.pdf?fileId=8ac78c8c8e7ead30018ee43d60a1036a)

| 候选 | 核实事实 | 决策 |
|---|---|---|
| PSoC4100S Max | 可编程CAPSENSE；上述套件提供滑条与触控板评估 | 第一轮共同平台；扫描时间、触点ID与满负载性能需实测 |
| IQS9150 | 官方支持最多7指追踪，触点在内存位置跨周期保持；I²C最高1MHz。超指上限会清XY数据；手册的典型10ms扫描示例不是最坏10ms保证 | 整面备选；单片不作为双手10指方案，左右分区再评估；IRQ/RDY窗口需专门驱动 |

旧47号FDC优先建议针对测量前端，本次按最新连续位置、多指身份与两种几何重新排序。旧证据不删除，也不把任何候选标为已达10ms。芯片的“触摸面积/强度”不等于真实压力或可靠起音力度，真测力仍需受力结构与独立标定。

## 延迟预算与接口

设计预算：扫描及必要确认≤4ms；输入帧排队/传输≤2ms；识别/映射/事件仲裁≤0.5ms；音频调度及DAC≤1ms；预留2.5ms，总计10ms。这些均是待测预算，DAC一项不能用FPGA样本周期代替实测。

原型帧建议含版本、帧序号、采样时间/数据年龄、触点数、触点ID、区域、位置、接触/离开状态与质量标志。触点开始/结束用显式事件，坐标更新不能冒充note-on；超时、NACK、复位和超触点数量需报告并撤销相关所有权。帧格式待驱动实现时冻结，不在本轮改音乐规则。

传输示例：10触点×6字节＋8字节帧头＝68字节，16位寄存器指针的读事务约(68＋4)×9/400kHz＝1.62ms，未含拉伸/START/STOP/软件间隔。仅用于预算，不是传感器现有协议或最终触点数。若两前端串行读取，要算合计；不够则独立总线并行或经核实使用更高速模式。

现有i2c_master数字契约已通过，但结果缓冲4字节，未接实际器件；大帧需扩为流式/RAM接收，并验证一致快照与错误恢复。不能因为I²C单元PASS就声称触控集成已完成。

## 冻结正式BOM的门槛

1. 用最终覆盖层、电极和供电测坐标线性、静止抖动、边缘、长按、湿手、手掌接近和音频功放噪声。
2. 同时测独立键4指与整面4/5指；扩展后测满左右手工作负载。确认ID不换人、靠近不合并误控、分别释放不挂音，同键多指能力如实记录。
3. 扫描在全部目标节点开启且有效滤波时达预算；包括首次触摸、空闲唤醒、最坏相位、去抖、I²C排队和音频输出。低功耗模式不能偷偷拉长首次响应。
4. 统一测量时间基准下测实际触摸→DAC，记录最坏值与分布；至少1000次多相位动作作为初轮，不能用平均值或有限样本当无限条件硬保证。明确温度/供电/噪声测试范围与最坏预算。
5. 原型记录确切器件、固件/参数、电极尺寸、覆盖层、通道开关、原始数据、时间戳、逻辑分析仪和音频波形；绑定版本。
6. 核对可追溯货源、封装/贴片、库存交期和完整报价后才冻结料号/片数/PCB。当前未询价或采购；国内供应未核实，不能编造价格。

结论：**现在选PSoC套件做双形态验证，保留IQS9150整面备选；正式量产BOM在几何、满负载时序与噪声验证后冻结。** 这是有明确进入/退出条件的器件决策，当前没有一款已获得本项目实物≤10ms验收。
