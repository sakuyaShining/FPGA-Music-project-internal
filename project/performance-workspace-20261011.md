# 键盘演奏工作区与实际波形

2026-10-11，用户明确要求补充键盘演奏工作区并观察实际音乐可视化。当前源integration-20261011-02，共228输入，仅主机GUI改动；原01源和04FPGA证据保留，RTL/约束未改，不下载新码流。

第04页改为“演奏与观察”：Z/X/C/V/B/N/M/逗号对应C4/D4/E4/G4/A4/C5/D5/E5五声音阶；可同时按键、鼠标点击、上下两档八度、力度1–15。松键释放按下时锁定的音符，切换八度不改变已按住音的释放目标。切页/失去窗口激活会释放按住音，另有释放全部128音符按钮。模拟后端只用于指令测试，无音频合成。

同页观察FPGA内部实际24bit波形：单次或约每秒一次连续快照，干声/效果后、显示放大、时间/来源与导出保留。命令状态清楚标为已发送，不冒充实际音符轨迹。频谱与设备执行轨迹仍显示待FPGA接口，不加入PC FFT；用户尚未批准PC分析模式。

UART是全双工。采样独占接收/寄存器事务；音符0x60/0x61写可继续发送，写互斥锁避免字节交错。所有其他命令在采样期间拒绝，配置timeout在流启动前完成，读回和关闭不可打断采样；采样错误停止连续模式并保留原始数据和历史快照。

39项主机测试与GUI自测PASS。真实COM6验证：初始无活动声部，用GUI键盘事件发送B/N（A4/C5），流接收过程中释放，on/off计数各增2，最终active=0，GUI按键状态清空；2048点全部非零，完整流6145byte，事务约0.703s。结果见[evidence/performance-20261011-02/board-check.json](evidence/performance-20261011-02/board-check.json)，原始流和截图保留。标签只能确认诊断配置，不独立证明码流SHA；内部数字样本不能代替外部DAC/听感。

当前输入不是完整钢琴半音键盘、MIDI设备或真实触控，多指音高/右手新语义尚未接演奏页。波形为快照，连续勾选不等于音频采样连续无间隙或20–30fps。真正轨迹/频谱需FPGA模块、协议、预算、联合PnR和关联验收。
