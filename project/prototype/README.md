## 接线前检查表

- [ ] 核对实际套件板版本、原理图与J10配置，将目标默认5V切为3.3V；万用表实测。
- [ ] 分别记录两板供电来源；USB电源输出不直接并联；信号共地。
- [ ] SDA/SCL/IRQ的实际上拉来源、阻值及电平已记录；未确定总线电容前不照抄固定4.7kΩ。
- [ ] PSoC为传感器前端，FPGA为音乐/音频运算核心；实验调试主机与FPGA不会同时驱动同一I²C总线。
- [ ] 连接器针号取自实际原理图/丝印，暂不编造FPGA引脚分配。
- [ ] BTL喇叭输出两端均不接地；接地式示波器地夹不夹在任一输出端。选择适当差分测法。
- [ ] 原型固定、导线短；记录电极尺寸/覆盖层/线长，移动接线即新实验条件。
- [ ] FPGA下载前check-build核对实际构建SHA；仅使用已授权SRAM流程，不按文件名猜版本。COM口测试单一占用，上位机保持可见。

## 每种形态共用实验序列

1. 空载基线；功放关闭/开启、USB供电及不同手掌距离作对照，不在同一数据集混条件。
2. 单指静止、沿滑条/面板往返、边缘、慢移/快移；记录位置单调性、抖动和质量标志。
3. 多指分别进入、反向移动、靠近/交叉、部分释放、全部释放、重新进入；记录ID误配、漏点、假点和身份重用。
4. 长按与快速重复；记录实际持续时间、基线漂移、释放确认及恢复时间。接触面积数据仅称强度/面积代理，不称真实压力。
5. 全部目标节点、实际滤波开启；记录满周期、空闲首次触摸与有效扫描最坏相位。小原型结果不能直接外推全尺寸。
6. 第一轮至少1000次多相位动作，逐次保存端到端延迟；报告样本数、P50/P95/P99/最大值及丢失/超限次数。有限样本的最大值不等于无限条件保证。

每次独立建`project/evidence/touch/<日期-形态-序号>/`，复制模板并填写。原始数据、失败、仪器截图/波形与固件文件不可覆盖。条件变化另开run。

## 记录模板

- `run-template.json`：器件、版本、工具、供电、电极、扫描参数、仪器与结果索引。
- `contacts-template.csv`：一帧一触点一行，保留传感器坐标和状态。无触点帧也留一行，contact_id/state可为空。
- `latency-template.csv`：一动作一行；所有时间单位µs并来自同一测量基准。缺段留空，不填0；无音频响应记missing_response。

CSV的计时字段是记录格式，不是尚未冻结的设备线上协议。不能混用MCU时钟与PC时钟后直接相减。

## 等硬件期间的软件落点

已核对当前源：`i2c_master.v`只读1–4字节、写0–2字节，寄存器指针8位；`finger_pitch.v`是组绑定后的表达端点，不是物理触点追踪器。直接把10点帧塞进现有I²C口不可行。

| 工作 | 实现前应确认 | 必需验证 |
|---|---|---|
| 前端采集固件 | 实际电极及官方API、扫描/滤波、报告能力；多点追踪算法支持范围 | 原始节点与坐标对照，满负载，空闲唤醒、溢出/复位可观测 |
| I²C长帧接收 | 帧长/地址、快照锁存、IRQ读/清顺序、最大拉伸与发布周期 | 末字节NACK、短帧/NACK/超时、更新中读不混两帧、停止释放总线 |
| 输入帧译码 | 版本/序号、ID/生命周期、坐标尺度、质量与错误状态 | 序号跳变、损坏、重复/乱序、复位不让旧指控制新组 |
| 分配结果与所有权接合 | 使用分配器确认的组，不能按MIDI音高猜；同音多指缺口单列 | 部分释放、重用、满队列拒绝、移动不产生新note-on |
| 产品顶层启用 | 新驱动/约束和FINGER_EXPR配置，当前tdm_ship仍未接实体前端 | 新源清单→关联/全回归→PnR→构建绑定→SRAM→实体输入与DAC |

这些是准备好的开发任务，尚未宣称驱动实现。实际帧协议待前端能力确认后冻结；右手权重/保持、三种发声方式等音乐语义继续按N编号由用户裁决。
