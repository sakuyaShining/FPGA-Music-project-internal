# 今天的台架实验：面包板、20K与仪器

**2026-10-10最新约束：只使用Tang Nano20K FPGA进行应用计算。以下PSoC固件/到货/接线步骤为历史计划，不能执行为当前原型路线。PSoC数量0，其他MCU及外部坐标/ID计算也不允许；新的原始测量前端、FPGA扫描与追踪须另建可验证实验方案。**


2026-10-10准备，**尚未执行**。预计60–90分钟；无仪器时只做1–3步。触控器未到货时，面包板本身不能验证多指触控。

用户修正确认已借到LED、不同接口杜邦线、面包板、几个音响及若干电阻，示波器和逻辑分析仪均未拿到，万用表当前可用性待确认。今天先做USB串口/内部数字测试；无万用表不开始新供电接线。仪器到位后按通道数测BCK/WS，三线同时采集须至少3通道或合适数字输入；不能把不同时间的三次采集当同一帧精确解码。音响类型和电阻阻值未确认，先不接音频负载或裸LED到GPIO。

## 1. 断电通断检查（15分钟）

拔掉开发板USB，面包板不接电。万用表选通断档，两表笔相碰确认蜂鸣；逐根测杜邦线两端，晃动接头排除间歇断开。检查面包板每组孔、中央沟槽、长电源轨中段是否连通；根据实测标3.3V/GND。拍照保存。开发板放绝缘底板上，面包板只接外围。

## 2. 单板与面包板供电（10分钟）

先只接20K USB。在实际板卡丝印和[Sipeed官方原理图入口](https://wiki.sipeed.com/hardware/en/tang/tang-nano-20k/nano-20k.html)确认GND与3.3V可接触位置。万用表黑线插COM、红线插电压孔，直流档测3.3V对GND并记录。

断电后才把已确认3.3V/GND用短线引到对应电源轨，再上电测远端电压。明显不符3.3V、USB反复断连或发热异常就断电检查。暂不接5V、未知GPIO与外部电源；通断档只用于断电电路。

## 3. 版本与串口（10分钟）

SRAM掉电会丢失；重新上电不能假设仍是04。D3/rev2标签也不能区分02/04。确认另一板测空闲后，在项目根目录核对源/构建并按已授权SRAM流程下载：

```powershell
python tools/scripts/project_version.py check project/versions/integration-20261010-04.json
python tools/scripts/project_version.py check-build project/versions/board-build-20261010-04.json
powershell -NoProfile -ExecutionPolicy Bypass -File tools/scripts/flash_20k_verified.ps1 -BuildRecord project/versions/board-build-20261010-04.json
```

失败即停止，不拿旧文件替代，不写Flash。保存终端日志；04码流SHA为`4f62b2e89b826e3dedfdecf58b09cec080e89c0039b181323775b4d8c09c3fdf`。

上位机先断开串口，再只读身份；COM6为此前实测口，以设备管理器为准：

```powershell
python -c "import sys; sys.path.insert(0,'tools/scripts'); from test_board_hardware import Board; b=Board('COM6'); print({hex(a):hex(b.read(a)) for a in (0x7f,0xa4,0xa5,0xa9)}); b.port.close()"
```

期望依次0x11、0xd3、0x02、0x20（32组）。一个串口仅一个程序打开；身份检查不能签收物理音频。

## 4. 有仪器再测I²S（20–30分钟）

登记仪器型号及配置，断电连接仪器GND、BCK、WS、DIN。同一仪器同时抓三信号。

| 网络 | 本版CST中FPGA封装脚号 |
|---|---:|
| HP_BCK / dac_bck | 56 |
| HP_WS / dac_ws | 55 |
| HP_DIN / dac_din | 54 |
| PA_EN | 51 |

**这些不是排针序号。** 还须按实际板版本原理图确认可接触测点；没有明确测点就停，不拿杜邦线碰细间距芯片脚。数字信号无需绕面包板。

逻辑分析仪3.3V兼容输入，实际同时采样≥24MS/s，先采20ms；示波器先10×探头、DC耦合、正确倍率，约1µs/div看BCK、10µs/div看WS，地线只接板GND。

当前顶层DIV_BCK=16、BCK_PER_LRCK=32、每声道16位：

| 测量 | 当前期望 |
|---|---|
| BCK完整周期/频率 | 约0.5926µs / 1.6875MHz |
| WS完整周期/频率 | 约18.963µs / 52.734375kHz |
| 一帧BCK数 | 32，每声道16 |
| 复位后稳定静音DIN | 零样本；复位首帧单独观察 |

不要把WS半周期当采样周期，也不要按旧文档用64位帧。用可见上位机确认协议、已验默认音色、效果旁路，然后低力度发A4（MIDI69）、保持约2秒、松开。观察DIN由零到数据再释放恢复，保存原始三线波形。

解码采用16位、有符号、MSB先发；左右为同一单声道。标准I²S一位延迟须按实测WS/DIN关系独立核对，不能因“能解出数字”宣布相位PASS。第一轮只确认频率、帧长、电平和数据变化；完整相位/样本精确比较留原始波形分析。旧36号方案的64位帧及内部观察“独立证明”不作为本轮判据。

## 5. 复位观察（10分钟）

保持一个低力度音，开始I²S采集，再按S1、松开。当前包装顶层为S1高有效，旧CST低有效注释不适用。

记录按下/松开时波形、活动音是否清空、串口身份是否能重新读取、重新发音/释放是否正常。初步手动5次，保存不一致；这不是完整复位时序验收。

## 6. 后续实物与记录

- 喇叭到货后断电接实际SPK+/SPK−，从低力度单音开始，再释放、四音和弦、换音色。BTL两输出均不是GND；示波器地夹不接任一输出，不直接接耳机/有源音箱输入。
- PSoC到货按[原型实验包](README.md)先独立扫描；默认5V先切3.3V并实测，尚未实现前端接口时不随意接pads。
- 当前04诊断顶层忽略实体RC pads，接裸线或铜箔不会自动发音。旧RC实验需要单独配置身份，不能冒充新多指前端。
