# 现有器材下的原型实验

2026-10-10。用户询问可执行实验，本文为计划而非已执行结果。已确认Nano20K、面包板、杜邦线、LED、若干未知阻值电阻及无标记裸喇叭；未借到示波器/逻辑分析仪，用户随后确认已拿到万用表，但没有临时电极材料。没有已购线路DAC、屏幕或选定原始触控前端。唯一应用计算资源Nano20K，电脑只作开发与参考验证。

已有05/05 powered-board内部数字检查、04板测15/15及100/100完整流保留，不为原型名称重复刷板或把这些结果当真实触控。04诊断配置模拟触点，不能直接连接电极后认为新版触控已工作。

## 不增加硬件即可开展

| 实验 | 方法 | 输出与边界 |
|---|---|---|
| 面板/整机纸样 | 按Nano实际尺寸、屏幕候选尺寸画1:1纸样；摆放双手、按键、3.5mm/USB和排线，分别比较独立键与整面；记录手指遮挡、手距和装配空间 | 支撑板外形、安装孔与连接器位置；不能证明电极电气/多指追踪 |
| 轨迹/波形/频谱数据原型 | 使用归档真实FPGA样本及确定性事件，在电脑参考模型验证显示定义，再实现最小FPGA旁路模块；与同一数据的软件参考逐项对照 | 验证符号位、min/max峰保持、FFT缩放、指/声部世代与时间戳。电脑图只是参考，FPGA实现才算本功能 |
| 可视化资源可行性 | 独立综合波形桶、事件历史及固定参数FFT候选，再与保留32组音频、未来触控预算联合评估/PnR | 得到真实增量资源与时序，帮助选择显示接口；没有屏幕时只签收数据计算，不签收实体显示 |
| 串口提速/结果传输 | 新实验源身份及新码流，逐级改FPGA和主机波特率；固定数据连续流逐字节对照、记录时长、错字节/超时、并发命令和队列溢出 | 得到实际可靠吞吐，决定上位机更新率。不能只改单端、自动更新BL616固件或覆盖04身份；下载和串口占用须独立核对 |

## 有万用表及材料后

1. 断电测杜邦线和面包板通断，再确认排针3.3V/GND与远端供电；辨认电阻。GPIO位置按官方板版本原理图和丝印核对，不能按封装编号找排针孔。
2. 外接LED可做单GPIO输出/接线验证，串联已确认合适电阻；或用已知偏置的输入做接触/释放测试。需要受控实验顶层和端口约束；不能把当前诊断端口盲接当可用输入。此实验只签收引脚/连接，不证明触控。
3. 用铜箔/铝箔制作可替换小电极，先做单通道FPGA RC充放电原始计数实验。旧pad_scan只是候选测量结构；新实验构建独立身份，保留04。测试无触、接触、离开、长按、邻近手、移动线缆、不同覆盖层/线长，保存原始计数及误触/漏触次数。可先计划50次接触/释放及60秒静置、30秒长按，均是实验样本量建议。
4. 在单通道有可重复信噪差异后增加相邻2–4电极，研究耦合与简单位置数据可辨识性。单点/少通道通过不证明最终全通道、多指或≤10ms；RC方法不能未经验证承诺互电容面板坐标追踪。若结果不足，作为退出该电气方案的证据，而非改需求。

## 当前不能完成

- 真实连续位置/多指追踪与满通道感测：前端、实验电极及FPGA算法尚未完成。
- I²S电气解码、音频输出电压/质量和真实触摸→声音最坏≤10ms：缺测量条件，内部时间戳不能替代完整物理路径。
- 裸喇叭发声实验：无标记阻抗/功率、未确认匹配连接，不能接GPIO、I²S或当线路输入使用；板载MAX需要合适负载/连接，3.5mm路线还缺线路DAC。
- 三视图实体刷新/可读性：屏幕未选定或到货，只能先验计算与候选带宽。

建议当前优先：纸样布局＋FPGA可视化资源原型，完成万用表基础检查、补小电极材料后做原始感测；随后冻结前端/显示/DAC接口，完成全机引脚/供电预算再画载板。先做小实验板，最终大板发出前必须有原始测量可重复性、目标通道预算、触点算法验证和电气接口依据。此计划不降低多指/32组或新语义需求，不把尚未验证项算完成。
