# 当前开发板与芯片要求：换板核对

**2026-10-10最新约束：唯一应用计算平台固定为Tang Nano20K FPGA。下文Primer20K规格比较保留为历史研究，换板或更大FPGA不再是当前解决资源不足的方案；禁止其他MCU或计算板承担触控、音乐和可视化计算。**


2026-10-10。用户提出队友希望换开发板；已提供Tang Primer20K及“1gDDR3、TinyMaix、Type-C、板载下载器，一个按键坏了”的描述。Dock/Lite底板、损坏按键归属/丝印与换板原因待确认；当前未批准迁移或采购新主板。

## 文档的三种口径

1. 竞赛平台：01号竞赛约束和[高云官方2026赛题](https://www.gowinsemi.com.cn/university/match2026)列Nano20K、Primer25K、Mega60K、Mega138K。其他高云板不能仅按同厂芯片自动判合规，需核实组委会认可。
2. 历史建议：01号开发方案立项时建议主Mega60K、辅Nano20K；07号架构候选又建议先Nano20K。这是早期建议/资源估算，不是当前迁移已批准。01号表的音频口、底板配置、价格和免费申请仍须按实物/官网复核。
3. 当前实现：CURRENT/design和已验构建明确Nano20K、GW2AR-LV18QN88C8/I7、27MHz、32音符组×16分量=512时隙。换芯片、时钟、DAC、约束后是新的板级配置，原证据仅保留作来源。

## 新板必须核对什么

| 项目 | 当前依赖 | 换板要求 |
|---|---|---|
| 平台与套件 | 已在手Nano20K | 准确型号、芯片、核心板/底板版本、赛事适配、完整供货与到货时间 |
| 逻辑/布局资源 | 当前04完整32组诊断配置较满 | 按相同源码/配置实际综合与PnR评估，不能只看型号的K数；为未实现设计保留可论证余量 |
| 片内RAM/DSP | 波表、状态、延迟线、乘法等 | 核对块大小、端口、推断/初始化与乘法器能力；片外DDR不会自动替代片内BSRAM |
| 时钟 | 27MHz，512拍/样本=52734.375Hz | 有适合时钟源/PLL与约束；若改频率，同步音高/时间常数/串口/I²C及相关表，不能只改晶振数字 |
| 音频 | MAX98357A板载I²S功放，当前16位双声道同内容，BCK/WS=32 | 实际DAC/Codec料号、配置总线、MCLK需求、支持采样率/格式、功放和负载；有耳机口不代表原代码能直接发声 |
| 传感器接口 | 新PSoC前端，PCB+I²C，3.3V，IRQ/复位/调试需预算 | 核对真正引出的兼容bank与供电、电平、针脚和总线。38个历史电极不等于需要38个FPGA GPIO |
| 编译下载/通信 | Gowin教育版、SRAM下载、板载USB-UART | 新器件工具支持、许可证、烧录器与驱动、串口电平/时钟/引脚；旧码流绝不能跨器件下载 |
| 工期与测试 | 内部10/31提交、11/4官方截止 | 迁移后仍要新源身份、PnR资源/时序/IO、构建绑定、数字板测及实体音频/输入；不挤掉验证窗口 |

当前Nano20K官方硬件：[Sipeed资料](https://wiki.sipeed.com/hardware/en/tang/tang-nano-20k/nano-20k.html)。板上有64Mbit SDRAM，但当前音频路径没有因此自动使用它扩效果缓存。

## 本版实际资源，替代旧估算

来源：`project/evidence/full32-hostfix04-20261010/pnr/record.json`，tdm_board_test、FINGER_EXPR1/BOARD_DIAG1、完整32组，place0/route2：

| 报告口径 | 使用/总量 | 含义 |
|---|---:|---|
| Logic | 17800/20736，约86% | 当前逻辑规模 |
| CLS | 9798/10368，约95% | 布局打包资源较满，不等于还有14%任意可用扩展空间 |
| BSRAM | 34/46，约74% | 片内块RAM占用 |
| DSP（工具报告单位） | 9.75/24，约41% | 与官方48个18×18乘法器数量不可直接混作同一单位 |

setup+11.111ns、hold+.214ns、TNS0，PR1014保留。该配置成功前发生3次未布通，失败证据保留，说明布局余量值得重视。资源数包含诊断观察器，不能无评估地视为最终产品精确需求或所有新功能都能装下的证明。

20K已验56/56数字回归、15/15受控板测、100/100流一致；真实触控、DAC/电气及端到端10ms仍未完成。更大芯片可能缓解资源/布线压力，但不会自动完成这些缺口，也不会自动增加复音/分量数。

## 条件建议与保留方式

### 本轮具体候选：Tang Primer20K

已按[官方规格](https://wiki.sipeed.com/hardware/en/tang/tang-primer-20k/primer-20k.html)、[官方规格PDF](https://dl.sipeed.com/fileList/TANG/Primer_20K/01_Specification/Sipeed%20Tang%20Primer%2020K%20Datasheet%20V1.0.pdf)、[官方例程](https://github.com/sipeed/TangPrimer-20K-example/blob/main/README.md)核实：

| 项目 | Nano20K | Primer20K |
|---|---|---|
| 芯片 | GW2AR-LV18QN88C8/I7 | GW2A-LV18PG256C8/I7，器件/封装不同 |
| LUT4 / FF | 20736 / 15552 | 相同 |
| BSRAM / 18×18乘法器 | 828Kbit、46块 / 48 | 相同 |
| PLL | 2 | 4 |
| 外部RAM | 64Mbit SDRAM（8MiB） | 1Gbit DDR3（128MiB），不是1GB |
| 形态/接口 | 小板及现有引脚 | SODIMM核心板加Dock或Lite底板；更多引出机会，实际可用3.3V脚须逐bank确认 |
| 音频 | MAX98357A功放 | Dock例程用PT8211-S DAC及耳机通路；Lite不列板载音频口，不沿用Nano喇叭接法 |

Primer20K没有增加本工程最紧的逻辑/片内RAM总量，不能保证解决CLS95%或布线压力；PG256封装下是否更好放置/布线需实际PnR。DDR3需控制器与缓存新设计，不自动替代现有BSRAM。TinyMaix和Type-C宣传不等于新音乐能力。

**平台待确认：**本次官方赛题适配表明确列的是Primer25K，未明确列Primer20K；它虽属Tang系列，不能由我们直接断言获准。主提交切换前需要核实赛事认可。当前Nano20K在明确列表内。

**按键待确认：**用户补充确认损坏发生在准备换来的Primer20K，哪颗按钮/故障方式和Dock/Lite仍不清楚；没有证据表明当前Nano损坏。若仅用户按钮损坏且无短路，可能维修/换按钮或单独接外部按钮；若是复位常按/短路可能阻断运行；若为下载器按钮则影响不同。需断电通断/实际原理图和基本下载/串口测试，不以一句“坏了”判整板报废。

建议现阶段保留Nano20K主交付路线；若Primer已在手可作为接口实验/备用候选，但换它不是资源升级。不直接把已验Nano码流下载到GW2A，不替换当前约束；迁移须重新验证时钟、复位、UART、音频格式、PnR及身份。

收到新板信息后逐项对比。若仅换同芯片载板，仍核对时钟/引脚/音频/下载差异；若换另一高云系列，增加存储/DSP推断与工具迁移；其他厂商另核实赛题平台。

继续保留20K已验分支、码流和台架。新板有明确收益、交期可行时，单独建立目标配置，沿用最新整合实现做验证；新板至少通讯、PnR和实际音频跑通后再决定是否取代主交付路线。当前不把“想换板”记录为已迁移。
