# R2：独立局部数字布局路线

当前待用户分配。先读[入口](../START-HERE.md)、[合同](../CONTRACT.md)、[验收](../ACCEPTANCE.md)。写`hardware/pcb-parallel/candidates/R2/`；独立从951读取实际几何，不以R1的阻挡解释为前提，不回写旧工程或正式板。

## 首个60分钟产物

交`layout-proposal.md`及实际坐标/对象变换表：U8/U9周边数字出口、MUX/ADDR0/ADDR1共同走廊、SCK/输入链预留、真实过孔与回流位置、供电桥与C8保护。至少提供一份可检验几何原型，不能只有示意箭头。允许提出声明的数字器件改位，未声明的PAD与接口保持。

## 主交付

1. 独立可复现的局部数字区候选，以K1三网完整可连接为目标，说明其余9网空间可实施性；所需焊盘/走线/过孔/铺铜变化全部列入ECO。
2. 触及IO848时核对47脚整体供电、宽度与C8短去耦恢复；不直接删共享供电换走线。供电与参考变化必须按E3合同计算、由V4独立查验。
3. 输出可编辑候选/生成脚本、`handoff.json`、`changes.json`、`results.json`、图及原始数据；绑定951或M0新发源SHA，不混用IOtail对象ID。
4. 与R1对比时使用相同约束和最终验证入口；路线选定后停止互斥开发，承担M0分配的剩余批次或卡点接替。

## 验证和退出

V4核对ECO前后逻辑网表/引脚不变、许可的几何变化、实际物理/参考/回流和原生可重现性，M0选方案。换封装/器件/换面需E3/V4专项审查；用户冻结接口/保护区/板框/层数等不因求解困难而自行更改。

两次同类失败或90分钟无新证据按合同提交BLOCKER。若局部区域确有经验证的限制，交具体扩大重构范围、受影响功能/对象和验证成本；不能仅声称“需要重画”，也不能未经决策直接重构全板。首轮独立设计完成后再读R1结论，避免共享未经验证的假设。
