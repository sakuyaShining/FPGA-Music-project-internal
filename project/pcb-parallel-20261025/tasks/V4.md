# V4：独立验证、反例与最终拒收权

当前待用户分配。先读[入口](../START-HERE.md)、[合同](../CONTRACT.md)、[验收](../ACCEPTANCE.md)。写`hardware/pcb-parallel/verification/`；候选与正式源只读，故障注入只在明确隔离副本。你不设计/修补待签核走线；若转任作者，相应独立验收必须换人。

## 首个60分钟产物

交检查入口、`baseline-review.json`与已发现/未检查清单。独立恢复951，核对SHA、PAD/网表、12开放网和原生工具能力。先重现已知失败，不能只有“脚本运行成功”。没有原生运行条件时写NOT_RUN及具体阻碍，不复用旧PASS。

## 建立可信检查入口

1. 原生四层重铺和严格DRC负责原生连接/间距/物理/网表检查；独立提取实际几何/网表核对必连PAD、跨网短路、供电和参考。复用公共解析库可行，但不能只调用作者同一缓存和相同检查结果。
2. 在隔离副本注入至少三类反例：切断必连段、跨网短路/间距冲突、混入错误源版本。必须抓到对应错误并保留原始输出；短路与间距可使用不同小反例。故障样本永远不能进入正式板。
3. 每次报告声明检查范围与未覆盖项、约束版本/来源、工具版本和命令、真实输入SHA、原始结果。检查器修改需重跑相应反例，避免为候选放松阈值。

## 各阶段产物

- G0：独立输入/恢复与硬件范围审阅，保留全域过期/漂移事实。
- G1：关键引脚/电压/工艺/供电/机械约束复核，有疑点返回E3。
- G2：对R1/R2按同一口径报告连通/间距/孔/参考/回流/电源/旧接触/PAD/ECO；既找假阳性，也识别启发式误拒。不能因允许数字器件改位而要求其坐标不变。
- G3/G4：新集成源逐版独立核对所有12网及保留网；检查真实重铺、严格DRC、保存关闭重开，报告绑定实际最终SHA。旧例外逐项复核，不自动豁免。
- G5/G6：独立查看Gerber/钻孔/层对齐，BOM/CPL逐位号和方向对账，清洁目录恢复；由下载的精确远端提交核对交付包哈希。给出`final-review.json`和明确拒收项。

每个被拒候选交最小反例、对象ID、位置/单位、触犯判据和重跑方法。不能只写“有风险”；V4可提修复方向，但不在同一次验收中亲自改板后自签。

完成条件：检查入口已被故障反例校准，所有最终必检项PASS、无隐藏NOT_RUN，制造包与Bfinal一致。某路线BOUNDED_NEGATIVE只关闭实验；全项目G6未过时V4不得宣告PCB完成。
