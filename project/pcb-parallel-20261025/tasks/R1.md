# R1：最小改动路线与可复现诊断

当前待用户分配。先读[入口](../START-HERE.md)、[合同](../CONTRACT.md)、[验收](../ACCEPTANCE.md)。写`hardware/pcb-parallel/candidates/R1/`；不得写正式板、R2目录或checkpoint。用户分配后先登记源提交、工作树和首个实验。

## 首个60分钟产物

交`hypothesis.md`、可重跑诊断入口、输入SHA和至少一个对照结果。区分“启发式裁剪造成的不可达”与“实际异网铜/孔/参考造成的不可达”。参考`project/reviews/20261025-pcb-sync-plan/p1-source-review.json`；旧physical-port脚本以routeRegions开始，旧零端口不是全板无解证明。

固定其他硬约束，对单层导引裁剪做有/无对照；展示连通域、真实阻挡对象ID和实际几何。不要把邻近对象推断为阻挡原因；不得只扩大旧窗口或无限提高采样。离线IOtail与951差异必须完整声明，不能冒充原生输入。

## 主交付

- 可复现候选生成入口及完整修改清单；完整K1（MUX_DISABLE、ADDR0、ADDR1）连通方案，同时预留SCK/输入链及K3出口。局部段可作中间产物，不能签G2。
- 真实铜、孔/环、间距、参考/回流、接地锚、47脚供电和C8恢复核查；全板受影响PAD/网表/ECO对比。实际原生验证交M0/V4在隔离副本进行。
- `handoff.json`、`changes.json`、`results.json`、带单位和图的README、实际候选文件/脚本/依赖、原始日志。每个结果绑定父PCB SHA和约束版本。
- 选定方案后完成M0分配的K2或K3批次；若R2胜出，按新集成源工作，不继续维护互斥正式板。

## 验证和退出

V4独立复核，M0决定接纳；硬约束未冻结时只能标候选。完整连通、无新短路/间距/供电/参考退化且可在原生重现，才通过路线验收。失败必须保留最小复现；有界否定结论可结束诊断任务，不能算PCB交付完成。

首个计算默认30分钟预算，可由M0基于证据调整。两次同假设失败或90分钟无新证据交BLOCKER并暂停该方法，转交V4反证/R2比较。不得把搜索上限描述为物理无解。独立提出首个假设后再比较R2结果，避免双方复制同一误区。
