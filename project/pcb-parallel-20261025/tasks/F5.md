# F5：制造资料、可恢复交付与装配说明

当前待用户分配。先读[入口](../START-HERE.md)、[合同](../CONTRACT.md)、[验收](../ACCEPTANCE.md)。写`hardware/pcb-parallel/release/`。可提前验证导出工具和清单，所有预演包标DRAFT/NOT-FOR-FAB；正式输出必须等G4的Bfinal及E3签核。

## 首个60分钟产物

交导出能力清单和一份注明输入版本的预演：可编辑工程恢复、Gerber/钻孔/BOM/CPL能否实际导出，缺工具/字段的具体解决方式。不可用旧包改名字充当当前包；不得因等G4而只产出空目录。

## 正式交付

在`release/<release-id>/`生成[验收清单](../ACCEPTANCE.md)的全部七类实物文件：source、fabrication、assembly、interfaces、verification、test-plan、handoff。

1. 记录Bfinal源SHA、工程/PCB ID、导出工具版本/设置/时间、导出前后源SHA。无声几何变化须退回M0重新走G4。
2. 实际四铜层/阻焊/使用的丝印/板框、PTH和NPTH钻孔（无某类则有依据）、叠层和制造参数；独立查看器预览，检查单位、比例、镜像和孔层对齐。
3. BOM覆盖全部终版位号、MPN/封装/数量/装配方式，Top与Bottom坐标包括旋转/原点/单位合同；12TH及双面装配、特殊连接器/线束/不装项明确。不得手改CSV遮蔽PCB源错误。
4. 收齐E3接口/机械/测试文件和V4同版报告，写中文打开与制造审查说明；尚未实测性能保持UNMEASURED，保留音乐黄金与主机实体兼容限制。
5. `release-manifest.json`逐文件记录相对路径、类别、字节数、SHA256及对应源SHA。清单不自哈希，压缩包及清单自身SHA记录在包外交付收据，避免循环引用。提交ID也由后续交付收据绑定，不伪造包含自身的提交哈希。
6. 提供完整压缩包和实际远端提交。若单文件超远端限制，使用有SHA/长度的分卷和可重组入口；不能只有本机D盘路径。压缩包不重复嵌套历史恢复包，源依赖须完整。

## 验证和完成

V4从精确远端提交/交付位置取得文件，在新的空目录恢复并逐项查看；M0签G6。全部文件实际存在且非空、清单校验通过、源和生产输出一版、装配坐标与BOM一致，才交付“制造审查资料”。任何缺件或导出错误返回责任人；不得标完成后让用户补关键文件。

F5不改板、不负责代签DRC、不下单。工厂DFM反馈需改几何时回M0产生新Bfinal，所有受影响导出和验证重跑。
