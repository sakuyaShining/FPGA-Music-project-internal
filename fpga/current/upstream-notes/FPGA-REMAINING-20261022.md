## 0. 先纠正一个容易混的事实：当前顶层不发声

`rtl/joint_timing_top.v:270`：

```verilog
// No acoustic output: internal DAC logic remains visible in observation.
assign {dac_din,dac_ws,dac_bck,pa_en}=4'd0;
```

**音频四根线全部硬钉为 0。** 这不是"待接线"，是设计上就不出声——这个顶层的目的只是把内部状态
压成 956 位可观察量、再从 `probe_out` 一位一位吐出来。

同一文件 `:38`：

```verilog
localparam INPUT_BITS=587,OUTPUT_BITS=956,OBS_CHUNKS=30;
```

输入是 587 位串行历史（一根 `scan_in`），输出是 956 位异或压缩（一根 `probe_out`）。
**这是一个纯位串行探针，不是产品。**

所以必须区分三种构建，不能混着说"板子能出声"：

| 构建 | 内容 | 发声 | 真实输入 | 面积 |
|---|---|---|---|---|
| 72/73 号测试工程 | 音乐引擎 + I²S 输出 | **是** | 否（PC UART） | 15258 Logic / 14 IO |
| `joint_timing_top` | 全功能探针 | **否** | 否（1 位 `scan_in`） | 20233 Logic |
| **产品顶层** | — | — | — | **不存在** |

73 号文档自己也写明了：「测试工程的 15258 Logic / 36 BSRAM / 14 IO 与 27MHz 内部 PnR 来自 72 号，
**不代表包含左手扫描、右手触控和可视化的完整整机容量**」。

## 1. 关键判断：最小可演奏单板的面积其实是够的

按 87 号的分层账（同一次综合、互不重叠的子层次，不能相加父层）：

| 层 | Logic | 属于"能演奏"必需吗 |
|---|---:|---|
| 音乐全部 | 14710 | **是** |
| 原始扫描 / 校准 / 位置 | 1523 | **是** |
| **小计** | **16233** | |
| 可视化 | 2909 | 否 |
| 双向 FIFO / 环形仲裁 | 501 | 否（录放用） |
| SDRAM 控制 | 153 | 否（录放用） |
| system 合计 | 19796 | |

**16233 / 20736 = 78%。** 按 87 号的折算比 0.5136 估 CLS ≈ 8337/10368，**余约 2000 格**。

而现在塞不下的 20233 里，有 **3563 Logic 是可视化 + 录放 + SDRAM——没有一项是"能演奏"的必需品**。

> **结论：砍掉可视化与录放，做一个"音乐引擎 + 左手电极 + 音频输出"的最小单板，
> 面积与时序大概率自然通过。** 这是 11-04 前唯一现实的路径。
> 限定：8337 是线性估算不是实测，必须真跑一次 PnR 才算数。

## 3. 11-04 前的现实切片

| 档 | 工作 | 理由 |
|---|---|---|
| **必做** | W1–W6（产品顶层 + 音频接出 + 真实引脚 + 最小单板时序） | 不做就没有能烧的码流 |
| **必做** | W8–W10（右手规则 + 配对方案） | 纯文档 + 零 RTL，不做白不做 |
| **必做** | W12（效果器） | 零面积，一行寄存器 |
| **可缓** | W11（右手触摸 I²C） | 来不及就先用上位机滑块，文档写明是原型路径 |
| **可缓** | W13–W16（包络/nyq/叠层/四层） | 都在面积与排期之外 |
| **不做** | W17–W20（录放）、W23（双屏） | 面积和排期都不允许 |
| **顺手** | W21（RA8875 集成） | 如果最小单板有余量再考虑 |

## 4. 建议的下一步

**W1 的骨架**：从 `joint_timing_top.v` 派生一个 `product_top.v`，分四刀切：

1. 删 `probe_scan_store` 与 956 位 `observable` 压缩链
2. 删 `assign {dac_din,dac_ws,dac_bck,pa_en}=4'd0`，把 `probe_dac_*` 提到端口
3. 把 587 位 `controls` 拆成三路真实源：`pad_scan` 事件、右手推子增益、配置寄存器
4. 端口换成真实引脚：`pad` inout ×16、I²S ×3、UART ×2、复位、LED

第 3 刀最难，也是整个 P1 的核心。
