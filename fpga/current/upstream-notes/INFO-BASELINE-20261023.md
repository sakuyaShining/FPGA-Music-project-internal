### 1.1 七条红线（AGENT-BOARD §2，任何 agent 不得以"省资源"为由推翻）

1. **双屏保留，不合屏、不缩小推子。** RA8875 出推子/编辑/曲谱，ILI9341 出可视化。（Codex 87 号 §4.6）
2. **不削减**：32 组 × 16 分量、四槽分层、逐音滑条、录放、非易失、实体交互。
3. **不换平台**（GW2AR-LV18QN88C8/I7），**不改 PCB 接口**。
4. **左手是两排逐音滑条 + 独立八度条**，不是 8 个离散触摸键。
5. **右手是 7 英寸电容触摸 + 分区竖直推子**；左右分区、同侧就近、两侧取算术中点、松手保持、分区隔离。
6. **PCM5102A 在 52.734375 kHz 不可用**，用 PCM5122（TI SLAS859C §9.3.5.2 的 ±4% 检测窗口）。
7. **禁止下载码流、禁止制造放行**，除非用户明确批准。

> 注意：红线 1「不合屏」与 87 号动作 A「合并两屏删 ILI9341 渲染器」在字面上冲突。
> 87 号的实测结论是：合屏只回收 −37 CLS，但让布线从 FAIL 变 PASS；随后暴露出 WNS −5.608 ns。**该动作尚未成为产品决定。**

## §3 产品规格（已冻结部分）

- **核心**：实体机独立完成自定义乐器（激励 + 频谱/分量 + 时间演化 + 表情映射）+ 四槽同次演奏同音分层
- **左手**：两排逐音滑条，每排一个完整八度；另有**只选档、不测力的八度条**
- **右手**：7 英寸触摸显示区，手指下显示泛音图形，作用于全和弦，松手保持，RESET 平滑恢复
- **音频**：板载 MAX98357A + 4Ω/3W 喇叭；新增 3.5mm **线路输出**（只接有源音箱，非耳机/无源喇叭）
- **录放**：TF + SDRAM 缓冲 + 事件/音频配对；支持"伴奏回放期间现场演奏另一乐器"
- **存储**：24LC256 存乐器参数（32 KiB）
- **控件**：4 预设 + 编辑 + 带按压旋钮

### 4.1 传感链路（已定，88 号 §0）

```
电极 → 1kΩ 串阻 → 74HC4067（16 地址）→ 公共端 RC → SN74LVC14ADR（施密特）
```

- **6 路并行 SENSE**，每片 4067 用 14 个电极位 + 2 个参考负载（地址 14/15）

- 595 的 8 位全占满：Q0–Q3 地址 / Q4 使能 / Q5 RC_DRIVE / Q6 屏 RESET / Q7 触摸 RESET
- 165 的 8 路全占满：4 预设 + 1 编辑 + 旋钮按压 + A 相 + B 相

## §5 A 轴逻辑/资源现状

### 5.1 资源账（87 号 §2，综合口径）

| 资源 | 用量 | 上限 | 占用 | 余量 |
|---|---:|---:|---:|---:|
| **CLS（约束项）** | ~10168 | 10368 | **98.1%** | **~200** |
| Logic | 19796 | 20736 | 95.5% | 940 |
| 普通寄存器 | 10708 | 15552 | 68.9% | 4844 |
| BSRAM | 31 | 46 | 67.4% | 15 |
| DSP | 13.75 | 24 | 57.3% | 10.25 |

**关键判断**：约束是 **CLS（物理逻辑片）**，不是 Logic/寄存器/BSRAM/DSP。过去几轮优化（71 号锚点共享、78 号参数回读 RAM、85 号音高 RAM）都在减寄存器，方向对但收益有限——寄存器本来就有 31% 余量。

要在 CLS 上腾余量：5% 余量需砍 ~620 Logic；10% 需砍 ~1630；容纳新功能需砍 ~2270。

### 5.2 层次明细（86 号 resource-map.json）

| 层次 | Logic | 占比 |
|---|---:|---:|
| `music` | 14710 | 74.3% |
| └ `u_tdm`（合成引擎） | 3999 | 20.2% |
| └ `u_nm`（声部分配） | 2702 | 13.7% |
| └ `contact_expression.u_finger` | 1942 | 9.8% |
| `visualizer` | 2909 | 14.7% |
| └ `u_renderer` | 2057 | 10.4% |
| `sensor` | 1523 | 7.7% |
| `transport` + `sdram` | 654 | 3.3% |

三个反常点：`u_nm` 1474 寄存器（逐组平铺）；`sensor` 1458 寄存器（比 `u_tdm` 还多）；`u_renderer` 2057 Logic 只为画 320×240。

### 5.3 动作 A 的实测修正（重要）

| | 估算 | **实测** |
|---|---:|---:|
| 删 `u_renderer` + 接 RA8875 命令层 | −1657 Logic / −851 CLS | **−628 Logic / −37 CLS** |

**错因**：按模块名切账 ≠ 按"与输出方式是否相关"切账。`u_renderer` 的 2057 Logic 里 1428 是画面内容计算，与输出方式无关。

**但结论方向成立**：布线从 `DesRoute failed` → **PASS**，第一次拿到有效码流。真正起作用的机制是"凑出 48 个空 CLS 给打包器"。

**同时暴露**：`core_clk` Setup **TNS −250.223 ns / WNS −5.608 ns**（在 `u_tdm`，26 号从来测不到）。

### 5.4 87 号给出的解法（一箭双雕）

```
要时序约束 → 需要探针 → 探针放不下 → 路由失败 → 拿不到时序
```

86 号探针用了 **587 位串行输入历史链** + **956 位分 30 块奇偶观察**，本身不是产品需要的（只占 368 Logic / 1.8%，但占 9 DSP）。

**解法**：用真实 UART 命令接口替代重型探针。产品本来就需要命令协议（配置/演奏/状态回读）。输入变成真实音乐命令帧，输出变成状态寄存器回读，探针开销降到接近 0，同时解决"探针不能演奏"。

## §6 传感与力度现状

### 6.1 两条扫描路线互斥

| 顶层 | 传感前端 | 能发声 | 资源 |
|---|---|---|---|
| `tdm_top_owned.v` | `pad_scan #(.NCH(16))`，16 路 inout **直连** | **能**（73 号已验证） | CLS 99.6% |
| `instrument_sensor_probe.v` | `rc_mux_scan #(.LANES(6), .STRIPS(26))` | **不能**（纯探针） | 95.4% Logic |

`rc_mux_scan` 在 `engine/src/` 里**只被探针实例化**，主顶层里没有。

**⇒ 能演的固件跑不了现有小样板（2 根 sense），能跑小样板的固件不发声。** 这是 11-04 前必须裁定的岔路口。

### 6.2 力度：表是对的，功能是关的

- **`vel_wtab.hex` 完全正确**：16 力度 × 16 泛音，基音恒 256，有效泛音数随力度增加（vel0 只 3 条 → vel15 全 16 条），频谱重心 0.96 → 8.32（8.7 倍）
- **Bug 1**：`reg_bank.v` 只有 `mem[8'h5C]=8'h70`，**没有 `0x6E`** ⇒ 复位 0 ⇒ `vel_vscale=0` ⇒ 力度完全不影响音色
- **Bug 2**：力度值本身是固定的 —— `pad_scan` 固定 12/15，`pitch_pos` 固定 `4'd12`（`tdm_top_owned.v:645`），只有 `u_ev_vel = wr_data[3:0]`（上位机）可变
- **MUX 路线**：`rc_strip_positions` 只用 `read_delta` 做位置质心，`grep -i "vel|force|pressure"` **零命中** ⇒ 力度通路一行没写
- **物理信号在**：`row_count` 每帧都有，轻按接触面积小 → delta 小，重按压扁覆盖层 → delta 大
- **时间预算**：每地址 ~31 μs 典型 / ~97 μs 最坏，16 地址整帧 **0.5–1.6 ms**，对 10 ms 指标有 6–20 倍余量
- **唯一硬前提**：重按/轻触 ≥ 1.5 倍（**未上板验证**）

### 6.3 现有 `pad_scan` 素材（若走直连路线）

`cnt[i]`（12 位放电计数）、`raw[i]`（锁存）、`base[i]`（标定窗最小）、`hi = base×1.156`、`lo = base×1.078`；`dbg_raw_sel`/`dbg_base_sel` 已输出。

加力度需：`output reg [3:0] ev_vel` + `input [3:0] vel_shift`，约 **32 LUT + 4 寄存器**。`vel_shift ≈ log2(base/60)`，**必须上板量 base**。
