## 1. 三态状态机

| 态 | 电极行为 | 槽键 K0–K3 语义 | LED |
|---|---|---|---|
| `PERF` 演奏态 | 出音高+力度 | 切换**在奏**槽 | 4 位显示在奏槽 |
| `EDIT_SEL` 编辑·选槽 | 仍可弹（当前在奏槽） | 指定**编辑目标**槽 | 目标槽位慢闪 |
| `EDIT_ACTIVE` 编辑·调参 | 仍可弹（用草稿音色） | 切换编辑目标槽（草稿未应用先提示） | 目标槽常亮 + dirty 快闪 |

退出：`EDIT_ACTIVE` 按 K4 → 若 dirty 则先提示（LED 三闪），再按一次才退出并丢弃草稿。

**"编辑态必须能弹"是硬要求**：不能弹就听不到自己在改什么。所以编辑态不是"停奏"，而是"用草稿音色弹"。

## 2. 四处你的设想和现有硬件对不上

### (a) 只有 4 个预设槽，而且"2 bank"不是用户 bank

`instrument_table.v:1` 原文：

> Four volatile slots, two banks per slot. Commit needs all 16 words.
> Writes target the inactive bank; allocator serializes admission and commit.

| 项 | 实际含义 |
|---|---|
| `slot[1:0]` | **4 个用户预设槽**（这才是"预设按钮"对应的东西） |
| `banks[3:0]` | **每槽一个双缓冲位**，写非活动 bank，commit 时翻转 —— 是原子性机制，不是"每槽两套音色" |
| `words[0:127]` | 4 槽 × 2 bank × 16 泛音 |

**所以"预设按钮"是 4 个，不是 8 个。**

### (b) 激发参数是全局的，不在槽里

`tdm_top_owned.v:834-877`：

| 寄存器 | 内容 | 默认值 |
|---|---|---|
| `0x38` | `[0]artic_enable` `[1]strike_auto_rel` `[7:4]strike_s_lvl` | `0x22` |
| `0x39/0x3A` | `artic_mask[15:0]` 每泛音选 strike | `0xFFFF` |
| `0x3B` | `[1:0]strike_d_m` `[5:2]strike_d_k_curve` | `0x2B` |
| `0x3C` | `[4:0]strike_d_k_base` | `0x0E` |
| `0x3D–0x3F` | `hold_ticks[19:0]` | `0x0134FE` = 1500 ms |

这 8 个字节是**顶层全局寄存器**，切槽不改变它们。

**后果**：现在"槽 0 = 钢琴（sustain）、槽 1 = 钟（strike）"做不到 —— 切槽只换音色，激发方式跟着全局走。

**你要"每个预设有自己的激发方式"，必须把这 8 字节搬进槽。** 改动：4 槽 × 64 位 = **256 FF**（寄存器 4302→4558，28%→29%）。便宜。

> 顺便：`instrument_table` 的 `word[87:84]` 是 4 位保留位（校验要求为 0），4 槽×16 泛音×4 位 = 256 位，正好装得下 32 字节。但把"每槽的激发参数"拆成 16 份塞进每泛音的保留位很难看，建议单独用 256 FF，不动 `instrument_table` 的校验规则。

### (c) "边改边听"被原子 commit 挡住了

`instrument_table` 的语义是：一个槽要么是旧的完整 16 词，要么是新的完整 16 词，**没有中间态**。

所以"改第 3 个泛音的幅度 → 正在响的和弦立刻变"这件事，**现在的结构做不到**。

三条出路：

| 方案 | 做法 | 代价 | 听到的时机 |
|---|---|---|---|
| **A 改完重弹**（推荐） | 每次按键改动 → 立即重写整槽 16 词 + commit | 0（16 拍） | 松手再按 |
| B 单泛音 live bypass | 被改的泛音绕过 commit 直送在响 instance | 88 位 mux × 16 实例，改动面大 | 立刻 |
| C 完全草稿 RAM | 4×16×88 独立草稿区 | +1 BSRAM + 一条读取通路 | 立刻 |

**推荐 A**：`instrument_table` 本来就要求"16 词齐才 commit"，编辑器在 FPGA 内部组装 16 词只是 16 个时钟。用户的工作流是"改几个参数 → 弹一下听"，这本来就是调音色的正常方式，而且天然避免"改到一半的非法中间态被听到"。

**顺带一个架构上的好处**：草稿就是 `instrument_table` 的**非活动 bank**。因为写操作本来就落在非活动 bank，所以：
- 编辑改动 → 写非活动 bank（部分写，不必 16 词齐）
- 应用 → 16 词齐了 commit（翻转 bank）
- 撤销 → 不 commit，非活动 bank 被下次写覆盖
- **不需要额外 RAM，只需要把 `written[slot]` 的语义从"位图"改成"脏标记"**

### (d) 没有触控屏，编辑只能编宏观参数

16 泛音 × 5 个有效参数 = **80 个数值**。8 个键 + 6 个 LED 编不了。

| 档 | 能编什么 | 依赖 |
|---|---|---|
| **M1 宏观版**（11-04 可做） | 6 个宏观量：亮度 / 衰减长短 / 起音 / 泛音数 / 激发方式 / 激发强度 | 按键 + LED |
| M2 完整版 | 16 泛音 × 5 参数逐项 | 触控屏 J10 |
| M3 手绘版 | 右手推子直接画谱形 | 触控屏 + `rh_fader_*`（10 个模块已写但未接） |

**M1 的 6 个宏观量都是"批量改 16 个泛音"**，需要一次批量重算（16 次乘法，可用 1 个 DSP 分 16 拍做，不占面积）：

| 宏观参数 | 实际改动 | 涉及字段 |
|---|---|---|
| 亮度 | 把 `amp[k]` 按 k 乘一个斜率 | `amp[31:24]` ×16 |
| 衰减长短 | `d_k ± n`（同时受 621 ms 天花板约束） | `d_k[4:0]` ×16 |
| 起音 | `a_inc`（**现在是硬编码 117 = 5.31 ms，必须先开 `INSTRUMENT_ENV`**） | `[78:63]` |
| 泛音数 | `amp[k≥N] = 0` | `amp[31:24]` |
| 激发方式 | sustain / strike / hybrid | `0x38[0]` + `artic_mask` |
| 激发强度 | `strike_d_k_base` | `0x3C` |

> ⚠️ **"起音"这一项现在是空的**。`INSTRUMENT_ENV=0` ⇒ `a_inc` 走 `legacy_env` 分支的硬编码 117。不开这个开关，编辑界面上的"起音"旋钮转了没声音变化 —— 和现在上位机那 6 个空旋钮是同一个问题。

## 3. 键位：8 键不够，建议 PCF8575（16 键）

按"保持独立键"的要求，8 键会撞车：

```
8 键方案：K0-K3 槽 + K4 EDIT + K5 激发 + K6 应用 + K7 撤销
→ 编辑态的"参数选择 / 值+ / 值−"没有键位，只能靠长按组合
```

**改用 PCF8575**（16 位 I²C 扩展，同系列、同总线、地址 0x20–0x27，¥2–3）：

| 键 | 演奏态 | 编辑态 |
|---|---|---|
| K0–K3 | 切在奏槽（独立键，按哪个是哪个） | 指定编辑目标槽 |
| K4 | 进入编辑 | 退出（dirty 则提示） |
| K5 | 激发方式循环 | 激发方式循环 |
| K6 | — | 参数选择（6 个宏观量循环） |
| K7 | — | 值 − |
| K8 | — | 值 + |
| K9 | 应用（commit） | 应用（commit） |
| K10 | 撤销 | 撤销（回到该槽已保存内容） |
| K11 | 保存到 EEPROM | 保存到 EEPROM |
| K12–K15 | 备用 | 备用 |

**16 个独立键，无模态重载，不需要长按组合。** 面板上是 16 个小按钮，比"4 槽键 + 6 旋钮"占的面积还小。

> I²C 总线：`STORE_SDA/SCL = 25/26`。PCF8575(0x20) 与 24LC256(0x50)、GT911(0x5D) 地址不冲突，单主机分时调度即可，无需仲裁。

## 4. 面积与时序预算

| 项 | 增量 | 后 |
|---|---|---|
| 每槽激发参数（4×64 位） | +256 FF | 4558 / 15750（29%） |
| 编辑态状态机 + 按键消抖 + LED 编码 | +80 FF / +120 LUT | — |
| 宏观参数批量重算（1 DSP 复用） | +0 DSP / +60 LUT | — |
| `i2c_master` 接入 + PCF8575 驱动 + 调度器 | +150 FF / +200 LUT | — |
| `INSTRUMENT_ENV=1`（起音可调的前置） | +1 BSRAM / +30 FF / +200 LUT | 16 / 46 BSRAM |
| **合计 CLS** | 约 +400 | 8265 → **约 8665 / 10368（84%）** |

**红线**：hold 现在只有 **+0.205 ns**。每加一块组合逻辑都必须重测 hold，这是最容易静默失守的一条。

## 5. 实施顺序（每步可独立验证、独立回退）

| 步 | 内容 | 验证手段 | 关闭态逐位不变 |
|---|---|---|---|
| E0 | `i2c_master` 接入 + 调度器 + PCF8575 驱动，读出 16 键原始值 | UART 回读键值寄存器 | ✅ |
| E1 | 三态状态机 + LED 编码（不接编辑功能，只切态） | UART 回读 `state` 寄存器 + 看 LED | ✅ |
| E2 | 每槽激发参数（4×64 位）+ 切槽时加载到全局 | UART 写槽 0/1 不同 `artic_mask`，切槽后回读 | ✅ |
| E3 | 草稿 = 非活动 bank；`written` 改脏标记；K9 应用 / K10 撤销 | `tb_instrument_table` 新增"部分写→不生效→补全→commit 生效"判据 | ✅ |
| E4 | 6 个宏观参数的批量重算 | 逐参数：写值 → commit → 回读 16 词比对期望 | ✅ |
| E5 | `INSTRUMENT_ENV=1`（起音可调） | `tb_engine_env` + 板上听 5.3ms vs 200ms 起音 | ⚠️ 此步**不满足**逐位不变，需单独基线 |

**E5 单独列出来的原因**：它是唯一一个会改变现有发声行为的步骤（`EPW` 31→71，`legacy_env` 分支被绕开）。必须单独建基线、单独回归，不能混在其他步骤里。

## 6. 需要你拍板的四件事

1. **每槽激发参数做不做？** 不做 ⇒ "选预设"只换音色，激发方式全机一套，你的设想只实现一半。做 ⇒ +256 FF。
2. **"边改边听"要立刻变还是松手重弹？** 推荐松手重弹（方案 A），零改动。
3. **键位用 PCF8575 16 键，还是坚持 8 键 + 长按组合？** 推荐 16 键。
4. **编辑态编到哪一档？** M1 宏观 6 参数（11-04 可交付）/ M2 逐泛音（要触控屏）/ M3 手绘（要触控屏 + 接 `rh_fader_*`）。
