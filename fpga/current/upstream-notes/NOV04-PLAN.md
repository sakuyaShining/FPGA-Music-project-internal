## 4. 文档可以并行，不占硬件时间

现有 89 份设计文档已覆盖设计演进，缺的是**一份面向评审的最终说明**。建议 6 节：

1. **乐器是什么**（一页讲清）
2. **核心机制**：32 组 × 16 分量加法合成、逐指表情、右手 8 推子泛音构造、四层
3. **已实现并上板验证的**（列证据：73 号出声、71 号黄金轨迹、32 组压测）
4. **已验证但未上板的**（数字仿真/回归，标明是仿真）
5. **未实现 / 已知缺陷**（如实写：三/四层、录放、双屏、时序未收敛）
6. **路线图**

> 第 5 节**不能省**。现有文档的风格是每处结论都带限定（例如 89 号对帧率推导主动加了
> "只算 SPI 载荷时间、不含绘图执行与总线争用"的限定）。评委会认这种写法，掩盖反而扣分。

## 5. 时序收敛的现实概率

| 项 | 状态 |
|---|---|
| 缺口 | setup 0.700 ns、hold 0.126 ns |
| 已穷尽 | `place_option` 0/1/2/3/4、`route_option 1`、`correct_hold_violation 1` |
| 唯一可行组合 | `place 1 + route 0`，缺口固定 |
| 根因 | CLS 99.6% 满，修正器找不到合法延迟资源；不是路径坏了 |
| 唯一被实测证明有效的腾面积动作 | **RA8875 替换渲染器：−628 Logic、空 CLS 从 11 抬到 48，路由从 FAIL 变 PASS** |
| 已否决的零敲碎打 | 删 512×14 字体 ROM 只换 31–38 CLS，需 ~200 CLS，量级差 5 倍 |

**判断：有希望，但不保证。**

**最值得做的一次实验**：把 RA8875 渲染器替换 **与** `place_option 1` **组合**重跑。
理由：前者给空 CLS，后者给布线自由度，两者不冲突。
**限定**：89 号的构建顶层是 `joint_timing_top`，本轮 M1 的构建顶层是 `left_layer_music_probe`，
两者资源与路径不能直接相加，必须重跑一次完整 PnR 才能下结论。

### 7.2 三个采购陷阱（已有文档记录，别踩）

1. **不要买 SSD1963 的屏。** 项目里已经有 RA8875 渲染器（`mv_panel_ra8875.v` + 新 `mv_renderer.v`，
   实测 **−628 Logic、空 CLS 11→48、路由从 FAIL 变 PASS**）。SSD1963 要新写驱动，而且省不了面积。
   **买错屏 = 同时丢掉"显示"和"时序收敛"两条路。**
2. **ER-TFTM070 有多个配置版本**，必须指定「**4 线 SPI + 电容触摸**」。基础版是电阻触摸或无触摸。
   厂家国内页索引价 273.22 元是基础配置，电容触摸是单独选项。
3. **屏的触摸 IC 可能是 FT5316 而不是 GT911**，两者驱动不同。到货先用 CH341A 读一次，
   确认 IC 型号再决定写哪个驱动。不要照 GT911 的寄存器表硬写。

### 7.3 不用买

- 左手音高电极的触摸 IC：`pad_scan.v` 是 **FPGA 直扫电容**（charge/discharge/latch 三态，
  32 轮基线标定，3 轮去抖，16 路 = bit0-7 左手音高 + bit8-15 右手泛音），铜箔直接接 GPIO 即可。
- 喇叭：已有。
- 开发板：已有 Tang Nano 20K。

## 8. 「完整实体机」的真实路径：三道关

| 关 | 内容 | 现状 | 难度 |
|---|---|---|---|
| **1** | **码流能烧**（时序收敛） | setup −0.700 / hold −0.126，**现在不能烧** | **高** |
| **2** | **真实顶层**（触摸/滑条 → 音符） | 现在是 `joint_timing_top` 探针，音符由 PC 通过 UART 发 | **中高** |
| **3** | **上位机** | 有 11 版 Qt GUI 源码（104 项离线回归通过），可重做 | 低（你说的 vibecoding） |

**第 3 关最容易，第 1、2 关是瓶颈。** 顺序不能反：上位机做得再好，码流烧不进去就是空壳。

### 8.1 第 1 关的唯一希望

RA8875 渲染器替换 **＋** `place_option 1` 组合重跑。前者腾空 CLS，后者给布线自由度。

**限定**：89 号的构建顶层是 `joint_timing_top`，本轮 M1 是 `left_layer_music_probe`，
两者资源与路径**不能直接相加**，必须重跑一次完整 PnR 才能下结论。单次构建约 400–600 秒。

### 8.2 第 2 关的最小实现

不追求完整 M2，只做**能演奏的最小通路**：
- 左手：铜箔电极 → `pad_scan` → `note_map` → 发声（这条链已存在，接上真实 GPIO 即可）
- 右手：屏触摸 → I²C → 推子位置 → 增益（**这条链不存在，要新写**）
- 保留 UART 作为上位机通道，双通道并存

**降级方案**：若右手 I²C 驱动来不及，视频里右手推子用上位机滑块驱动，
但**必须在文档里写明这是原型路径**，不能拍成"实体推子已工作"。
