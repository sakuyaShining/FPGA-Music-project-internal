## 本轮实际布线

先重新捕获原生器件、1079 个焊盘、2841 段 API 铜线及 404 个过孔，确认与离线方案的原始 API 输入完全一致；另将 API 遗漏的 24 段极短原生铜线纳入几何障碍。

应用四网音频候选后，核对全部器件身份和位置、全部焊盘、规则及其他网络铜线未变。原生重建地铜并重新打开后，得到 0 间距/0 物理/118 未连通检查点。I²S 三根信号线均接通，但地铜重新分割使 GND 报错对象从 11 增至 16，不能用完成三网直接推算总报错下降数。

随后以增加连接的方式处理地网，不拆除原地线：第一批 14 条连接后未连通降至 106；补充三条连接后降至 104。每批均核对非地铜不变、原地线几何仍被保留、全部焊盘与器件位置不变，再重建地铜并运行原生 DRC。

最后的隔离位于 U12 第 24 脚。单独补地或仅重布 DAC_XSMT 会封住相邻脚的出线通道；不合格的试算均未应用。最终联合安排第 23/24/25 脚的错位出线：保留全部既有地线，替换 DAC_XSMT 与 I2S_LRCK，并增加 U12.24 的地连接。过孔位置同时检查上下层铜线；局部 6 mil 出线符合现有最小线宽。候选最小异网铜间距约 0.172846 mm，真实端点连通和钻孔间距检查通过后才应用。

最终保存、重建两层地铜、关闭并重新打开 PCB，原生 DRC 为 0 间距/0 物理/102 未连通，GND 连接报错消失。联合候选见 `resume-dac-ground-repair-plan.json`，应用前后核对见 `resume-native-dac-ground-repair-audit.json`。

注意：原生连接错误可能以连通组中的代表对象显示；不能把没有单独报错的某个地焊盘或过孔直接认作已接入主地铜。中间的地网修复以实际保存铜面和最终原生 DRC 为准。未连通对象数也不是飞线数量或完工百分比。
