# 音频交付说明：每个 WAV 对应"什么输入 → 什么输出"

> ⚠️ **先说清楚性质**：这些 WAV **全部是仿真渲染**（RTL 逐样本输出 → `render_wav.py` → 48 kHz）✗
> **不是板上录音** ✓（板子还没插过电 ✗）。渲染源采样率 52734.375 Hz ✓，输出同时给 48000 Hz 版本 ✓
> （必须 48 kHz：ZCode 之前发现非标准采样率在某些声卡上**静默无声** ✗）。
> 每个文件都归一化到 −1 dBFS ✓，可直接双击播放 ✓。

## 一、交互层三件（本批 ①b + ③ 的产物，`sim_build/show/`）

| 文件 | **模拟的输入** | **输出的音频** | 证据 |
|---|---|---|---|
| **`A_左手电极弹五声音阶`** | **16 根电极中的 pad0..pad7（左手音高键）被逐个"触摸"** ✓<br>触摸 = 模型的放电时间从 **30 拍 → 95 拍**（手指 ⇒ 电容变大 ⇒ 放电变慢 ✓），与真实 RC 行为同构 ✓<br>**不注入任何音符事件** ✓ —— 完全靠 pad_scan 自己扫出来 ✓ | **五声音阶旋律**：C4 D4 E4 G4 A4 C5 D5 E5 上行，再回到 C4 ✓（每个音≈0.23 s ✓） | `tb_show +show=0` ✓<br>判据 `tb_pad` PS4：8 键按下/松开共 16 事件、note 逐一对 ✓ |
| **`B_右手泛音键塑谱`** | 先**按住 pad0（C4）** ✓，同时**摸右手第 1 根泛音键**（只响基音）✓；<br>之后每 0.35 s **多摸一根**（2/3/4/5/6/8）✓<br>模式 = **替换**（`0x5A=0x03`）⇒ 只响被摸到的泛音 ✓ | **一个持续音，音色从"纯基音"逐步长成"全泛音"** ✓<br>（听感：从长笛般单薄 → 管风琴般丰满 ✓） | `tb_show +show=1` ✓<br>判据 **VP2a/VP4**：单刷声部在 ≤2 个样本周期内变形 ✓、未触及声部逐位不变 ✓、单位掩码只 boost 对应泛音 ✓ |
| **`C_替换vs叠加_对比`** | **同一个音 + 同一组右手掩码**，先"叠加"（`0x5A=0x02`）再"替换"（`0x5A=0x03`）✓<br>两段之间只差一个寄存器位 ✓ | **第一段**：预设底谱 + 被摸泛音加强（丰满但有底噪般的泛音堆 ✓）<br>**第二段**：**只有被摸到的那几根泛音**（干净、像拉杆风琴的注册音 ✓） | `tb_show +show=2` ✓<br>判据 **VP3**：叠加模式增量恒为常数（±1 截断）✓；替换模式各泛音相等 ✓ |

**怎么听出"对"**：A 段的音高应当是标准的 **C D E G A C D E**（无半音、无错音 ✓，这正是五声音阶的意义 ✓）；
B 段应当**没有音高变化**（只有一个音 ✓）而**音色在变** ✓；C 段两段的**音高相同、音色不同** ✓。

## 三、⚠️ 每个 WAV 的"上板会不一样"的地方（**必读**）

| 差异 | 说明 |
|---|---|
| **电极的绝对量程** | 仿真里"手指"是**我设定的 30→95 拍** ✗。真实值 = 内部下拉电阻 × 电极电容 ✗，**两者都不知道** ✗✗ ⇒ 可能太快（分辨不出）或太慢（计数器封顶 ⇒ 永远摸不着）✗。<br>**缓解**：每根电极外接 **1 MΩ + 22 pF** ⇒ RC ≈ 594 拍（量程中段 ✓），手指加 ~10 pF ⇒ +270 拍 ✓。**上板第一件事就是量这个** ✓（见 `步骤16_上板风险审计.md` §1 ✓） |
| **音质** | 仿真给的是**数字波形** ✓；板上还要过 I2S、MAX98357A、扬声器 ✗（增益/频响/群延迟都会变 ✓） |
| **混响尾巴** | 仿真里是 16 位定点运算 ✓；板上一致 ✓（同一份 RTL ✓），但**听感受扬声器影响** ✓ |
| **事件时序** | 仿真里事件间隔都很大 ✓；上板若**高速连奏**，UART 事件可能撞上刷新窗口被丢 ✗（pad 路径有握手 ✓，不受影响 ✓） |

## 四、每个文件的"听什么"速查

```
A_左手电极弹五声音阶_48000.wav    → 8 个音上行 + 回落；音高应是 C D E G A C D E（五声，无错音）
B_右手泛音键塑谱_48000.wav        → 一个长音，音色由"单薄"逐步变"丰满"；音高不变
C_替换vs叠加_对比_48000.wav       → 两段同音高：第一段丰满（含预设底谱），第二段干净（只有摸到的泛音）
协议全链路_曲谱下载+混响_48000.wav → 板子自己演奏的旋律（UART 下载曲谱）+ 混响
效果器对比_干声延迟合唱混响_48000.wav → 同一旋律四遍：干/延迟/合唱/混响
```

**复现命令**（改 RTL 后重出音频）：
```powershell
$env:PATH = 'D:\iverilog\bin;' + $env:PATH
cd sim_build\show
vvp show.vvp +show=0     # A：左手电极弹旋律      → show_pads.txt
vvp show.vvp +show=1     # B：右手塑谱（在响变形）→ show_spec.txt
vvp show.vvp +show=2     # C：替换 vs 叠加        → show_ab.txt
cd ..\..
python tools\scripts\render_wav.py --dump sim_build\show\show_pads.txt `
  --out "sim_build\show\A_左手电极弹五声音阶.wav" --src-rate 52734.375 --rates 48000
```
