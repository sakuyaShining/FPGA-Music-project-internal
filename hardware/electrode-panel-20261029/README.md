## 独立验证样片

`candidate/ElectrodeCoupon-CANDIDATE/`为46×72 mm、双面1 oz、标称1.6 mm FR-4的**单音位三电极候选**，滑动图形12×48 mm。正面铜由工厂蚀刻并保留阻焊，不用手工铜箔；背面仅走三根信号和接口局部地线，电极背后不铺整面地。暂不设最终装机孔，样片可由绝缘夹具固定。

候选J1复用已核验的PZ254V-11-16P/C22465876封装；本版放在正面下端服务区，避开触摸覆盖层。Pin8=A/CH0、7=中/CH1、6=B/CH2、15/16=GND，其余针只保留物理焊盘并电气悬空。它只验证一个音位，不能用其余空针冒充完整14电极面板。连接器库存、预焊报价和确切配套线束商品尚未复核。

图形使用重复锥形边界扩展空间交叠，电极间隙0.8 mm、图形圆角约1 mm半径；具体图形必须实测。三电极不能测量真实机械压力；位置、接触面积和演奏表情仍依赖现有RC测量与后续固件标定。样片图形本身不代表表情功能已通过。

`candidate/source-geometry.json`记录生成模型；`candidate/saved-native-source-audit.json`独立重读实际PCB，确认A/中/B各自的排针—背面走线—过孔—正面铜区连接。样片已在嘉立创V4.1.71打开、保存、关闭文档重开，再运行严格原生DRC，返回0项；原始响应在`native-DRC-raw.json`与`native-reopen-export.json`。

同一重开文档已导出候选Gerber、原生BOM和IPC-D-356A。`candidate/Gerber-copper-audit.json`从实际Gerber重新计算：顶层最小异网铜距约0.799993 mm、底层0.94 mm、铜到板边1.15 mm；源/导出几何差在0.000014 mm以内。铜距按0.25 mm独立门限判断，5 μm源图形等价容差不用于放宽铜距。三个信号在底层各为单独连通铜区。

补充核验已确认：双面阻焊各16个开窗仅对应排针，触摸电极上方无阻焊开窗；钻孔文件共19个镀孔（16排针+3过孔），另一个Via钻孔文件是其中3孔的子集，不能重复加计；闭合板框为46×72 mm。已把J1标记移回接口服务区并增加A/M/B、Pin1和COUPON标记，保存重开后再次DRC0并重新导出。

**仍未完成：** 预焊与线束精确商品/报价核对、实物性能与整套机械设计。因此本候选不可按最终完整面板直接下单。面积交叠的简化计算为几何研究，未包含电场、人体接地、RC、电缆、覆盖层和噪声，不能当实测表情性能。

## 可重复生成

Python 3和Shapely 2环境运行：

```powershell
python build_candidate.py --sensor-project <已核验的Sensor14Bank-FINAL-REVIEW目录> --harness <ELECTRODE-HARNESS-84-VERIFIED.csv原件>
```

生成器只读取旧源，不修改旧控制板/传感板，也不导出或捏造制造验证结果。模板PCB全长指纹必须与已登记的2184d027版本一致。重新生成写入单独的`generated/`，不会覆盖经过原生核验的`candidate/`；它生成相同铜图形和标记设计，不承诺复刻原生软件追加的逻辑时钟与图元ID。核验时先运行`verify_native_candidate.py`，再运行`audit_gerber_candidate.py`。

参考：[Microchip AN2934，§1.2.3与§1.3–1.4](https://ww1.microchip.com/downloads/aemDocuments/documents/TXFG/ApplicationNotes/ApplicationNotes/Capacitive-Touch-Sensor-Design-Guide-DS00002934-B.pdf)。采用其被动电极空间插值、圆角、覆盖层和寄生电容的设计原则；其器件专属采集能力不作为本项目HC4067/RC前端的合格证明。
