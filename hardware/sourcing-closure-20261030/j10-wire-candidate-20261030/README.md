# J10到屏幕的端到端针表候选

已把C88的12针控制接口与ER-TFTM070-5V4厂家资料中的屏端信号逐项对应，见CSV。**当前是供屏幕厂家逐项确认的接线候选，尚未放行线束加工。** 屏幕的外部RA8875复位引出需要厂家确认，不能把12针线按同序接40针。

本轮从厂家托管的最新版模块手册索引文字（§4.1，第11–12页）和2024-06-11接口参考图索引读取：四线SPI的CS/SDO/SDI/SCLK为屏端5/6/7/8针，触控INT/SDA/SCL/RESET为33/34/35/36针。C88对应端和3.3V逻辑供电按冻结R2回查。完整PDF直接下载仍403，未完成图面视觉核验；这不构成实物连通验收。[模块手册](https://www.buydisplay.com/download/manual/ER-TFTM070-5V4_Datasheet.pdf)、[厂家接口参考图](https://www.buydisplay.com/download/interfacing/ER-TFTM070-5V4_Interfacing.pdf)。

## 需要厂家明确的三处

1. **显示复位**：手册将屏端11针标为`/RESET (NC)`并提到板载RC复位，接口参考图也写NC。C88.J10.7是主动低有效DISP_RESET_N，不能据名称猜接屏11针。请厂家确认11针在所交付修订上是否真正可用作外部3.3V硬件复位；若不可用，需由厂家从合格RA8875复位点另预焊一根引出线，并给照片/针表。没有确认时保留该线未接，不能把接线整套称为已完成。
2. **连接器身份与方向**：模块手册§4.1标题写JP2/CON1，接口参考图却写JP3/CON2。CSV以“主40针接口的针号/功能”表述，具体已焊连接器、针1标识及正反面必须由厂家照片确认。屏模块的跳线J10与控制板C88.J10连接器不是同一对象。
3. **触控版本**：接口参考图仍出现FT5206标记；本项目要求实际交付FT5316电容触控。请确认对应板卡修订的33–36针触控引出一致、触控FPC已正确安装，并提供实际IC/接口照片。不能将旧触控图标签当成已交付FT5316的证据。

厂家参考图的四线SPI配置提到模块侧R35–R38装0Ω、R39–R42不装，以及模块J10/J12/J14/J16短接、J9/J11/J13/J15断开；这些仅供厂家核对所交付修订，**不作为用户自行改焊步骤**。5V模块供电与3.3V逻辑/裸触控电源分开确认；本候选不向触控裸电源或NC针送5V。

## 给屏幕厂家的补充规格草稿

请报价1套ER-TFTM070-5V4：RA8875、800×480、4线SPI出厂配置、5V模块电源、FT5316电容触控、全部3.3V控制信号；40针及触控FPC均安装、配全部匹配线束。请按附件C88.J10针表回填屏端实际引脚和照片，明确显示硬件复位引出、两个地回路、电源分配、对插接头高度及候选线长。还需实际外形/孔位/总深度图、含运人民币总价和发货日。当前没有代发送询价或下单。

不必因此改画C88：现有板已经提供显示复位和触控信号；未闭合的是屏端出厂配置与预焊引出、厂家版本和线束验收。若厂家无法提供要求的引出，须再评估兼容路径，不能擅自取消复位需求或宣称现有软件已支持另一种启动方式。整机450×190×60mm包络及原84路映射保持。
