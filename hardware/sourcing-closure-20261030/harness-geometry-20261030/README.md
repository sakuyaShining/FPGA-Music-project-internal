# 96芯线束的源坐标与距离下界

脚本读取实际EP84/S2封装PAD中心与组件角度，按450mm装配候选转换到共同俯视坐标，输出96条同针号连接坐标。六板J1/J2中心均与原安装图一致。固定候选高度下板面差41.4mm，最长端点直线下界56.298935mm；假设两端已对插接头各占16mm后，出口直线下界最长39.293385mm，垂直自由间隔9.4mm。

100mm候选未被直线距离立即否决，仍不能签收加工长度：需要实际母座/端子占高、线径/弯曲半径、总长与自由线长定义、松弛和夹持净空。六条C88至S2.J2线束也占用底舱。当前没有已确认的成品线束SKU或报价。

共同俯视下六组排针针序方向相反，不能按左右位置接线。B0电极pin1位于(64.049999,24.000001,55.4)，S2.J1.pin1位于(25.949999,26,14)。电气合同始终同针号直通，不能因此翻转原84路映射；制作图要给实际对插观察面，并100%逐芯导通检查。

可运行python -B hardware/sourcing-closure-20261030/harness-geometry-20261030/check_harness_geometry.py，或附仓库根目录参数。结果为源几何与候选安装坐标的核查，不是实配或弯线可行性验收。旧原生源、CAM包和安装图保持不变。
