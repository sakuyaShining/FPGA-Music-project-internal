## 整机统一口径

一台整机由 Control88 R2 控制板×1、Sensor14Bank×6、用户已有 Tang Nano 20K×1、左手完整 FR-4 电极面板×1套、右手 J10 7英寸电容触摸屏×1套，以及覆盖层、外壳、固定件、供电和连接线组成。不是七块板加屏就已可装成成品。Control88 已集成 PCM5122，无需再买 DAC；J11 已取消。音箱由用户借用，采购预算中不再计音箱。

用户已确认：**450×190×60 mm（宽×高×厚），18 mm 音位中心距优先采用**。左手两排25音位（C3–B3 的12个、C4–C5 的13个），每音位3电极共75路，加5八度与4备用，共84路。传感板每块14个外部通道，另2个校准通道。严守 `raw_index=channel*6+bank`；C5三电极仍为 B0/B1/B2 的 CH12。不能为了采购或布线重排映射。

左手236×156 mm与右屏名义180×104 mm的放置仅是包络候选；内部堆叠、安装孔、插头弯线和实际触控盖板干涉尚未验收。60 mm深度不是已经装配成功的结论。详见电极目录 `mechanical-envelope.json`。

新增全部硬件、PCB/SMT、屏幕、附件和运费合计上限 **700元人民币**。现有 Nano 不重复采购；用户没有 USB-A 转 USB-C 数据线或5V电源；有源音箱借用。没有已经确认的整机总价和供货日期，未知报价不能填0。

## 直接商品与询价要求

1. **USB数据线：Ckmtw S100920007 / C430908**，USB-A公转USB-C公、1m、有数据功能，1条。立创详情：https://item.szlcsc.com/426730.html 。袋装数量不等于购买起订量；国内实时价格、库存、运费以结算页为准。
2. **音频座：星坤 XKB PJ-301M-3-B / C381127**，TRS立体声、3焊片、带螺母面板安装。https://item.szlcsc.com/353359.html 。不要误买 -2-B/-2-Y 单声道版本。C19189087不再作为本方案首选。C88 的 J12 是 C49257 三针排针，针1=L、针2=R、针3=GND；经约200mm柔性双芯屏蔽线到 TRS 的 Tip/Ring/Sleeve。实际座脚须以插入TRS插头的通断测试确认，不猜焊片编号。预焊、绝缘热缩、应力释放、面板固定一并报价。详见 `audio/` 的厂家图纸、接线说明和可直接提交的补充需求。
3. 嘉立创可以对 C88 上 J12 等排针做插件焊接审单；**外置音频座和线束是否接单尚未确认**。定制线束询价入口：https://cable.szlcsc.com/customize.html 。普通裸母排针不是已压接好的成品线束。若采购队友联系厂家，附 `audio/给嘉立创-音频接口预焊补充需求.txt` 并索取接单确认、针序图、含运总价和交期。
4. **屏幕厂家候选：BuyDisplay ER-TFTM070-5V4**，7英寸800×480、RA8875、FT5316电容触控。官方：https://www.buydisplay.com/7-inch-lcd-module-capacitive-touch-screen-panel-i2c-spi-serial 。明确要求出厂 **4线SPI、5V供电、3.3V逻辑兼容、FT5316 I2C/INT/RESET、预焊40针及所有匹配线束**；索取模块/触控外形、孔位和接头图纸、完整配置含运人民币报价与真实发货日期。默认接口可能为8080并口，料号和页面起价不足以保证配置；不能把 Arduino shield 变体当直接替代。用户仅允许屏幕单独走厂家官方店，其他器件继续嘉立创/立创。我们没有代发询价或取得报价。
5. **供电**：5V系统，Nano USB-C独立支路，C88 J13另一支路，共地；J5.1 的 Nano5V保持NC，J13不能给Nano供电。5V架构确定不等于电源商品已选好。需核对整机电流预算、峰值裕量、接头和线径后确定电源及分线，不能用未核实的充电头冒充已闭合方案。
6. 电极到传感板6组接口线、控制板到传感板线、J10屏线和触控线、USB线、供电分支和音频线均须在总表核对，不能只买排针。传感板J1通道CH0…13对应针8/7/6/5/4/3/2/1/14/13/12/11/10/9，15/16地；按针号逐端核验，不能只看线色。外壳、螺柱螺钉、绝缘支撑、连续粘合绝缘覆盖层仍待完整机械设计精确选型。Nano有TF槽，是否需另买卡及容量/格式随最终固件确认，不另买TF模块。
