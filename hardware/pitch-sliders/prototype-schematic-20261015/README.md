## 接口及不能直接制造的原因

J1实际草稿针序：1=3V3，2=GND，3=BUS_SCK，4=BUS_MOSI，5=SCAN_LATCH，6=INPUT_LOAD_N，7=INPUT_DATA，8=FPGA_SENSE_A，9=FPGA_SENSE_B，10=STORE_SDA，11=STORE_SCL，12=GND。**这是小样线缆连接器的针号，绝不是Nano排针或FPGA封装脚号。** J2的1～12对应STRIP0_E0至STRIP3_E2。

两连接器暂用真实库候选BOOMELE `2.54-1*12P反弯针/C247920`；尚需核对安装方向、机械尺寸、配套线缆与实价。实体电极应尽量靠近MUX；J2用于可拆试验板，线缆寄生必须实测，不把长杜邦线效果当最终PCB电极效果。现草稿没有实际电极封装、测试焊盘和低寄生ESD器件；MUX剩余I9～I15明确NC。SW1机械脚6/7明确NC，最终安装脚处理仍需对照厂家图；按键1/2与3/4分组来自库图，仍需供应商图纸资格确认。

595上电状态未知：开始计时前先送完整控制字并锁存，完成初始化前忽略测量结果。共享显示SPI时，必须重新移入完整控制字后才能脉冲RCLK；不要把屏幕像素直接锁入扫描控制。165/EEPROM的软件时序、传感计时与总线仲裁尚未实现。传感器覆盖膜、位置连续性、相邻独立性、噪声/电源干扰、最坏触摸至声音≤10ms都需实物验证。

## 新增录音和曲谱功能

详细方案：[57号设计稿](../../../docs/02-技术方案/57-小样接线与录音曲谱功能扩展-2026-10-15.md)。建议板载TF保存配对PCM与演奏事件，板内8MiB SDRAM缓冲，24LC256继续只保存自定义乐器。

[官方Nano20K说明](https://wiki.sipeed.com/hardware/en/tang/tang-nano-20k/nano-20k.html)及[3921 Rev1.30原理图](https://dl.sipeed.com/fileList/TANG/Nano_20K/2_Schematic/Tang_Nano_20K_3921_Schematics.pdf)支持板载资源与TF信号80～85脚预留；用户实板版号/最终CST仍需核对。小样不新增外接TF座、不增加计算MCU。保留独立TF总线，避免与触控/显示共享SPI时钟造成冲突。

候选首版按设备演奏录入、屏幕跟弹提示、至少5分钟多段录音核算；这些细则正在询问用户，尚未冻结。按现有52734.375Hz单声道PCM16，5分钟约31.64MB；256KiB单向环形缓冲约2.49秒，不能据平均卡速保证任意卡不丢样。容量算式在[recording-capacity-plan.json](recording-capacity-plan.json)。还需SD读写/文件保存、SDRAM仲裁、播放链路和曲谱UI的联合综合/PnR，现有95.4%Logic探针不包含这些新增功能。先在原60元预备金内给卡留30元，总预算目标仍500元，尚无完整实际报价。
