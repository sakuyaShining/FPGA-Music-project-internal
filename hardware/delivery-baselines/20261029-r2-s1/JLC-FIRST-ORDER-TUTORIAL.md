# 嘉立创新手审单、报价与下单教程

核对日期：2026-10-29。适用当前Control88 R2×1、Sensor14Bank S1×6。官方页面文字可能调整，以登录后的实际界面和客服回复为准。

## 先理解你要购买什么

- PCB制板：工厂生产还没有焊元件的裸电路板。
- SMT贴片：工厂购买/接收器件，并将贴片器件焊到PCB上。
- 插件焊接：排针、排母等通孔器件的焊接，要另行选择并确认。
- Gerber：告诉工厂铜线、焊盘、阻焊、板框和孔等如何制造。
- BOM：告诉工厂每个位号使用什么器件。
- CPL/坐标：告诉工厂器件放在哪里、角度多少、在板的哪一面。
- DFM/贴装预览：厂家按工艺检查文件并展示制造/装配结果；不等于验证电路和固件功能。

你这次要购买7块装好元件的板，不是只购买7块裸PCB。共256件板上器件，其中232件SMT、24件插件。

## 第二步：登录国内官网并联系官方客服

1. 打开https://www.jlc.com 。
2. 登录/注册；若已有嘉立创EDA账号，先按页面使用同一账号登录。账号、验证码及收货信息由你本人处理。
3. 找“PCB/FPC下单”“计价/下单”或“嘉立创PCB服务→立即下单”。官方教程也提供“专属客服”入口。
4. 如看见专属客服或在线客服，先咨询；如进入SMT页面，找右侧“下单帮助”。通过官网显示的联系方式接入，不根据搜索广告随意添加私人账号。
5. 发下面这段开场白，再附总包ZIP和需求TXT：

> 你好，我第一次在嘉立创做PCB+SMT，想先审单报价，暂不付款投产。我有两种设计：Control88 R2需要1块装配成品，Sensor14Bank S1需要6块装配成品，都是四层板、名义1.6mm。附件包含各板Gerber、BOM和坐标，请协助确认：PCB最低投板数、实际贴装数量能否1和6、插件/排针排母能否预焊、料库是否可供，以及含税运总价和最早发货日。我无法自行焊SMT，请勿只报裸板价格。请指导我分别建立PCB和SMT订单。

这一步只是咨询/人工预审，未必能仅靠聊天附件获得最终自动报价。客服若要求先建立未付款PCB订单，按以下流程建单，并保留订单号供关联。

3. 等待解析，核对板框约100×100mm、铜层数4；若识别成2层或显示多块不相关板，先停下联系技术支持。
4. 基本参数按下表填写/向客服确认。

|页面项目|Control88 R2|
|---|---|
|类别|普通FR-4硬质PCB，非FPC、铝基板|
|铜层数|4层|
|单板尺寸|100×100mm|
|板厚|名义1.6mm|
|叠层|JLC04161H-7628；无可选项时写备注并让客服确认|
|铜厚|当前工程外铜35μm、内铜15.2μm；要求按该标准叠层核对，不自行改厚铜|
|阻焊/字符|可先按常规绿色阻焊、白色字符询价|
|表面处理/过孔工艺|按Gerber与SMT要求让客服确认常规可行方案及费用|
|本单是否需要SMT|需要|
|拼板、工艺边、基准点|本次按单板源提交，交工厂评估；不自行拼成多联板|

|目标贴装数量|1块装配成品|

5. 在备注中写清：“Control88 R2，需1块装配成品，最低多做裸板请分列，不默认增加贴装数量。需要SMT并询插件预焊。四层叠层JLC04161H-7628，名义1.6mm，先审单报价，待PCB/SMT及交期确认后付款。”
6. 若需提交未付款订单才能审单，可按提示提交审核；确认页面状态为待审核/待付款。此时不进入支付，也不确认任何启动生产的动作。

## 第五步：为每个PCB订单分别建立SMT订单

官方流程一般是“SMT贴片加工→在线下SMT订单”，或PCB提交后“继续去下SMT订单”。进入https://www.jlc-smt.com/order?smtOrderSource=pcb 后，可能先看到“选择未发货PCB”。

1. 先选对应PCB订单，核对文件名/订单号，避免控制板配上传感板BOM。
2. 选“上传BOM和坐标”。本次使用已经冻结的外部文件，不用系统从另一个源文件自动生成的资料替换。
3. 按下表上传。

|订单|BOM|SMT坐标|贴装数量|SMT焊接层|
|---|---|---|---:|---|
|Control88 R2|01-Control88-R2/Control88-R2-BOM-FACTORY.csv|01-Control88-R2/Control88-R2-CPL-SMT.csv|1|只贴顶层|
|Sensor14Bank S1|02-Sensor14Bank-S1/Sensor14Bank-S1-BOM.csv|02-Sensor14Bank-S1/Sensor14Bank-S1-CPL-SMT.csv|6或客服确认的可执行数量|只贴顶层|

“只贴顶层”描述贴片器件所在面，不能据此自行推定所有排针排母安装方向；插件安装面和方向按原生工程/装配要求请客服确认。

4. 原生全坐标TSV是复核附件，包含插件信息；常规上传优先使用上表的SMT CSV。若工厂为插件需要全坐标，让其查看原生TSV并确认转换，不直接把.tsv后缀改成.csv。
5. 当前BOM包含全部器件，SMT CSV只包含76/26个贴片器件。插件位号不在SMT CSV内有明确原因；不要直接删除插件。让客服指导插件/手焊选型及位置资料。如平台提示缺坐标，将原生全坐标附件交其处理或交回工程转换。

## 第六步：BOM匹配与贴装预览

1. 选择自助匹配，优先按BOM准确C编号和型号匹配。若平台提供付费“帮我选型”，先看当前收费再决定；不需要为上传已经准备好的文件而默认购买人工选型服务。
2. 核对每行最终匹配型号、封装、数量、价格及库存。自动推荐的相似型号不能直接全部接受。
3. C14663、C1591等按当前冻结BOM分别保留。缺货、起订量过大或不在可贴库时，记录对应位号/料号，交回工程核对；不自行删掉或换成近似料。
4. 明确要求：控制板12件插件、每块传感板2件插件共12件，一并询预焊。嘉立创有插件焊接服务，但该具体器件/安装面能否接单与费用应由客服和订单匹配确认。
5. 看贴装预览：器件不能整体偏出板框、不能落在错误焊盘；芯片1脚、旋转和连接器方向请厂家核对。出现红色极性/角度/位置警告时，不凭“DRC为0”忽略。
6. 若厂家新增拼板工艺边，应让其同步处理Gerber与坐标，并回传预览。不能由你只修改其中一个文件。

## 第七步：拿到完整报价后再确认付款

让客服分列两种设计的：裸板数量/费用、实际贴装数量、器件费用、SMT费用、插件预焊费、税运、加急、最早发货日。页面一个“PCB价格”不是装好元件的总价。

整机700元还要留屏幕和附件预算，不能将700全部用于板子订单。未取得实际总价前，不依据历史教程中的工程费、优惠券、SMT天数承诺成本和交期。

付款前留存：两个PCB订单号、两个SMT订单号、最终物料匹配结果、制造/贴装预览、分项报价、发货时间、插件预焊说明。已付款但SMT未关联的裸板可能进入制板/发货流程，首次操作应请客服确认关联和出货方式后再支付。
