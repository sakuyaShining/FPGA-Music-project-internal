## 钻孔证据

`native-drill-audit.json` 读取实际原生文件；本机 API 的部分 `getState_Hole()` 返回值比原生孔尺寸小一数量级，不能直接用于出孔径结论。`exported-drill-audit.json` 与 `DRAFT-DRILL-AUDIT-169open-NOT-FOR-ORDER.zip` 确认导出采用实际孔径；导出前后 PCB 文件 SHA 不变。

这份 ZIP 仅为孔型审查，仍有未连通和过时地铜，**不是投板文件**。其中完整 PTH 钻孔已包含过孔，额外 `_Via.DRL` 是过孔子集；制作最终制造包时须明确主钻孔层，避免把相同过孔重复累计。最终布线改变过孔后须重新导出与复查。
