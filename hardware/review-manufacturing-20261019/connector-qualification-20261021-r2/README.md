## 电源线端型号收敛

采用标准 **XHP-2 壳体 + SXH-001T-P0.6 端子 + AWG22 导线**；绝缘外径应在0.9–1.9mm，成品压接线优先。不要只写“SXH系列”后让采购任意替换。

本轮选择普通插拔力的SXH-001T-P0.6；后缀N是低插入力型，不自动替代；SXH-002T-P0.6只适合AWG30–26，不适合本方案AWG22。J13.1为正5V、J13.2为GND，必须以插合状态逐线通断核验，红黑线颜色不能代替测试。长度、适配器端插头、合格成品线商家及到手价仍未确定。

原厂来源：[XFCN PZ254V-11-XX图纸](https://www.xfconn.com/uploads/soft/20240711/4-240G111231T93.pdf)、[JST XH目录](https://www.jst-mfg.com/product/pdf/eng/eXH.pdf)。本地原始PDF及抓取UTC/SHA见manufacturer-fetch.json。只摘取必要尺寸用于核对，不把原厂完整图纸内容改写成自己的制造图。
