区域图的最少孔是其声明图模型内的结果，不是完整PCB最优解。它未考虑路径长度、新孔彼此避让及实际参考地；本轮展开路径后才检查完整铜间距、孔间距和真实分层连通。几何可连通也不能抵消绕行质量失败。线长为各段求和，不宣称是全局最短或唯一铜长度。

根因定位：现有顶层3V3_IO走线构成HARM四端点的区域分隔。诊断中移除该网172条顶层线后，四端点才同属一片可布区域；单移除地线仍有两个组。不能将此诊断当成删电源线方案。

电源铜图包含48个电源焊盘、222个铜对象、351个接触关系；172条顶层线逐条测试，50条可单独移除而保持焊盘连通，但HARM区域边界仅4条，且多数是极短重叠段，不能合并删除或据此宣布供电质量通过。

R13通过将局部过孔向轨道法线方向偏移，找到79个满足当前几何筛查的短电源桥候选、4个代表；保留源线宽0.33528/0.399796mm。三桥同时替换后，48个电源焊盘仍连通。但HARM联合路由仍247.98mm，整体否决；压降、瞬态、真实地铜和原生DRC均未因此关闭。
