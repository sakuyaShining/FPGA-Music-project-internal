# 控制数量范围纠正及U9的实际八路输入

2026-10-27。上轮采购说明把J10的8个泛音触控分区误算成8个实体按钮，进而写成13按钮、两片165，这是没有规格和原理图依据的额外采购，现撤回。此纠正没有修改PCB、原理图或RTL，也不删减任何产品要求。

当前统一规格PRODUCT-SPEC.md R03明确泛音由J10触屏分区推子实现；R06的当前载板基线是四个预设键、一个编辑键和一个带按压编码器，不批准16键、PCF8575或新GPIO表。原02_Shift_and_memory及06_Controls两页的现存SHA已重新核对，与原227件功能基线一致。

|U9 SN74LV165ADR脚号|原网络|输入用途|
|---:|---|---|
|11|ENC_A|编码器A相|
|12|ENC_B|编码器B相|
|13|ENC_PUSH|编码器按压|
|14|PRESET0|预设键0|
|3|PRESET1|预设键1|
|4|PRESET2|预设键2|
|5|PRESET3|预设键3|
|6|EDIT|编辑键|

八路正好对应5个按钮信号及编码器3信号。U9.10串行输入接GND，U9.9输出KEY_QH；现图没有第二片165的级联输入。U9.1=INPUT_LOAD_N，2=BUS_SCK，8/15=GND，16=3V3_IO，7为未用互补输出。

采购基线因此写为5按钮、1带按压编码器、1片165和1片595。它是原图已存在的硬件，不代表完整编辑需求已满足：保存、取消等独立操作还没有被签收的完整接口合同。不得因为撤回额外8键就默认将这些功能塞进编码器按压、删除独立操作要求，或修改产品固件去适配未批准的新GPIO方案。

完整预焊控制/接口/存储/供电实现和总价仍未闭合。此前对用户说的“13按钮、两片165”不再作为采购数量依据。
