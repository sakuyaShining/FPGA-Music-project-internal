# AUX产品输出与试听设备范围纠正

用户再次确认产品使用3.5mm AUX音频输出。原61号硬件规格第31—32行明确线路DAC＋TRS（L/R/参考地），不要求耳机直驱；当前阶段允许两路输出同一单声道节目。

独立功放、裸喇叭或新购有源音箱不是实现AUX输出的必购组成，不再阻塞AUX模块方案或自动计为必需产品费用。历史试听商品证据保留，但不继续以选定喇叭为采购定稿前置。若视频确需新购外接播放或录音设备，另列清楚用途与预算后核对。

原规格也包含板载MAX98357A喇叭支路及“已有喇叭”的旧假设；库存只Nano20K已覆盖该假设。本次不擅自删除历史支路，也不把它扩大成必须新增双声道功放/扬声器。

当前55元DAC候选的RCA线路输出至最终3.5mm TRS的准确转接/面板件、滤波保护、电平、静音与断电行为仍需核。模块自带3.5mm耳机插座不直接冒充线路输出。PCM5122时钟/PLL/格式初始化仍未闭合。**撤回“TPA6130A2只影响耳机、可以排除于AUX初始化门”的判断**：同SKU原理图中的耳放、全局LOUT/ROUT网络、隔离变压器和音频切换器存在共用输出路径；在确认实际跳线/装配及完整RCA路径前，不能假定RCA绕过耳放，也不能省略对应初始化、静音和电平核验。厂家仍明确将RCA归类为AUX OUT，这与板内是否使用放大级是两个问题。两个音频槽复制相同节目也不自动等于违反独立立体声需求，原规格当前允许同节目两路。

到可购买清单仍有四组收口：①完整84路预焊前端；②控制/存储/电源保护及AUX/附件具体实现；③整机固件物理接口兼容性；④屏完整配置、全部报价/交期/逐针接线与700元总额。此后还有到货组装联调校准、拍摄视频两个阶段。不能把这些描述为只差六个小操作。

前端当前实际状态以sensor-fourlayer-progress-current.json及当前活动入口为准，旧“仅左8离线、原生未变”的描述已经过时。原主板仍未完成。实物UNMEASURED，完整采购方案未放行。
