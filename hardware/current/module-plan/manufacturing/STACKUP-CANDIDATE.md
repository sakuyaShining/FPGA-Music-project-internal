# 传感四层板叠层核验候选

当前源身份与缺口见`sensor-source-manufacturing-audit.json`，不直接修改已批准的原生源。

供原生客户端核验的厂商标准候选为嘉立创JLC04161H-7628，标称四层1.6mm。原厂[叠层资料](https://jlcpcb.com/impedance)列出：

| 从顶到底 | 材料 | 厚度mm |
|---|---|---:|
| L1 | 外层铜 | 0.035 |
| 介质 | 7628半固化片 | 0.21040 |
| L2 | 内层铜 | 0.0152 |
| 芯板 | FR4 | 1.065 |
| L3 | 内层铜 | 0.0152 |
| 介质 | 7628半固化片 | 0.21040 |
| L4 | 外层铜 | 0.035 |

这是候选厂商材料表，不是已写回CAD或经厂商接单确认的叠层。使用时复核该料号的实际可制造选项、公差、铜厚与报价。本板已启用内层15/16，不能用仅含两层铜的物理记录替代四层映射。内层含信号与地，不能把所有内层描述为无分割完整地平面。

连接EDA后须检查：PCB身份与源哈希；逻辑1/15/16/2到物理L1/L2/L3/L4的一一映射；铜/介质/总板厚；通孔贯穿层、成品孔及钻孔表；叠层调整后的铺铜与严格DRC/网络连通；35项限定例外仍只作用于批准项；Gerber确有四铜层、外形与钻孔坐标一致；BOM/CPL与28件板一致。若保存导致源哈希变化，必须记录前后源并重新评审相关几何/距离，不能沿用旧SHA上的检查结论。
