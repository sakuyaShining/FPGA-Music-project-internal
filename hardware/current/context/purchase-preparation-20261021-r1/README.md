## 本轮明确的装配决定

每板 **217个SMT位号交工厂供料贴装，13个通孔件补焊**。旧分工是212 SMT+13通孔+5手焊SMD按键；现在把5个同型号按键交工厂，不改原理图或封装。原因是 C318884 本轮散买库存0，而立创国内公开商品页精确料号核对后记录 `smtStockNumber=273109`。此字段只支持工厂供料的候选路径，不能替代最终装配匹配/锁料和报价。

报价暂按2块贴片板、1块补焊接口、1套乐器，第二块贴片板留备份；没有自动多买第二套屏幕。国际JLC原型说明最少2块，国内平台工艺和费用仍需实际匹配，数量可在工作簿黄色输入区修改。5块裸板仅为询价假设。

散买量只计算用户补焊件，按本轮MOQ/销售倍数向上取整。工厂供料项散买量为0，避免用户再买整包被动元件。参考库存是快照，不是预留。没有人民币单价、税运和工程费的项目保持缺失，不产生虚假整机总价。
