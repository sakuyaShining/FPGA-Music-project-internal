# FPGA 加法合成电子乐器

基于高云 GW2AR-LV18QN88C8/I7（Sipeed Tang Nano 20K）的纯硬件实时加法合成乐器。
振荡器、包络、效果与曲谱时序全部在 FPGA 内完成，主机仅经串口下发控制参数。

选题：2026 高云半导体 FPGA 创新设计赛道「基于 FPGA 的实时多音色合成电子乐器引擎」。

**首版行为合同已建立，交互细节已重新讨论，实现与硬件验收仍在推进**：见 [首版行为合同 v1](docs/02-技术方案/36-首版行为合同-v1.md)。
首版以可靠复音、16 分量音色编辑/保存/调用、8 档右手塑谱与明确发声方式收口；
合同逐项区分已有证据和待实现行为。现有掩码塑谱与帧日志导出还不能代表这些功能已经完成。

**行为细节已重新讨论，尚未全部实现**：最新选择见 [需求分析](docs/02-技术方案/37-首版交互需求分析-讨论稿.md)，
上板前按 [需求到实现追踪](docs/02-技术方案/42-需求到实现追踪.md) 核对支持的行为；RTL 接手入口为 [src/rtl/README.md](src/rtl/README.md)。

## 音频链与硬件参数

| 项 | 参数 |
|---|---|
| 主时钟 | 板载 27 MHz（引脚 4），不使用 PLL |
| 采样率 | 52734.375 Hz = 27 MHz ÷ 512（顶层 DIV_BCK=16，32 BCK/帧） |
| 音频输出 | FPGA 生成 I2S BCK / WS / SD；24 位内部数据取高 16 位送板载 MAX98357A |
| 控制接口 | UART 115200 8N1，两字节帧 `[地址][数据]`，地址表已冻结 |
| 演奏输入 | 16 路电容触摸电极（RC 充放电计数）：左手 8 键定音高，右手 8 键定泛音幅度 |
| 面板指示 | 6 个板载 LED；板载按键（引脚 88）预留 |

## 合成引擎要点

- **时分复用结构**：一个样本周期划分为 512 个时隙，即 32 声部 × 16 泛音。每个时隙完成一次相位累加、幅度查表与累加。
- **振荡器更新率**：512 × 52734.375 Hz = 27.0 M 次/秒（全部分量活跃时的计算规模）。
- **音高**：128 项相位增量 ROM 覆盖 MIDI 0–127。增量按精确频率计算而非现场近似，实测音高误差小于 0.1 音分。
- **混叠保护**：某次泛音的频率超过 Nyquist 频率时将其静音，而不是任其混叠。
- **塑谱**：16 字节泛音幅度表（谱 RAM），支持逐声部刷新。物理电极掩码与主机下发的谱按位或，因此"手指塑谱"与"软寄存器塑谱"逐位一致。
- **音色预设**：4 组泛音表。
- **效果**：延迟、合唱、8 抽头混响网络（含反馈与阻尼）。
- **曲谱时序**：片内定序器。曲谱既可固化在 RTL 中（上电后自行演奏，不依赖主机），亦可经 UART 下载。

## 目录结构

```
src/rtl        可综合 RTL：时分复用合成引擎、声部分配与音高、电极扫描、
               效果器、I2S 发送、串口接收、寄存器堆、片内定序器
src/sim        仿真测试台（各模块与顶层、判据验证）
src/constr     引脚约束（.cst）与时序约束（.sdc）
src/gowin      Gowin 工程与综合用数据表（音高表、预设泛音表、倒数表）
tools/scripts  构建、回归与判据脚本；命令行上位机；寄存器表抽取
tools/host     图形界面上位机（PyQt5）
docs           赛事情报、技术方案与学习路线文档
sim_build      仿真产物与音频证据（音频仅保留交付用的少量文件）
```

## 构建与验证

```powershell
# 编译全部仿真测试台
powershell -File tools\scripts\build_sims.ps1

# 全量回归：12 组套件，含 512 点频谱栅格与 16 组位一致比对
python tools\scripts\regress_all.py --full

# 综合与布局布线
powershell -File tools\scripts\build_gowin.ps1 `
    -Project src\gowin\tdm_synth\tdm_synth.gprj `
    -SspiAsGpio -PlaceOpt 2 -RouteOpt 2

# 图形界面上位机
python tools\host\dsp_gui.py
```

`-SspiAsGpio` 用于把 54/55/56 三脚从专用 SSPI 功能释放为普通 IO，DAC 数据线接在这三脚上，因此该选项不可省略。

## 验证方法

- **回归套件（12 组）**：加法引擎黄金参考（时分复用实现与全并行参考实现逐位一致）、I2S 编解码、包络、测试模式频谱栅格、寄存器音高、定序器事件、混响冲激响应、Nyquist 保护等。
- **音频级判据**：音高估计 7/7（±1 音分内）、混响衰减曲线、谱外能量占比。
- **判据全集、配方与证据路径**：`docs/02-技术方案/21-验收判据清单.md`。
- **接口规格（冻结）**：`docs/02-技术方案/19-UART协议v1.0草案.md`。
- **电极规格**：`docs/02-技术方案/20-pad扫描规格书.md`。

## 上位机

`tools/host/` 为图形界面：键盘演奏、16 路泛音幅度调节、电极遥测柱状显示与量程判定、寄存器回读、帧序列导出。

串口不可用时可用内置"模拟设备"模式走通完整界面流程；连接真实硬件时，界面顶部徽标会明确标示当前设备类型，避免把模拟数据误认为硬件读数。
